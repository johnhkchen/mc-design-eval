Find freely licensed reference photos for two San Francisco landmarks. They will be used as design references for a
Minecraft recreation shown on a public website (the photos may also be displayed on that site beside the build, with
attribution). Use Wikimedia Commons (its API, e.g. https://commons.wikimedia.org/w/api.php with prop=imageinfo and
iiprop=url|extmetadata, or the category pages), or other sources only if the licence is explicit.

Allowed licences: public domain / CC0, CC BY, CC BY-SA (any version). Skip anything else (no "fair use", no
non-commercial, no unclear licence, no images whose licence you can't read from the file's own metadata).

1. Painted Ladies, Alamo Square ("Postcard Row", 710-720 Steiner Street): 5-8 photos. Want: the whole row from the
   park (the classic view), straight-on facades, at least two close-ups of one house's facade details (bay window,
   gable, trim, porch/stair), and if possible a view showing the rear or side and the slope of Steiner St.
2. Palace of Fine Arts (Marina District): 5-8 photos. Want: the rotunda with the lagoon, the rotunda straight on,
   the colonnade (peristyle) curving away, close-ups of a column/capital, the planter boxes with weeping figures on
   top of the colonnade, the coffered dome inside, and an aerial/overview if one exists.

Download each at about 1600 px on the long side (use the Commons thumbnail URL with a width), into
  refs/painted-ladies/NN-short-name.jpg  and  refs/palace-of-fine-arts/NN-short-name.jpg
Then write refs/LICENSES.md: one table per landmark with columns file | what it shows | author | licence (with link) |
source page URL | attribution line to display. Also refs/licenses.json with the same data.
Check every file opens as a JPEG. Report how many you got for each landmark and anything you couldn't find.
