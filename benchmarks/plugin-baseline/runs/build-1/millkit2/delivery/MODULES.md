# millkit2: modules

8 modules on a 12 x 20 plot grid (x along the lane, z from the lane's far edge back). Each file is one plot, 12 wide, 33 high, 20 deep, on a solid foundation: load them side by side along x, 12 apart, all at the same y and z, in any order and any count. Mirror a module in the structure block (Mirror: Left/Right) for variety; rotate a whole row to face another lane.

## Mixing with the first kit (millkit)

Same plot grid and lane: the lane's top surface is at y 11 of every module file in both kits (this kit's foundation is
11 deep so it lines up), the lane at z 0..4, plots 12 wide. Load a module from either kit at the same y and z, 12 apart
along x. This kit's files are 20 deep (the first kit's are 19): the extra back row holds only the shutters on a back
wall, so place both kits from the lane side (same z) and it lines up.
