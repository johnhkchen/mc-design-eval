to do next* — then hand the Script desk a tight brief.

Questions to answer (output: `audience-message-brief.md`):

- **Framing.** "Engineered quality climb", a measurement instrument + a categorical judge, autonomous
  self-judging overnight loops, the multimodal image-to-3D pivot. Which angle leads?

- **CTA.** What the post asks for (follow / discuss the method / try it).
