# PR room

The content-production workspace for **E-12 (evolution-showcase)** — a "room of desks", each a workstream
that produces one part of a LinkedIn video artifact: a "March of Progress" evolution of the technique
(the same Minecraft temple facade improving stage by stage, captioned with what each iteration added).

This is **comms, not code** — it consumes the project's existing artifacts (`benchmarks/temple-facade/runs/`,
`benchmarks/temple-facade/concepts/`, `docs/knowledge/design-learnings.md`, the categorical scores) and
turns them into a crafted, honest, on-thesis story.

## Desks

| Desk | Folder | Produces |
|------|--------|----------|
| Research | [`research/`](research/) | audience + message + consumer-psych brief; positioning, hook, CTA, trust beats |
| Script | [`script/`](script/) | evolution beats, on-screen captions / voiceover, storyboard with timing |
| Assets | [`assets/`](assets/) | the canonical ordered evolution sequence (hero spine + breadth beat) + captions + scores |
| Production | [`production/`](production/) | output spec (format/length), assembly plan, rough cut, LinkedIn post copy |

## The artifact, in one line

Crude gray box → measured technique-by-technique climb → the image-to-3D pivot (plot twist) → a stunning
palette-disciplined facade → the staged-sculptor vision. Engineered, not lucky — with the rubric scores
climbing on screen.
