# Script desk

Narrative & script for the evolution-showcase video.

**Job:** turn the research brief into the *beats* — which iterations to feature, what each one *added* —
and the on-screen captions / voiceover, with timing.

Output: `beats.md` (the ordered story beats + the technique each frame unlocks), `script.md` (caption /
voiceover lines), `storyboard.md` (frame → caption → duration).

The arc — two threads woven (quality climb + velocity/realness):
1. **Hook** — crude gray box ↔ the finished facade (before/after tease).
2. **The measured climb** — same subject improving: "+ design-doc grounding" → "+ reference grounding" →
   "+ one-plane fix", with the categorical score climbing (competent → strong).
3. **The velocity engine** — dozens of builds a day; techniques accumulate in the journal and *transfer*
   across subjects; the compounding that powered the climb.
4. **The plot twist** — text-JSON hits a ceiling → change tools → the **image-to-3D pivot**, the visual leap.
5. **The explosion** — a wall of high-quality "bet-you-can't-do-this" builds.
6. **"Yep, that's real"** — those builds **rotating in 3-D** through our own rig (prismarine-viewer + real
   minecraft-assets textures); a 360° spin an AI picture can't fake. We control the rig; it's true-to-Minecraft.
7. **Breadth** — the five references generalize.
8. **The vision** — the staged sculptor (Golden Gate ambition): we're the sculptor, not the 3D tool.
