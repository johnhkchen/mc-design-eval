# Script — evolution-showcase video

Per-frame on-screen captions + optional voiceover. Frame IDs `F01–F15` join to `beats.md` and
`storyboard.md`.

**Voice (locked):** declarative, receipts-forward, skeptic-respecting. Short sentences. A real
number wherever the brief has one. **No hype adjectives** ("stunning / revolutionary / amazing"
are banned — the climbing score does the bragging). `caption:` is the on-screen text, written for
**muted autoplay** (terse, ≤ ~8 words). `VO:` is an *optional* fuller voiceover line the
production desk (S-034) may record or drop. `overlay:` is the score chip / `[concept]` tag / number
shown on the frame — it must not duplicate or contradict the caption.

## CTA block (S-034 lifts these; do not over-promise a product)

- **Primary — follow for the method:** *"I'm publishing the whole journal — the principles, the
  null results, the climb. Follow if you build with LLMs and want the receipts."* (links
  `docs/knowledge/design-learnings.md`.)
- **Secondary — discuss (comment bait):** *"Which technique would you have bet on? We were wrong
  about best-of-N."*
- **Soft-pedal try-it:** there is no packaged tool yet — do **not** add a "try it" CTA. Promising
  a product breaks the honesty contract and the v1-sequencing reality (brief §7/§8).
