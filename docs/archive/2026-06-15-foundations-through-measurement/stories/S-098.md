## Background (self-contained)

Epic **E-26**. The E-21 map's placement vocabulary is 4 coarse rules (`walls` / `corners-edges` / `trim`
/ `roof`) over whole zones — which is how both stone and plaster claimed `walls` and one ate the other
(the 215→8 plaster collapse). The kit (S-096) names *what* the ingredients are; nothing yet says *where
each instance goes*: the stripped-log frame follows floor lines, corners, and gable rakes; the panel
block fills the fields *between* the frame; each window instance gets its own treatment.

## Goal

A **placement grammar** binding kit entries to **structural feature instances** from the structural read:
frame lines (floor lines, corner posts, gable rakes, eave beams) → the frame block; bounded fields
between frame lines → the panel block; each opening instance → its declared treatment (S-099 applies
it); roof courses → the course block. Deterministic given kit + structural read; pure and unit-tested on
synthetic reads; no per-subject code (E-25 Rule 3 inherited).

## Builds on

- S-096 kit (the vocabulary); `src/view/structural-read.mjs` (floor lines, wall fields, openings,
  roof region — the feature instances); E-24/E-25 zone-fill (the grammar refines *what fills the field*
  and adds *the lines and sites the fill must respect*).

## Run-the-test ticket

- `T-098-01` — grammar core + cottage run: stripped-log frame on the frame lines, smooth-sandstone
  fields between them, both storeys matching the concept's framing rhythm; before/after renders.
