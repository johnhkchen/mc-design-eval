## Background (self-contained)

Epic **E-25**. The E-22 resemblance gate judges **one shared 3/4 view**. The defects that currently make
builds look wrong — the roof's grey side-faces (42.7% spruce on the exposed roof surface vs 96.7% from
straight above), wall residue, the gatehouse cavity — are at their worst on **the views the gate never
sees**. A single-angle gate structurally rewards skinning the photographed face and ignoring the rest;
the multi-angle cottage contact sheet showed exactly that.

## Goal

Widen the gate so a build must read as the concept's object **from any angle a viewer would stand**:
render the build at **4 fixed azimuths** (45°, 135°, 225°, 315° at the contract elevation/resolution),
judge each view categorically (same object / drifted / different object + named gap) against the
immutable concept, run the E-24 coverage precondition per view, and emit a **contact sheet** (concept |
4 views) as the verdict artifact. **Pass = same-object at every azimuth, ≤2 named minor gaps total.**
Binding: the angle set is fixed in config; the gate refuses to run with a missing view; no gating on the
friendliest angle.

- E-22 resemblance gate (`benchmarks/sculpture/resemblance.mjs` — triptych, judge, Rules); E-24 S-088

## Run-the-test ticket
