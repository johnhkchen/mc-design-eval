## Goal

Build the **render harness** (epic **E-02**, spec §3–§4): construct a design artifact as an **in-memory voxel world** and render it to an image **headless** with existing Minecraft rendering tools (JavaScript + `prismarine-viewer`) — **no Minecraft server, no Mineflayer bot**. Exposed as a tool the Agent SDK invokes. Render-only — rendering exists to produce scoring images, never to build the human deliverable (§6).

This is half of what the "see an image" milestone needs; the other half is the experiment harness (S-004), which converges with this story at the smoke trial.

## Track breakdown

- **Foundation:** `T-003-01` scaffolds the JavaScript render environment (pinned MC version, assets, in-memory world, headless render path). Everything in this story depends on it.
- **Parallel after foundation:** `T-003-02` (voxel-world construction) and `T-003-03` (headless render) both depend only on the scaffold and run concurrently — but world construction also gates on **S-001** `T-001-02` (it consumes the expanded voxel set).
- **Convergence:** `T-003-04` wraps construct + render into one tool.
