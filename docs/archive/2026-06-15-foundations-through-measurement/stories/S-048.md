## Background (self-contained)

Epic **E-16** uses real TRELLIS GLB meshes (`benchmarks/sculpture/glb/{koi,heart}.glb`) as a **3-D form
target** for the E-15 surgical revision loop. E-15's loop hill-climbs a form number; its old number was a
silhouette IoU vs a **flat** concept image, too blunt for a local edit to move and with no honest
region-vs-region signal. A GLB fixes that — but only once we can turn the mesh into a **target
silhouette** from a chosen camera, including masked to a region.

Key realization: a *silhouette* needs no GL, no textures, no lighting — it is just the **filled outline of
the mesh's triangles projected to 2-D**. So this is a **pure software rasterizer**: transform vertices by
the camera matrix (the render rig's camera math already exists — `render/src/camera.mjs` `framedCamera`),
project to the image plane, fill each triangle into a binary mask. Whole-object, and masked to a region's
projected 3-D bounding box (the per-region target the loop never had).

## Goal

A pure module that loads a GLB's geometry (vertices + triangle indices from the glTF binary — see the
parser shape in `benchmarks/sculpture/trellis-glb.mjs` `inspectGlb`), projects it from a given view
(matching `SCULPTURE_VIEW_3Q`), and rasterizes a **binary silhouette mask** — whole-object and per-region
(masked to a 3-D bbox's projection). Deterministic, GL-free, unit-tested on a tiny synthetic mesh (a cube)
so the suite stays offline and fast.

## Builds on

- The GLB on disk + `trellis-glb.mjs` `inspectGlb` (the glTF JSON/binary parse pattern).
- `render/src/camera.mjs` (`framedCamera`, `boxOf`, `boundingSphere`) — the same camera the build renders
  with, so target and build silhouettes are comparable.
- The E-15 form metric (`src/form/form-fidelity.mjs`) for the IoU it ultimately feeds.

## Run-the-test ticket

- `T-048-01` — implement GLB load + projected-triangle silhouette rasterization (whole + per-region);
  unit-test on a synthetic cube (known silhouette); one real koi.glb silhouette saved as a visual check.
