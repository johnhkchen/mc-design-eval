## Goal

Epic **E-13**. The breadth: run `vConcept` (S-035) on **8 sculptural subjects** at standard scale **~32**,
one ticket each — proving the system goes from a single word to a built object across wildly different
form types. Each records a **fidelity-vs-concept** read (concept image vs 3-D build render) so the
frontier is legible.

(koi, bow & arrow, heart) will trail hardest — that's the measured gap that motivates the sculptor.
