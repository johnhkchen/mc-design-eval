## Background (self-contained)

Epic **E-15**, terminal link. The epic builds a region-scoped *observe → tweak → re-observe →
accept-if-improved* loop that surgically revises a finished build to close the **form** gap (organic line
loss: the koi S-curve, the heart aortic loop). By now the substrate exists: a form-fidelity metric
(silhouette IoU, S-043), a region-lock + section-observe (S-044), the proven deterministic loop/accept-gate
(S-045), and the LLM form-edit route behind that gate (S-046).

Two things remain. **(1) The GLB seam.** A standing project intention is that *down the line* an image→3D
tool (TRELLIS → a GLB mesh, deferred in E-09) will supply a **better form target** for "is this region the
right shape." The loop must already consult a **form-target interface** so that target can swap in later
with no change to observe/diagnose/accept. Today the target is derived from the concept image / occupancy
heuristics; this story builds the *interface and the seam*, **not** the GLB itself. **(2) The honest demo +
measurement** — the project's discipline (mirroring E-14's value-true consolidation): run the whole loop
end-to-end, report a before/after **number**, and show the residual rather than hide it.

## Goal

Define the per-region **form-target interface** (concept/heuristic implementation today; a documented GLB
adapter point for later) that the loop's accept step consults. Then run the full surgical loop on ≥2
measured-gap sculptures (koi, heart): record **before/after form-fidelity (IoU) + judge categorical** vs
the E-13 baseline; journal a **form-revision** section in `docs/knowledge/design-learnings.md` (where
surgical revision helped, where it didn't, the iteration cost, the residual); hand improved renders +
before/after pairs to E-12 (`pr/assets/`).
