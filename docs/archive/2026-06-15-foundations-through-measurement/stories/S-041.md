## Goal

Epic **E-14**, the build end of the co-design loop. Wire E-10 into the **live build** so block
*placement* hits the concept's **value**, not just its name. Today the build prompt says "primarily the
document's palette" and the model picks blocks by hue intuition — which is how the moai came back
`gray_concrete` (too dark) despite a faithful form. Replace that with a **CIE-Lab nearest-block snap**:
extract the concept's realized palette and let the color engine choose the value-true block per region.

Division of labor: the **model owns form + where** (which region is which intent); the **engine owns
which block** hits that region's target value (`nearestLab` against the S-039 contract). This is the
direct cure for value drift on text→JSON's best forms.

## Builds on

- S-039 `resolveValueTruePalette` (the target values) + E-10 `image-grid.mjs`
  (`gridFromImage`/`extractPaletteFromImage`) and `cielab.mjs` `nearestLab`.

  `src/sculpture.mjs` `composeSculptureBuildPrompt`. Additive — the `.v1` build path stays intact.
