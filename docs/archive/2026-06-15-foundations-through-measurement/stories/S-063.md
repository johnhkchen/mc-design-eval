## Background (self-contained)

Epic **E-19**, the **artifact / stray-geometry fix** (no SAM). Voxelizing a TRELLIS mesh can leave content
that isn't in the reference: floating islands, and — worst case — **duplicate masses and hallucinated
connectors** (the moai's concept was a 3-view contact sheet, so TRELLIS reconstructed multiple statues
joined by invented bridging bars; it shows ≥3 connected components and silhouette IoU 0.565). The user's
directive: **no SAM** — clean this **geometrically**.

The no-SAM fix: compute the occupancy's **connected components** (face-adjacency) and **keep the principal
component(s)** — the largest, plus any above a size floor (so a legitimately separate part like an arrow
isn't dropped) — and **discard small floating islands**. This removes the moai's extra statues + connectors
and general debris without touching the input image.

This story also fixes a **verified bug**: the integrate/combined build passes `palette: prim` (primary
design-doc only) while claiming "augmented", so the **gated secondary blocks (T-058-03) are never placed**.
Pass the **augmented** palette (`aug`) so the secondary actually reaches the build.

## Goal

`pruneStrays(occupancy, opts) → occupancy`: connected-component analysis → keep principal component(s)
above a size floor, drop the rest; deterministic, pure. Wire it into the build path. Fix the integrate
build to use `aug` not `prim`. Measured by S-062's stray-voxel/component metric (moai → ~1 principal
component / largest-fraction ≈ 1) with form IoU recovering.
