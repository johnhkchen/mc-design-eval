## Background (self-contained)

Epic **E-26**, fifth why: the resemblance gate is *image-shaped* ("same object / drifted"), so missing
ingredients hide — at 512px the judge names "material zoning" gaps, never "missing trapdoor shutters."
The gate never asked for the kit, so no epic ever supplied it. The fooled-gate lesson
(E-22/E-24/E-25) in its newest form: a gate that doesn't enumerate can't demand.

## Goal

A **bill-of-materials check beside the multi-angle gate**: for each kit entry, verify presence **at its
grammar sites** (fence + trapdoors at each opening; frame block on the frame lines; panel block in the
fields) — absences are **named gaps** in the verdict. The check is a precondition companion to (never a
replacement for) the E-25 resemblance judgement, in the same spirit as E-24's coverage precondition: the
judge refines a build that already contains its ingredients; it cannot wave one through without them.
**Proof both ways:** the current kit-less cottage **fails** with "missing: trapdoor shutters, fence
infill, stripped-log frame"; the dressed cottage **passes**.

## Builds on

  kit + S-098 grammar (what and where to check). Presence-at-site checks are deterministic over the
  artifact — a candidate for the light model tier only where judgement is needed (E-23 routing).
