## Background (self-contained)

Epic **E-24**, terminal. The good cottage skin (77% plaster) existed only because an agent hand-edited the
artifact; `npm run spray:paint` regenerates the bad 9%-splat version. **A result the pipeline can't
reproduce is not a result.** This story proves the epic: high-quality skins produced **end-to-end by the
pipeline**, reproducibly.

## Goal

Re-skin **cottage + gatehouse** end-to-end via a **named `npm run` script — no inline edits** (Rule 1),
**seeded/stable** (Rule 2), composing the epic's pieces: zone-fill dominant (S-085) → value-true blocks
(S-086) → secondaries splat/LLM → coherent surface (S-087) → coverage-aware gate (S-088).

## Acceptance / scope (carried into T-089-01)

- A **single `npm run` script** produces each subject's skinned build end-to-end; a **fresh re-run
  reproduces it** (no hand-edited artifact anywhere in the path — verified).
- Both subjects: each zone's **dominant established full-coverage** (upper storey reads plaster, not
  patches), **value-true** blocks (cream not pink), **coherent** surfaces; **pass the coverage-aware gate**
  (S-088), with any residual **named** (Rule 5).
- **Refreshed triptychs** (concept | mesh | minecraft) saved; a **before/after** vs the E-23 splat-only skin.
- `docs/knowledge/design-learnings.md` gains a **durable high-quality results (E-24)** section: the
  zone-fill-vs-splat lesson (splat can't establish a dominant — 9% vs 77%), value-true selection, the
  coverage-aware gate (catching "looks the same"), and the **durable rule** (pipeline reproduces it, not the
  agent inline). Honest where it over/under-reaches.
- An **E-12 handoff** (`pr/assets/`); `npm test` green.
