## Goal

Epic **E-13**, the crux. Generalize `vConcept` to a **single-view sculpture mode**: from a single
**term**, write an imagined design doc → generate a **3/4 concept** (the object as Minecraft blocks,
isolated on black, via the locked stage-1 concept tooling, generalized from "facade" to "object") →
**build a freestanding 3-D voxel object** grounded on that one concept (our existing multimodal
claude -p build, not a facade-with-relief) → render **3/4 + turntable** (the orbit rig). Add a
**`--scale`** parameter. Wire it as a runnable approach taking `--subject` + `--scale`.

## Builds on

- The committed stage-1 concept tooling (`src/nano-banana.mjs`, `baml-concept.mts`, `FacadeConceptPrompt`),
  the `vRef` grounded-build seam (`requestDesignArtifactWithImage`), the render harness + orbit rig.
