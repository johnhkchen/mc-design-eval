## Goal

Epic **E-11**, the spine. Build the staged build-state model + the stage-pass interface + the orchestrator
+ lock semantics — the abstraction every craft pass plugs into. A **build state** carries per-cell
occupancy (massing), material, relief depth, and per-stage **lock flags**; a **stage** is a
`(buildState, intent) → buildState` transform; the **orchestrator** runs stages in order, locking each;
the state **compiles down to a `DesignArtifact`** so render/judge/export are unchanged.
