## Background (self-contained)

Epic **E-21**, the "**refine according to the original concept art**" step. The LLM material map (S-071) +
feature-aware assignment (S-072) get the materials *mostly* right, but feature heuristics aren't perfect
(a buttress the classifier read as "wall," a gable mis-zoned). This pass lets the LLM **correct material
regions against the concept** — the material analogue of E-15's form surgical loop.

Render the build; show the LLM the **render alongside the concept**; it flags regions whose *material*
doesn't match the artist's intent ("this corner should be cobble, not brick"; "the roof trim should be
dark oak") and proposes a **bounded material reassignment** (recolor a region — no geometry change). Apply
**accept-if-closer-to-concept** (P14-safe: a change that doesn't move the build toward the concept's
material zoning is rolled back; accepted regions lock).

**The LLM also has the right to ADD a block back into the palette** when, referring to the concept, it
catches a **material the concept clearly uses but the build is missing** (a "missing texture"). The palette
is not a cage here — the concept is the authority. The discipline is **concept-justification**, not a hard
count: each added block names the concept material + where it appears, is a real survival block, and is a
**distinct material role** (a near-tone block alongside an existing one — cobble with brick — is exactly
what we want; a redundant near-duplicate is not). This is concept-justified growth, the opposite of the
full-table bloat we fixed. E-21's allowed palette becomes design-doc ∪ gated-secondary ∪ these additions.

## Goal

A concept-grounded material-revision pass: observe render vs concept → LLM proposes region material
corrections → apply (recolor only, within the real block vocabulary / the S-071 map) → keep if it moves the
materials closer to the concept, else roll back; bounded rounds. Reuses the E-15 loop machinery (region
addressing, accept-gate, lock) with a **material** target instead of a form target.
