## Background (self-contained)

Epic **E-32**, terminal. The epic's claim: **design capability compounds** — a style can be formed in
language space, its missing brushes specified by the factory and implemented once by AI coding, and a
building in that style composed from the registry — with each later style cheaper than the last
because the library grows. The receipt is reuse, measured: registry count before/after, brushes
shared with `rustic`, rework on promoted drafts.

## Goal

**One new style, end-to-end through the whole stack**: theme brief → formed style (S-130,
human-ratified) → backlog generated (S-131) → the gap brushes implemented off **promoted** drafts →
**one building in the new style** composed via the E-31 workshop (budgeted, ledgered,
replay-reproducible) → **one frozen-gate run** (the epic's only judge call; receipts; T-119 pins;
T-114 replies). Recorded: the verdict + sheets (honestly, either way), the conformance results, and
the **compounding receipts** — brush count before/after, reuse fraction from `rustic`, draft-rework
measure. Journal + E-12: the factory thesis with numbers.
