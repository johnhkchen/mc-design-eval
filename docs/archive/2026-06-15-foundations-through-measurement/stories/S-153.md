## Background (self-contained)

Epic **E-36** (de-freeze the creation loop). Creation-side gates assert byte-identity /
silhouette-no-regress against the **committed draft** — so "don't change yesterday's build"
institutionalizes yesterday's build. Guarding a flat box against regression freezes the flat box. The
comparison that matters during creation is **vs the concept** (the glance), not vs the last draft. (The
philosophy's split: creation is free and iterative; only *measurement* is frozen.)

## Goal

Creation-loop gates compare to the **concept**, not the prior draft. Remove
`no-regress-vs-committed-draft` assertions from the **creation** path (the workshop loop, the
generate/chain runners), so a pass that moves the build *closer to the concept* is never rejected for
differing from last time. **Retain no-regress only where it guards the frozen instrument** — e.g. an
identity-class gate change (T-095/T-110/T-144), where "every previously-passing verdict re-derives
unchanged" is the whole point. Reframe the workshop / milestone runners so "better" means "closer to
the glance."
