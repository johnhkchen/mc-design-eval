## Goal

Define the **design-artifact contract** — the structured object the LLM emits and everything downstream reads (spec §5). This story ships the *design definition* side of epic **E-01**: a validatable schema, deterministic primitive expansion, the Agent SDK structured-output binding, and the first style palette (the material-constraint data, §6). With this in place, a model can emit a palette-constrained design and we can validate it.

This story is the foundation of the entire instrument — the seam that lets prompt construction vary in Phase 1 while everything else stays fixed.

## Track breakdown

- **Foundation:** `T-001-01` defines the schema. `T-001-02` and `T-001-03` depend on it.
- **Parallel after foundation:** `T-001-02` (primitive expansion) and `T-001-03` (structured-output binding) touch different modules and run concurrently.
- **Independent data:** `T-001-04` (style palette) has no dependencies — it is reference data and runs in the first wave.

## DAG

```
T-001-01 (schema) ──┬──> T-001-02 (primitive expansion)
                    └──> T-001-03 (structured-output binding)

T-001-04 (style palette)        (independent)
```

Downstream gates (cross-section): `T-001-02` feeds artifact materialization in **S-003** (`T-003-02`); `T-001-03` feeds the trial runner in **S-004** (`T-004-01`); `T-001-04` feeds the single-shot archetype in **S-004** (`T-004-02`).
