## Background (self-contained)

Epic **E-16**, Arm A — the direct test of E-15's cliffhanger. E-15 built a surgical region revision loop
(`reviseLoop` in `src/form/`) that keeps a tweak only if a form metric improves, and left a
**`glbFormTarget` seam** (`src/form/form-target.mjs`, currently throws) for a real 3-D target. On the
text→JSON koi/heart builds the loop rolled back **2 of 2** edits and moved nothing — because its target
was a **flat concept silhouette** (whole-object IoU: koi 0.481, heart 0.347). Now real GLBs exist
(`benchmarks/sculpture/glb/{koi,heart}.glb`) and S-048 can project them to a target silhouette.

This story plugs the GLB in and re-runs the loop on the **existing text→JSON builds** — the cleanest
possible A/B, because *only the target changes*. The whole point of the seam is that swapping
concept→GLB touches **nothing** in observe/diagnose/accept; the loop consults only
`scoreRender(renderPath, R)`. So this is mostly: implement `glbFormTarget`, pass it as
`liveFormScore({ formTarget: glbFormTarget(...) })`, re-run, measure.

## Goal

Implement `glbFormTarget({ glbPath, view })` behind the existing `scoreRender(renderPath, R)` interface
(render the build's PNG silhouette, compare to the GLB's projected silhouette from S-048 — whole-object,
and a *true per-region* IoU masked to R's projected bounds). Re-run the E-15 `reviseLoop` on the
text→JSON koi/heart builds with the GLB target; record **before/after form IoU + judge** vs the E-13
baseline, and confirm the loop ran **unchanged**.
