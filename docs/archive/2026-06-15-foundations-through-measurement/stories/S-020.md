## Goal

Epic **E-10**, the reusable core. A **portable CIE-Lab color engine** with ZERO mc-design-eval/Minecraft
dependencies: sRGB → linear → XYZ(D65) → L\*a\*b\* conversion, a pluggable ΔE (CIE76 default), and
`nearest(color, palette[{key,lab}]) → key`. Pure color math + nearest-neighbour. This is the module
E-09's voxelizer reuses (the "portable core, project adapter" principle) — so it must not import the
block table or the artifact schema; it takes a palette as data.
