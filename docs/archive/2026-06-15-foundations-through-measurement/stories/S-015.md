## Goal

Epic **E-09**, first link of the stage-1 concept-art chain. Choose the strongest INPUT VARIANT for the
Nano Banana concept stage on the evidence, not on two samples. The orchestrator
(`benchmarks/temple-facade/conceptart.mjs`) supports four variants of what is attached to the model:

- **A** — design doc + reference photo (inspiration only)
- **B** — design doc + reference + our prior prismarine render (everything)
- **C** — design doc + our render only (upscale our actual build)
- **base** — design doc only

Run the full matrix (4 variants × 5 references), eyeball each concept on the three stage-1 targets —
(1) fidelity to the design intent/palette, (2) inspiration-not-blueprint, (3) detail within the fixed
block resolution — and pick a default variant. Hypothesis from the spike: **C** (upscale our render)
wins on voxel-honesty and fidelity-to-our-build, but confirm against A/B across all references.
