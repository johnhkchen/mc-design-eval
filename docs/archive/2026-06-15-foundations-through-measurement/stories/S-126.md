## Background (self-contained)

Epic **E-31**. The most basic loop of all skilled work — look, adjust, look again — has been
structurally forbidden in this project: the no-re-roll rule (correct for *grading*) leaked into
*building*, so every build was a single blind shot. The E-31 mode split fixes the conflation (Rule 1):
iteration is the **workshop's** nature; the frozen judge convenes once, later, and the workshop may
never call it. The tools the loop needs all exist (idiom realization, parameter adjustment, the E-23
spray-paint path, renders at the gate azimuths); what's missing is the loop itself and its ledger.

## Goal

The **workshop loop**: build → **4-azimuth renders** → the model critiques its own build against the
concept (named, structured critique) → revises — re-recognize a part, adjust idiom parameters,
spray-paint details — → the pack's **conformance checks** gate the round (regularity never regresses)
→ repeat within a **declared budget** → the model declares done. Every round **ledgered** (critique,
action, render, check results — including the model's raw replies); the final build **replays
byte-identically** from the committed program + ledger via a named `npm run` (Rule 5: reproducible by
replay, not by sterility). **No frozen-judge calls inside the loop** — enforced the T-119 way
(structurally, tested), not by convention.
