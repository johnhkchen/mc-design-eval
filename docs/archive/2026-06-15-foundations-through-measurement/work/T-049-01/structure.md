## `src/form/form-target.mjs` — new/changed exports

### `mapVoxelRegionToMesh(subBounds, buildBounds, meshBounds) → {min,max}`  *(new, pure, exported)*
Per-axis fractional map of a voxel AABB into mesh coords:
```
f0 = (subBounds.min[a] − buildBounds.min[a]) / (buildBounds.max[a] − buildBounds.min[a])
f1 = (subBounds.max[a] − buildBounds.min[a]) / (buildBounds.max[a] − buildBounds.min[a])
meshRegion.min[a] = meshBounds.min[a] + f0 · (meshBounds.max[a] − meshBounds.min[a])
meshRegion.max[a] = meshBounds.min[a] + f1 · (meshBounds.max[a] − meshBounds.min[a])
```
Guards: a degenerate build axis (`max==min`) ⇒ that axis spans the full mesh extent (avoid /0). Output min
≤ max per axis (clamp/swap if a degenerate or inverted span appears). Pure, no I/O — directly unit-tested.

### `glbSilhouetteScore({ targetMask, renderImg, grid, fit, _extract }) → number`  *(new, pure, exported)*
The two-mask IoU kernel: `extractSilhouette(renderImg, RENDER_BG)` → `normalizeSilhouette` both
`targetMask` and the render silhouette to G×G → `iou(tNorm, rNorm)`. `targetMask` is an
`extractSilhouette`-shaped mask (whole or region-clipped — caller decides). No fs, no decode — `renderImg`
is already-decoded RGBA; tests pass synthetic masks/images. Imports `extractSilhouette`,
`normalizeSilhouette`, `iou`, `RENDER_BG` from `form-fidelity.mjs`.

### `glbFormTarget({ glbPath, view, buildBounds, grid, fit, _loadMesh, _rasterize, _decode }) → target`  *(replaces the throwing stub)*
```
{
  kind: "glb",
  glbPath,
  // per-region IoU = the loop's accept signal (the true-per-region upgrade)
  async scoreRender(renderPath, R) {
    const mesh = await loadMesh();                                  // memoized
    const region = (buildBounds && R?.subBounds)
      ? mapVoxelRegionToMesh(R.subBounds, buildBounds, mesh.bounds) // locate R in mesh space
      : undefined;                                                  // no bounds → whole-object fallback
    const targetMask = _rasterize(mesh, { view, ...(region ? { region } : {}) });
    const renderImg = await _decode(renderPath);
    return glbSilhouetteScore({ targetMask, renderImg, grid, fit });
  },
  // whole-object IoU = the harness's verdict signal (render whole build, no region clip)
  async wholeObjectScore(renderPath) {
    const mesh = await loadMesh();
    const targetMask = _rasterize(mesh, { view });
    const renderImg = await _decode(renderPath);
    return glbSilhouetteScore({ targetMask, renderImg, grid, fit });
  },
}
```
- `loadMesh()`: memoized closure var; default `_loadMesh = (p) => loadMeshFromGlb(readFileSync(p))` with a
  lazy `node:fs` import (the silhouette-CLI idiom — keeps the module's top level GL/fs-free for pure tests).
- `view` defaults to `SCULPTURE_VIEW_3Q` (imported; the build render's camera).
- `grid`/`fit` default to `FORM_DEFAULTS` (forwarded to `normalizeSilhouette`).
- Imports added: `loadMeshFromGlb`, `rasterizeSilhouette` from `./glb-silhouette.mjs`; `extractSilhouette`,
  `normalizeSilhouette`, `iou`, `RENDER_BG`, `FORM_DEFAULTS` from `./form-fidelity.mjs`; `SCULPTURE_VIEW_3Q`
  from `../sculpture.mjs`. `FormTargetNotImplementedError` stays exported (back-compat; now unused by the
  GLB path — kept so any importer/test referencing it still resolves).

`resolveFormTarget` is unchanged: it already passes `cfg.formTarget` through, so
`resolveFormTarget({formTarget: glbFormTarget({...})})` works with zero edit — the seam invariant, proven
by an existing test (D) plus a new one.
