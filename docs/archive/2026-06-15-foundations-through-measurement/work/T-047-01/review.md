## Open concerns / known limitations

1. **The whole-object single-view ceiling is real, not a bug.** Local edits barely move a whole-object
   silhouette IoU vs a flat concept; this is *why* both held. It is documented in the learnings + handoff +
   the `glbFormTarget` doc as the exact thing the GLB target resolves. A reviewer expecting an IoU *lift*
   should read the headline: E-15 ships the cage + metric + seam, not a number bump on these two subjects.
2. **`conceptFormTarget` ignores `R` in `scoreRender`** today (whole-object IoU; `region` is an opt-in 2-D
   bbox, not derived from `R`). That is honest — a true per-region target needs the 3-D projection. The
   signature already takes `R` so a GLB target can use it with no caller change.
3. **No GLB/TRELLIS code** (per the ticket): `glbFormTarget` throws. The deliverable is the seam + the
   documented contract, both present.
4. **Frame honesty:** koi `before`==`proposed` (byte-identical) — correct (the edit didn't move the whole
   silhouette), and stated as such; not a copy error.
