## Context

Epic E-10 / story S-022. Sample a concept image to a fixed N-wide grid (the held-constant resolution,
e.g. 48) and map each cell to a real block via the S-020 engine against a palette (the S-021 extracted
palette by default; the design doc's declared manifest when validating). Output the block grid (and a
visualization). Dithering OFF (clean architectural color fields).

Use the grid to demonstrate the E-10 thesis: (1) every cell is a real obtainable block — run the §9
**palette-adherence** check (zero out-of-palette placements when constrained to the manifest); (2) detail
is capped at the grid resolution. Also compute the **extracted-vs-declared** palette agreement (which
declared blocks actually appear, which the image introduced) — a signal on whether the concept honored
the doc.

## Acceptance Criteria

- [ ] A function/CLI samples an image to an N×M block grid and assigns each cell a block via the engine +
      palette; resolution N is a parameter (default matches the concept series, 48).
- [ ] A **visualization** of the block grid is produced (reuse E-02 render or a simple swatch render) and
      saved (gitignored, like `concepts/`).
- [ ] **Palette adherence:** when constrained to a declared manifest, the grid has **zero** out-of-palette
      cells; when discovering, the grid uses only blocks from the extracted palette. Tested.
- [ ] **Extracted-vs-declared comparison** is computed and recorded for one real concept (which declared
      blocks appear / are missing / were added) in the journal.
- [ ] **Tests** on a synthetic image: grid dimensions correct, every cell a palette block, a known region
      maps to the expected block. `npm test` green.
