## Context (self-contained)

Epic **E-32**, terminal / Story S-132. The epic's claim: **design capability compounds** — a style is
formed in language space (diegetic materials, ratified once), the factory specifies its missing
brushes, AI coding implements each once, and a building in the new style composes from the registry —
with each later style cheaper because the library grows. The receipt is **reuse, measured** — not
asserted.
