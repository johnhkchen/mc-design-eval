## Context (self-contained)

Epic **E-16**, Arm B (continued). T-050-01 turns a GLB into an **occupancy** grid (form, no color). This
ticket adds color and compiles a renderable build — the **GLB-voxel build** that goes head-to-head against
text→JSON. Reuse the proven E-10 color layer: `src/color/cielab.mjs` `nearestLab` + `block-table.mjs`
`loadBlockTable` (a 305-block Lab table) maps any color to the nearest real Minecraft block — exactly how
E-14 killed the moai value drift. Here the per-voxel target color comes from the **GLB surface** (nearest
vertex color, or a texture sample via mesh UVs) instead of a concept image. Output a standard
`DesignArtifact` so render + judge are **unchanged** and score it identically to a text→JSON build.

## Acceptance Criteria

- [ ] `glbVoxelBuild(glb, { scale }) → DesignArtifact`: from T-050-01 occupancy, assign each occupied cell
      a **value-true block** via E-10 `nearestLab` on the GLB surface color at that cell; compile to a
      `DesignArtifact` that **passes the AJV gate** (`src/artifact.mjs`).
- [ ] Pure color/compile logic **unit-tested** on synthetic occupancy + a synthetic surface color → a
      valid artifact with a sensible block manifest (offline, no GL, no 5 MB GLB).
- [ ] Real **koi + heart GLB-voxel builds** rendered (`SCULPTURE_VIEW_3Q`) + judged; artifacts + renders
      saved (`benchmarks/sculpture/glb-voxel/<subj>/`).
- [ ] `npm test` green.
