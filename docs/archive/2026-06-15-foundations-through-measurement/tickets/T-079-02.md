## Context (self-contained)

Epic **E-23** / Story **S-079**, a **fix**. The shipped spray-paint (T-079-01) produces a **wrong skin** on
the cottage (`benchmarks/sculpture/spray-paint/cottage/view-front-after.png`): plaster (`white_terracotta`)
is smeared across the whole face — including the **stone base and the roof** — plus floating painted stray
voxels. It reads as a pink blob, not a stone-base / plaster-band / wood-roof cottage.

**Evidence — `white_terracotta` lands in every height band** (it should be the middle storey *only*):
```
y0:65  y4:45  y8:51  y12:48  y16:52  y20:44  y24:10     (315 total; base y0–7 = 110, roof y24 = 10)
```

**Four compounding root causes (all real, verified):**
1. **The splat ignores the structural read.** `paintFace` (`src/view/face-paint.mjs`) recolors *every*
   surface cell whose color-quantized target is in-palette — there is **no storey-zone mask**. The structural
   axis the whole epic adds (`src/view/structural-read.mjs` — `storeyBands`, `roofRegion`, `wallFields`) is
   computed but **not applied** to the paint. (The T-079-01 POC restricted plaster to the upper-storey band
   and was clean; the shipped color-only splat dropped that discipline.)
2. **Concept→face alignment is a naïve stretch + quantization collapse.** The runner
   (`benchmarks/sculpture/spray-paint.mjs`) quantizes the concept then `resampleBlockGrid`-stretches it to the
   face dims with **no registration of the concept's bands to the build's storeys**; cream plaster / tan
   timber / light stone all snap to `white_terracotta` (`[[concept-image-not-color-value-preview]]`), so
   plaster is assigned high and low.
3. **It painted the raw, un-sealed surface.** Paint ran on `after-artifact.json` **before** S-084's
   stray-strip/seal (`src/view/surface-coherence.mjs`), so stray voxels got painted → the floating pink
   blocks. Ordering is wrong: **seal, then paint.**
4. **Refine skipped + gate fooled.** The report says `Refine: skipped`; the per-face gate accepted on a
   marginal `0.25→0.40` (or "GL-blind → accept by construction"). A marginal number rubber-stamped a
   visually worse skin.

**The fix in one line:** paint with **splat ∩ structural-zone**, on the **sealed** surface — color chooses
*which block within a zone*, the structural read chooses *which zone allows it*.

## Acceptance Criteria

- [ ] **Zone-masked paint**: derive zones from `structuralRead(occ)` — **base** (lower wall band[s]),
      **upper-storey wall band** (between base and roof), **roof** (`roofRegion`). The per-cell splat target
      is **intersected with the zone's allowed materials** before back-projection: plaster only in the
      upper-storey band; base keeps stone (`stone_bricks`/`cobblestone`); roof keeps roof material
      (`spruce_planks`/`dark_oak_planks`). A target landing in a disallowed zone is **rejected, not painted**
      (logged like `offPalette`). Implemented in `paintFace` / the runner via a zone-mask arg; **pure +
      unit-tested** (a base cell rejects plaster; an upper-band stone cell accepts plaster; a roof cell
      rejects plaster).
- [ ] **Measured result on the cottage** (the fix's proof): `white_terracotta` is **confined to the
      upper-storey band** — **0 plaster below the storey line** (base stays stone) and **0 plaster in the
      roof region** (roof stays wood). Report the per-band plaster histogram before/after this fix.
- [ ] **Seal before paint**: the spray-paint runs on the **S-084-sealed artifact** (or excludes the stray
      set), so **no stray voxels are painted** — no floating painted blocks in the render.
- [ ] **Refine not silently skipped / gate not fooled**: either run the refine pass, or have the per-face
      accept-gate **reject a paint that violates a zone** (so a marginal numeric gain can't ship a
      zone-wrong skin). State which, and why it's sound.
- [ ] **Visual proof**: re-render the cottage front + side (and re-run the **T-083 milestone** to refresh
      `pr/assets/cottage-face-after.png` + `cottage-multi-angle.png`) — the skin now reads as **three clean
      bands** (stone base / plaster-with-timber upper storey / wood roof), no pink smear, no floating strays.
      Before/after saved.
- [ ] `npm test` green; the journal (`design-learnings.md` E-23 section) gets an honest **correction note**:
      the color-only splat was *more sophisticated but worse* than the band-masked POC because it dropped the
      structural constraint — splat must be **∩ structural-zone**.
