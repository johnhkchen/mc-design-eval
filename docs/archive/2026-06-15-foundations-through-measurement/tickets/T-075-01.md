## Context (self-contained)

Epic **E-22** / Story **S-075**. The Minecraft build should look like its references. On the scale-64
gatehouse (`benchmarks/sculpture/building/scale-64/`) the build is clean by every block metric
(`speckle: 0.001`, `distinct: 4`, `offPalette: 0`; 2.0% surface neighbor-disagreement) yet the render reads
as grey static.

**Root cause (diagnosed).** At scale 64 the building spans ~64 voxels framed into ~400px of a **512×512**
image → **~6 px per block** while each Minecraft texture is **16×16**. The viewer atlas minifies with
`minFilter = THREE.NearestFilter`, **no mipmaps** (`render/node_modules/prismarine-viewer/viewer/lib/worldrenderer.js:91-92`),
and the renderer has **no antialiasing** (`render/src/render.mjs:75`, `new THREE.WebGLRenderer({ canvas })`).
Point-sampling a busy 16px texture down to 6px → minification aliasing → static. **Fix the lens, not the
build.**

**Rules of engagement (E-22, binding):** do not lower the scale to make the static vanish (Rule 3 — that's
a cheat); every claim cites a fresh render (Rule 4); the render stays deterministic + comparable (E-02); no
weakening tests to pass (Rule 5). A gap honestly reported beats a faked pass (Rule 7).

## Acceptance Criteria

- [ ] The render lens is fixed in **`render/src/render.mjs`** (owned code, no reliance on hand-editing
      `node_modules`) via **supersampling** (render at N× — e.g. 1024² or 1536² — and **box-downscale** to
      the 512² contract) and/or **mipmapped minification** (atlas `minFilter = NearestMipmapLinearFilter`
      + `generateMipmaps` via a post-load hook on the texture, keeping `magFilter = NearestFilter`).
- [ ] **Proof on the existing scale-64 gatehouse, same artifact**: re-render `artifact.json` with the fix
      and save a **before/after pair** (old-lens static → fixed-lens clean) with both paths in the report.
      The build is unchanged (same `placements`); only the lens changed.
- [ ] A **deterministic, GL-free unit test** of the supersample/downscale math (box filter on a synthetic
      high-frequency image: the downscaled output's high-frequency noise drops vs nearest-decimation) — the
      lisa env has no headless GL, so the *math* is tested; the live GL render is the impure proof.
- [ ] The render stays **deterministic and comparable** (E-02): the same artifact renders identically run
      to run; the contract output size is still 512² (supersampling is internal). No per-build camera
      tuning.
- [ ] **Resolution floor honored** (Rule 3): the fix works at the high scale (≥48); scale was **not**
      lowered to hide aliasing. Stated explicitly in the report.
- [ ] `npm test` green; the before/after PNGs + a one-paragraph note (what aliased, what the fix changed)
      saved under the work dir.
