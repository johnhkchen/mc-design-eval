## Context

Epic E-01, spec §5. The artifact is the spine of the instrument: the LLM emits a structured design object, not bot commands, and every downstream layer (export, render, evaluation, rating) reads it. This ticket defines that schema. Get it right and prompt construction can vary in Phase 1 while everything else stays fixed.

The schema must represent placements as **both** explicit voxels (coordinate + block type) **and** compact primitives (box / line / fill) so large builds stay within token budgets (§5, §11). It must also carry the palette manifest, the style intent + rationale, and the reproducibility metadata that keeps trials comparable.

## Acceptance Criteria

- [ ] Schema represents placements as both explicit voxels (coord + block type) and primitives (box / line / fill).
- [ ] Schema includes a palette manifest (declared materials), style intent (named style + short rationale), and metadata (prompting-method ID, model ID, seed, server-state ID).
- [ ] Schema is expressed as a machine-validatable definition (JSON Schema or equivalent) committed to the repo.
- [ ] A sample design artifact validates cleanly against the schema, and a malformed sample fails validation.
