## Context (self-contained)

Epic **E-36** / Story S-153. Creation-side gates assert byte-identity / silhouette-no-regress against
the **committed draft**, so "don't change yesterday's build" institutionalizes yesterday's build —
guarding a flat box against regression freezes the flat box. During creation the comparison that
matters is **vs the concept** (the glance), not vs the last draft. The philosophy's split:
creation is free and iterative; only *measurement* is frozen. No-regress is correct on the
**instrument** path (an identity-class gate change must prove every previously-passing verdict
re-derives unchanged — T-095/T-110/T-144); it is wrong on the **creation** path.

## Acceptance Criteria

- [ ] **Strip no-regress-vs-committed-draft from the creation path.** Audit the workshop loop and the
      generate/chain/milestone runners for assertions that reject a build because it differs from the
      *committed draft* (byte-identity / silhouette-IoU-no-regress vs the prior artifact, not vs a
      reference). Remove them from creation so a pass that moves the build *closer to the concept* is
      never rejected for differing from last time. List each site touched.
- [ ] **Keep no-regress on the instrument path.** Identity-class gate changes (the relief-aware gate,
      the budget v2, the proportion ruler) still prove monotone re-derivation of committed verdicts —
      untouched. The line is "is this protecting a committed *measurement*?" → keep; "is this protecting
      the prior *draft*?" → drop.
- [ ] **Reframe "better" to glance-vs-concept.** The workshop/milestone runners' notion of progress is
      "closer to the registered concept," not "byte-identical to last time." (The render-beside-concept
      from T-152-01 is the evidence surface; this ticket makes the *gate semantics* match.)
- [ ] **Honesty / no blanket unlock.** If a creation-path no-regress turns out to guard a committed
      measurement after all, it stays and the reason is recorded (E-36 Rule 1 — narrow, case by case).
- [ ] `npm test` green; reproducibility-by-replay of committed measurements unchanged; no new ceremony.
