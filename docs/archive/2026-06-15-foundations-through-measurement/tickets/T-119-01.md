## Context (self-contained)

Epic **E-30** / Story S-119. The committed verdict/record pins are load-bearing (instrument-diffs,
epic tables, head-to-head baselines all cite them) and two T-116 incidents proved nothing structural
protects them: (1) a reskin re-cut intended as a "cheap" record refresh **re-ran the judge** via
`component-skin.mjs` and re-rolled three styled verdicts (cottage 135° same-object flipped — the
budget-edge flap); commit `1baf955` was reverted and every pin restored byte-identically, fresh
verdicts preserved narratively (T-116 concern 6 — **residual ROUTED, not closed**). (2)
`npm run kit:extract --subject=barn` (missing `--`) dropped the flag and **silently swept the three
legacy kit pins** (caught, restored from HEAD). Vigilance is not protection.

## Acceptance Criteria

- [ ] **Read-only distillation mode** across the record-rebuilding runners: rebuilds records from
      committed outputs through a path where **judge-spawning is impossible by construction** (the
      judge seam absent or stub-that-THROWS in this mode) — **unit-tested**: invoking distillation
      cannot reach the judge; output records byte-match the committed pins on all legacy subjects.
- [ ] **Guarded pin writes**: any runner write that would overwrite a committed pin record **refuses**
      unless invoked with an explicit rotation flag (and says which pin and why it refused). The
      `kit:extract` missing-`--` sweep is the regression fixture: re-running it verbatim now refuses
      loudly. Unit-tested on a synthetic pin.
- [ ] **The pin-rotation policy**, recorded in `docs/knowledge/` (linked from design-learnings):
      canonical verdicts/records change **only** inside a ticket that explicitly owns verdicts, one
      judge run per view (T-114 governs malformed replies only), the retired pin named in the commit.
      Short, binding, citable.
- [ ] **T-111 residual 4 closed through the policy**: the stale styled-skin pins either rotated by an
      explicit, recorded act (if a verdict-owning run is warranted now) or explicitly retained with
      the staleness documented — decided, not left routed. No silent re-cuts.
- [ ] No gate semantics changes; no subject-specific constants; `npm test` green.
