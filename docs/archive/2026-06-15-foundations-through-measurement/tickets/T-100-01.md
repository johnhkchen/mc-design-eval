## Context (self-contained)

Epic **E-26** / Story S-100 — the fifth why made structural. The resemblance gate is image-shaped
("same object / drifted"): at 512px the judge names "material zoning" gaps, never "missing trapdoor
shutters," so missing ingredients hide and no epic ever supplied them. Same fooled-gate lineage as
E-22 (aliasing), E-24 (coverage), E-25 (single-angle): **a gate that doesn't enumerate can't demand.**

## Acceptance Criteria

- [ ] A **kit-presence checker** (pure, unit-tested): for each kit entry (T-096-01), verify presence
      **at its grammar sites** (T-098-01) — fence + shutters at each opening, frame block on the frame
      lines, panel block in the fields, course block on the roof. Deterministic over the artifact +
      structural read; absences come back as **named gaps**
      (`missing: trapdoor shutters @ openings 3/4`).
- [ ] **Wired beside the multi-angle gate** (T-093-01) as a companion precondition in the E-24 coverage
      spirit: the resemblance judge refines a build that already contains its ingredients; it **cannot
      pass a build missing kit entries** — and the kit check **cannot replace** the resemblance
      judgement (both run; both reported).
- [ ] **Proof both ways, recorded**: the current kit-less cottage **fails** with named absences
      (expected: stripped-log frame, trapdoor shutters, fence infill); a dressed cottage (or synthetic
      positive) **passes**.
- [ ] The kit itself is **immutable input** at gate time (extracted once per concept — the gate may not
      re-extract a friendlier kit; E-26 Rule 2). `npm test` green; no weakening of existing gate
      behavior for current callers.
