## Context (self-contained)

Epic **E-33** / Story S-134. The concepts' roofs read steep (~55–60°); the stair block's native slope
is 45°; if the roof vocabulary tops out there, steeper pitches are **inexpressible** and every build
reads squat regardless of how well proportions are measured — likely the largest single contributor
to "the form is off." Minecraft practice solves this with **mixed full-block/stair courses** (the 2:1
stepping family). The brush registry (T-128) is the door; the factory draft conventions (T-131)
define the spec shape.

## Acceptance Criteria

- [ ] **The steep-pitch brush through the registry door** (E-32 Rule 1): parametrized by pitch class
      above 45° (2:1 minimum; the implementer **declares which classes are realizable and which are
      refused by construction** — a refusal is a named finding, not an approximation); pure,
      exhaustively orientation-tested; render `unmapped` empty; **preview card** committed; catalog
      regenerated (brush count grows through the door).
- [ ] **Composes with the roof family**: ridge caps, verges, gable ends, and dormers realize
      correctly on steep courses (composition unit tests + a synthetic render card); conformance's
      course-evenness check passes on steep courses.
- [ ] **Realized on the barn** where its measured pitch (T-133, or the sketch directly if T-133
      hasn't landed) demands >45°: before/after renders at the gate azimuths committed — the
      silhouette visibly steepens.
- [ ] **No judge runs**; replay byte-identical; no per-building constants; `npm test` green.
