## Context (self-contained)

Epic **E-33** / Story S-133. The pattern-book builds pass the glance on identity (barn 4/4
same-object, T-127) and fail it on proportion — squat, shallow-pitched. Mechanism: recognition
*eyeballs* dimensions (VLMs are weak metric estimators) and the pack quantizes the rest, while the
conditioned sketch (T-123, `benchmarks/sculpture/sketch/*`) carries **measured** eave/ridge heights,
footprint aspect, and pitch — consumed only as recognition context. E-33 Rule 1: **identity from
language, quantity from geometry.**

## Acceptance Criteria

- [ ] **The measurement-to-program seam** (pure, unit-tested): the program schema's dimensional
      parameters (ridge height, eave height, footprint extents/aspect, pitch — per mass where the
      sketch names masses) are **sourced from the sketch's measurements** at seed time; recognition's
      qualitative naming is untouched. Conflicts (recognition implies a dimension the sketch
      contradicts) resolve **sketch-wins for quantity**, recorded.
- [ ] **Defaults demoted to recorded fallbacks**: a pack/default value is used only where the sketch
      cannot measure (named per parameter in the record); zero silent defaults on measurable
      dimensions — a test asserts the program records each dimension's source
      (`measured | fallback`).
- [ ] **Re-seeded programs for cottage + barn** behind the named runs: programs committed with
      sources; renders show the massing/pitch change; **before/after silhouette ratios recorded**
      (the S-135 metrics may be consumed pre-wiring or computed standalone here).
- [ ] **Replay holds**: re-seeded chains `--repro`/`--offline` byte-identical; prior committed
      records untouched (new programs are new records, prior pins valid).
- [ ] **No judge runs** (T-138-01 owns verdicts); no per-building constants; `npm test` green.
