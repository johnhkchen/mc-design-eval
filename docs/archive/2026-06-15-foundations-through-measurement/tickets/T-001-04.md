## Context

Epic E-01, spec §6. A palette is **data**: a JSON whitelist of survival-obtainable blocks per style, injected into the single-shot prompt as the binding material constraint (T-004-02) and, later, checked by the palette validator (E-04). This ticket defines the palette format and authors the first style palette.

Independent of the schema internals — palette block identifiers are standard survival-obtainable Minecraft block IDs (an external vocabulary), not something our schema invents — so this ticket runs in the first wave with no dependencies.

## Acceptance Criteria

- [ ] A JSON format for a style palette is defined (style id/name + whitelist of allowed block types).
- [ ] The first style palette (e.g. `industrial`) is authored, containing only survival-obtainable blocks.
- [ ] Every block identifier is a valid, survival-obtainable Minecraft block ID.
- [ ] The palette validates against its own format definition.
