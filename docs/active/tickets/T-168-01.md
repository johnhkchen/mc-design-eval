## Context (self-contained)

Epic **E-40** / Story **S-168**. Add **style distance** to `styleFidelityScore`
(`src/workshop/bakeoff-score.mjs`). Today: `100 − Σ penalty(severity)` (`PENALTY major=20, minor=8`) — it
counts missing-element presence and has no term for a present-but-wrong-style element. Derive a per-item
grammar mismatch from the Critique's `expected` vs `present` (the per-style Layer A names the wrong-style
grammar), score present-but-wrong-style as a **capping MAJOR** with a **distance** contribution, and fold
it in so a clean wrong-style build is capped low regardless of completeness.

## Falsifiable claim (anti-hedge — lead with how it fails)

The `expected`-vs-`present` mismatch is a reliable enough signal that a clean wrong-style build scores far
below its matched twin, **without** tanking a build that is merely incomplete-but-right-style. **Fails if:**
the free-text `expected`/`present` can't be classified into a grammar mismatch reliably (then Layer A needs
a typed grammar tag — a scoped feedback to the E-39 schema, flagged here not faked with brittle string ops);
OR the term over-/under-penalizes as a binary (needs a graded distance, validated in T-169-01); OR matched
and wrong-style still tie because Layer A emits identical `present` for both (the reading is the gate —
route back to Layer A, report).

## Acceptance Criteria

- [ ] A pure classifier in `bakeoff-score.mjs`: per item, decide present-but-wrong-style from `expected`
      vs `present`; assign capping MAJOR + a distance term; fold into `styleFidelityScore`. One source for
      the penalty/distance constants (the existing `PENALTY` pattern).
- [ ] Unit tests incl. a **matched-vs-wrong-style pair that now separates** (was tied), and a
      **incomplete-but-right-style** build that is **not** over-penalized by the new term.
- [ ] If a typed grammar tag from Layer A is needed, the gap is documented as a scoped E-39 schema feedback
      (do not hardcode brittle keyword matching to fake it).
- [ ] `npm test` green; pure (no GL/IO/model/Date/random); frozen instrument untouched.
