## Context (self-contained)

Epic **E-31** / Story S-125. The strategic reframe: resemblance comes from **recognizing** forms and
substituting canonical realizations ("that lumpy thing is a gable roof"), not from fitting the mesh.
Recognition is robust to the noise that broke fourteen epics of fitting, and it is the model's
demonstrated strength (the E-21/E-26 rationales prove the model *sees* materials and forms correctly
even when the output contract wasted the sight). This ticket puts the model's reading at the center:
the **building program** is authored by the model, in pack vocabulary, from the concept + the
conditioned sketch.

## Acceptance Criteria

- [ ] **Recognition seam** (the `claude -p` subscription shim, strong tier — never the metered API):
      the model receives the **concept image + the conditioned sketch** (T-123) and emits the
      **building program** — idiom instances with parameters (e.g. roof `gable, pitch-class 45°,
      dormers: 2`; walls `timber-frame, jetty: upper`; base `plinth: stone`; openings `rhythm +
      treatment`) — **schema-validated against the pack** (T-124); off-vocabulary output is rejected
      and re-asked within a declared budget (raw replies committed, the T-114 ledger pattern).
- [ ] **Realization wiring**: a validated program realizes through the idiom registry into a complete
      build — clean by construction, zero mesh cells, **no fit tolerances anywhere** (E-31 Rule 3).
      Pure composition logic unit-tested with synthetic programs.
- [ ] **Cottage + barn first drafts**: programs produced, committed (with raw replies + the
      prompt/schema documented), realized, rendered at the 4 gate azimuths — the renders show clean,
      regular first-draft builds passing the pack's conformance checks. **No judge calls** (S-127
      owns grading; the workshop owns revision).
- [ ] **Replayable** (E-31 Rule 5): the committed program realizes byte-identically via a named
      `npm run` (`--offline` re-assert); recognition itself may re-sample inside the workshop later —
      this ticket commits the accepted draft.
- [ ] No per-building code (the program is data; the grep checks building names in code as before);
      `npm test` green.
