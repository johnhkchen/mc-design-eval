## Context

Epic E-11 / story S-025. Bookend 1 — massing. Produce the gray massing shell as the first build state:
from a **form source** (the E-10 image→block grid, via a small `MassingSource` interface so a GLB can
replace it later), set `occupied` per cell, leave material/relief unset, and **lock the occupancy** (the
proportion lock) so no later pass alters the silhouette.

The proportion lock can be a simple accept gate now (occupancy locked once produced); the LLM/critic
proportion *judgment* can be a thin hook (record proportions; a fuller critic is the review bookend,
S-026). The point is a clean, locked gray substrate the craft passes build on.

## Acceptance Criteria

- [ ] A `MassingSource` interface + a concept-grid implementation produce a build state with `occupied`
      set and **locked**; material/relief unset.
- [ ] The shell carries proportion metadata (bounds, width/height) usable by the review critic.
- [ ] **Tested:** occupancy is locked (a later stage cannot change it — uses the S-024 lock enforcement);
      the shell compiles to a gray `DesignArtifact` (single material) that passes AJV and renders.
- [ ] The form dependency is behind the interface (no concept-grid specifics leak past `MassingSource`),
      so a GLB source is a drop-in later.
- [ ] `npm test` green.
