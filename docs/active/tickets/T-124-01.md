## Context (self-contained)

Epic **E-31** / Story S-124. Minecraft building is a finite pattern language and the project owns
canonical generators for most of it (gable/hip/pyramid roofs, arches, placement grammar, opening
dressing, hollowing, floorplans — E-23..E-30, all unit-tested). Missing: the **style pack** — a
per-STYLE bundle (sanctioned by E-31 Rule 2; per-building code stays forbidden) of curated palette,
idiom set, proportion rules, decoration vocabulary, and conformance checks. The pack structurally
retires the flagged-kit failure mode (the barn's auto-flagged kit silently disabled its own roof,
T-121/T-122): the **palette is human-curated once per style** — no per-subject recognition flags on
this path.

## Acceptance Criteria

- [ ] **The pack contract** (schema + loader, pure, unit-tested): `palette` (block per role,
      value-validated once with the E-14/T-086 tooling at pack-authoring time), `idioms` (names +
      parameter schemas), `proportions` (storey height, pitch classes, opening rhythm bounds),
      `decoration` vocabulary, and the pack's **conformance checks**.
- [ ] **The material story (`provenance`) field** — material choice is **diegetic, not optical**: the
      pack records the style's "local availability" narrative (local stone, local timber, wealth
      class, roofing economy) and the `palette`'s role→block assignments **derive from it** (the
      rationale per role cites the story). Precedence is part of the contract: explicit concept
      evidence > pack assignment > vernacular default — and **GLB textures are never read for
      materials** (TRELLIS textures are an amalgam of other games' assets; the barn's
      `flagged-mismatch` kit entries were the optical system correctly reporting that optics cannot
      decide materials — T-121/T-122).
- [ ] **Conformance checks** (pure, unit-tested both ways): courses even within a band; declared
      symmetry held; openings aligned to rhythm; palette in-pack; surfaces watertight/single-component
      (the integrity keepers from E-25). These are the workshop's per-round gate — cheap,
      deterministic, aimed at regularity (what eyes see), **not** mesh fidelity.
- [ ] **The idiom registry**: idiom name → canonical generator. Existing generators registered
      (gable/hip/pyramid roof, arch, timber-frame grammar, opening treatments, plinth, hollow/floor);
      the milestone's **gap generators built**: dormer, chimney, jetty — pure, exhaustively
      orientation-tested, `unmapped` empty through the render.
- [ ] **The first pack — `rustic` (Tudor/farmstead family, covering cottage + barn)** committed as a
      reviewable artifact: a human can read the palette and proportion rules against the two concepts
      and check them line by line.
- [ ] Every milestone idiom realizes canonically on synthetic specs (committed render card); no
      per-building constants (the pack file is the only style-specific artifact — code stays
      generic); `npm test` green.
