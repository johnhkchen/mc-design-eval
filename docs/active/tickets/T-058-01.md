## Context (self-contained)

Epic **E-18**, the **speckle fix**. The glb-voxel build (voxelize a TRELLIS GLB) wins on form but its
**materials are speckled** — each voxel sampled the GLB texture independently → scattered blocks. E-17's
material-clean pass (`materialCleanVoxel`: extract a value-true palette from the texture via the E-10
CIE-Lab technique, snap each voxel, light neighborhood smoothing) **narrowed but did not eliminate** it.
Per-voxel snap + a weak smoother can't enforce *regional* coherence; an isolated off-color voxel survives
as a speck.

Replace it with **material-region segmentation** — and pay special attention to **two observed symptoms**
(a directive), since they are why the speckle persists:
- **Palette leakage** — the build uses far more blocks than the subject has colors (per-voxel
  nearest-block over a loose palette + E-11 same-hue expansion let near-duplicates in). Hold a **tight
  fixed palette**: a handful of value-true blocks, **zero off-palette blocks**, distinct-block ≈ palette
  size.
- **Gradients** — the GLB texture's smooth gradients scatter into noise under per-voxel snap. A gradient
  region must become a **deliberate band / ordered dither** between adjacent palette steps.

So: under a tight fixed palette, group contiguous same-material voxels into regions (region-grow /
connected components by Lab ΔE in 3-D surface space), fill each region with **one** palette block
(off-color singletons absorbed), and **band/dither** any gradient region along its gradient direction.
Optional **E-11 material** (`src/sculptor/material.mjs`: same-hue set varied by normal/height) *within the
fixed palette* for deliberate texture. Reuse E-10 (`src/color/cielab.mjs` `deltaE`/`nearestLab` + the
palette-extract `medianCutLab`/`resolvePalette`, the block-Lab table).

## Acceptance Criteria

- [ ] `segmentMaterials(build, opts) → DesignArtifact`: confine to a **tight fixed palette**; region-grow
      over value-true voxels by Lab ΔE → regions; per-region single-block fill; **gradient regions
      band/dither** between adjacent palette steps; optional E-11 same-hue texture *within the palette*;
      output passes the AJV gate (`src/artifact.mjs`).
- [ ] **Palette discipline (the directive):** every block placed is in the canonical palette —
      **off-palette count = 0**, and **distinct-block count ≈ palette size** (a large drop vs the E-17 R2
      build); recorded before/after per subject.
- [ ] **Gradient handling (the directive):** a synthetic **gradient** voxel region renders as a clean
      **band / ordered dither** (≤2 adjacent palette blocks across the transition), not a scatter — unit
      asserted (distinct blocks across a gradient stays small; the transition is monotonic, not random).
- [ ] A **speckle metric** (fraction of voxels whose block differs from its 6/26-neighborhood majority)
      defined + computed **before/after** per subject; **drops** on the noisy ones (heart, koi).
- [ ] Unit-tested on a **synthetic noisy voxel set** (salt-and-pepper → coherent regions; a single
      off-color voxel absorbed) — pure, GL-free.
- [ ] Applied to **all 7** subjects → segmented builds + renders (`benchmarks/sculpture/glb-voxel-seg/
      <subject>/`); speckle + distinct-block + off-palette all down, **form IoU not harmed**.
- [ ] `npm test` green.
