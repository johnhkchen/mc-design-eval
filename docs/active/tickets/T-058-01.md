## Context (self-contained)

Epic **E-18**, the **speckle fix**. The glb-voxel build (voxelize a TRELLIS GLB) wins on form but its
**materials are speckled** — each voxel sampled the GLB texture independently → scattered blocks. E-17's
material-clean pass (`materialCleanVoxel`: extract a value-true palette from the texture via the E-10
CIE-Lab technique, snap each voxel, light neighborhood smoothing) **narrowed but did not eliminate** it.
Per-voxel snap + a weak smoother can't enforce *regional* coherence; an isolated off-color voxel survives
as a speck.

Replace it with **material-region segmentation**: group contiguous same-material voxels into regions
(region-grow / connected components by Lab ΔE in 3-D surface space) and fill each region with **one** block
(its dominant value-true block). Off-color singletons get absorbed. Optionally apply **E-11 material**
(`src/sculptor/material.mjs`: same-hue set varied by normal/height) *within* a region for deliberate
texture. Reuse E-10 (`src/color/cielab.mjs` `deltaE`/`nearestLab`, the block-Lab table).

## Acceptance Criteria

- [ ] `segmentMaterials(build, opts) → DesignArtifact`: region-grow over value-true voxels by Lab ΔE
      threshold → regions; per-region single-block fill (optional E-11 same-hue texture within a region);
      output passes the AJV gate (`src/artifact.mjs`).
- [ ] A **speckle metric** defined + computed (e.g. fraction of voxels whose block differs from its
      6/26-neighborhood majority, and/or distinct-block count), **before/after** per subject.
- [ ] Unit-tested on a **synthetic noisy voxel set** (salt-and-pepper colors → coherent regions; speckle
      metric drops; a single off-color voxel is absorbed). Pure, GL-free.
- [ ] Applied to **all 7** subjects → segmented builds + renders (`benchmarks/sculpture/glb-voxel-seg/
      <subject>/`); **speckle drops** on the noisy ones (heart, koi) with **form IoU not harmed**.
- [ ] `npm test` green.
