## Context (self-contained)

Epic **E-24**, terminal / Story **S-089**. The good cottage skin (77% plaster, cream) existed only because
an agent **hand-edited** the artifact; `npm run spray:paint` regenerates the bad 9%-splat version. **A result
the pipeline can't reproduce is not a result.** This ticket proves the epic: high-quality skins produced
**end-to-end by the pipeline**, reproducibly.

## Acceptance Criteria

- [ ] A **single named `npm run` script** produces each subject's skinned build **end-to-end**, composing
      zone-fill (T-085) → value-true blocks (T-086) → secondaries splat/LLM → coherent surface (T-087) →
      coverage-aware gate (T-088). **No inline/hand edits** anywhere in the path (Rule 1).
- [ ] **Reproducibility verified**: a **fresh re-run reproduces** the result (seeded/stable — Rule 2); state
      how determinism is achieved for any LLM-authored step.
- [ ] Applied to **cottage + gatehouse**: each zone's **dominant established full-coverage**, blocks
      **value-true** (cream not pink), surfaces **coherent**, **passing the coverage-aware gate** (T-088),
      any residual **named** (Rule 5).
- [ ] **Refreshed triptychs** + a **before/after** vs the E-23 splat-only skin, saved.
- [ ] `docs/knowledge/design-learnings.md` gains a **durable high-quality results (E-24)** section: the
      zone-fill-vs-splat lesson (splat can't establish a dominant — 9% vs 77%), value-true selection, the
      coverage-aware gate (catching "looks the same"), and the **durable rule** (the pipeline reproduces it,
      not the agent inline). Honest on over/under-reach.
- [ ] An **E-12 handoff** (`pr/assets/`); `npm test` green.
