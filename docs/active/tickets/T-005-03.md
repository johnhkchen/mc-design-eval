## Context

Epic E-03 / spec §7 (archetypes 2 + 3). A new named, versioned archetype — `iterative-multimodal.v1` — layered on the existing trial runner exactly as `single-shot.mjs` is. It is harness-orchestrated for determinism and attribution (results must be ascribable to the archetype, not wording drift):

1. **Round 0:** build the initial artifact from the base prompt (target = house, style = `neoclassical`, palette injected as the binding constraint — reusing `buildSingleShotPrompt`-style construction).
2. **Each round 1..N:** render the prior artifact to a WIP PNG (render tool, T-003-04), then call the multimodal seam (T-005-02) with that image plus a **revision instruction** — "here is a render of your current design; improve realism, proportion, depth, and neoclassical detail (columns, entablature, pediment, steps, window rhythm) while staying strictly in the palette; emit the COMPLETE revised artifact." Re-validate each emission.
3. Stop after N rounds (configurable, default 3) or on a no-op revision; the last artifact is final.

Every artifact stays schema-valid and in-palette. The number of rounds and the revision prompt are versioned (`.v1`) so trials are attributable. Per-round prompt construction and the round/stop bookkeeping are pure and unit-tested; the live loop (render + seam calls) is thin glue, not unit-tested (spec §4), mirroring `single-shot.mjs` / `smoke-trial.mjs`.

## Acceptance Criteria

- [ ] An `iterative-multimodal.v1` archetype module constructs the round-0 prompt and each round's revision prompt (pure, versioned, unit-tested), and exposes a live `runIterativeTrial(spec)` loop.
- [ ] The loop renders the current artifact and feeds the WIP image back via the T-005-02 seam each round, for a configurable number of rounds (default 3).
- [ ] Every round's artifact is re-validated (schema + palette-adherent); a malformed round fails loudly rather than logging a bad row.
- [ ] Each round is attributable to `iterative-multimodal.v1` in the artifact/trial metadata.
