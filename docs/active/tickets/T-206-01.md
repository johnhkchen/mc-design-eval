## Context (self-contained)

Epic **E-53** / Story **S-206**. The lead fix. The E-52 capstone (T-205) stalled at score 0 because **T-202
over-corrected** the form-readiness metric. Zero-spend seed probe (the smoking gun, same open-colonnade seed):

```
seed wall-band closure: 0.980          ← current eaveRingClosure (post-T-202 extent clamp)
close_shell ... closure 0.615 → 1.000  ← close_shell's internal measure of the SAME seed
```

T-202's `robustExtent` clamp (in `eaveRingClosure`, `src/view/wall-generate.mjs`) trimmed perimeter extremes to
ignore proud relief — but **also absorbed the colonnade's gaps**, so an open colonnade reads 0.980 = form-ready.
The form-before-detail gate never picks `close_shell` → detail runs on an open form → dark colonnade → judge
scores 0 / keeps all majors → stall.

Fix: measure closure on the **absolute program footprint** (`program.masses[].rect`). A footprint-perimeter
column with **no wall cell at the plane = open** (colonnade gaps read open); cells **proud of the footprint**
(relief) are **ignored** (relief doesn't crater it). Distinguish *missing inside the footprint* (open) from
*extra outside it* (fine) — T-202 conflated them.

## Falsifiable claim (anti-hedge — lead with how it fails)

The footprint metric reads the colonnade seed **~0.6 (< 0.9)**, a closed shell + proud relief **≥ 0.9**, a
genuinely-reopened shell **< 0.9**, and **agrees with `close_shell`'s internal measure** on the seed. **Fails
if:** the program footprint doesn't match the real wall plane on this seed (the `AMBIGUOUS` axis flag →
mis-read, deeper geometry problem); proud-vs-missing isn't cleanly separable (relief inside the plane / gaps at
the edge); or fixing the colonnade read re-craters the relief read (the two are coupled — name it).
