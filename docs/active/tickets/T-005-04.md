## Context

Epic E-03 / E-06, spec §10. The runnable, demonstrable deliverable: one command runs the `iterative-multimodal.v1` archetype building a **neoclassical** house end to end on the `claude -p` subscription path, and saves the **per-round WIP renders** so the improvement is visible round by round — this is the "watch it get better" artifact that answers the S-004 critique.

Mirror `scripts/run-trial.mjs`: write the trial under `trials/<trial_id>/` with `artifact.json` (final), `transcript.jsonl`, `trial.json`, and a render per round (`round-0.png`, `round-1.png`, …, plus the final `render.png`). Extend the trial record so it captures **per-round** token usage (input vs output — the iterative archetype's context grows turn over turn, spec §7/§9) and the list of round images. Print a summary (rounds, per-round tokens, total cost, final image path).

## Acceptance Criteria

- [ ] An `npm run` entry (e.g. `trial:iterative`) runs the neoclassical iterative trial end to end via `claude -p` and exits 0 on success.
- [ ] A WIP render is saved for each round (`round-N.png`) plus the final image, all under the trial store, and referenced from `trial.json`.
- [ ] `trial.json` records per-round token usage (input/output) and total cost, keyed by the §5 metadata `trial_id`.
- [ ] Running it produces a visibly more detailed, more coherent neoclassical building than the single-shot baseline (reviewed by eye against `trials/phase1-house-singleshot-demo/`).
