## Context (self-contained)

Epic **E-33** / Story S-137. The cottage never reached the judge (T-127): the per-view coverage
precondition failed it because **band1 has zero visible cells at the contract elevation** (eaves +
jetty occlusion). A census that fails a view on a band the camera **cannot see** is a
**measurement-identity bug** — fourth instance of the class (T-095 kit-renamed bands; T-101
dominant-only; T-110 literal-name). The discipline is established: monotone, both arithmetics,
committed records valid, thresholds/azimuths/judge unmoved.

## Acceptance Criteria

- [ ] **Visibility-aware per-view census** (pure, unit-tested): for each gate view, a band's
      denominator includes only cells **visible from that view** (reuse the existing per-view
      projection visibility); a band with zero visible cells is recorded `not-visible-from-view` and
      **excluded from that view's precondition** — it must still pass from every view that can see
      it (a synthetic test proves a band invisible from ALL views is a named failure, not a free
      pass).
- [ ] **The witness**: the T-127 cottage record re-censused — band1 excluded at the occluded
      view(s), censused where visible; the precondition no longer refuses on invisibility. (The
      judge is **not** called here — T-138-01 owns it.)
- [ ] **Identity-class discipline in full** (E-33 Rule 3): **monotone proof** as a unit test
      (committed records replayed — every previously passing view still passes); **both
      arithmetics** (visibility-aware + legacy) reported in new records; committed records untouched
      and still valid; no threshold/azimuth/judge-contract change (instrument-diff on any re-emitted
      record shows only the new census fields).
- [ ] No per-building constants; `npm test` green.
