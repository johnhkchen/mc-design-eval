## Context (self-contained)

Epic **E-48** / Story **S-188**. Run the first sustained **picture-driven climb** on the gatehouse: wire the
E-47 picture-anchored `DiagnoseBuild` (creation-loop critique, NOT the frozen instrument) as the workshop
loop's gradient — render → critique → revise → re-render — and discover where it stalls.

The machinery to reuse: the E-39 structured critique (department / expected / present / missing / kind) and
the E-43/T-176 critique→amplify loop. The two things to add: an **accept-gate** (a round is kept only if it
moves toward the concept on the picture-critique, never just because it changed) and a **restraint/stopping
rule** (T-176's amplitude loop overshot — hd3 glance-overruled to hd2; the climb must converge, not
oscillate).

## Falsifiable claim (anti-hedge — lead with how it fails)

≥3 rounds run and a clear **eyes-vs-hands inventory** results (what the critique named vs what the loop could
act on). **Fails if:** the loop can act on little of what's named (eyes-but-no-hands → S-189 scope is large);
it oscillates (restraint rule is the sub-problem); or the critique's verdicts are too coarse to steer (names
"roof wrong" but not *how* → the critique must emit a direction).
