## Context

Epic E-01, spec §5. Primitives (box / line / fill) keep large builds within token budgets, but downstream consumers — the schematic exporter (T-002-02) and the validators (E-04) — need explicit voxels. This ticket implements deterministic expansion of primitives into a normalized voxel set.

Expansion must be deterministic and order-independent, with a defined rule for resolving overlapping placements, so the same artifact always produces the same build.

## Acceptance Criteria

- [ ] Function expands box / line / fill primitives into explicit voxel placements.
- [ ] A mixed artifact (explicit voxels + primitives) normalizes to a single deduplicated voxel set.
- [ ] Expansion is deterministic and order-independent; overlapping placements resolve by a documented rule (e.g. last-writer-wins).
- [ ] Unit tests cover each primitive type and the overlap-resolution rule.
