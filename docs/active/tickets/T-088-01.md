## Context (self-contained)

Epic **E-24** / Story **S-088**. The per-face gate **accepted** the cottage skin on a marginal `0.25→0.40`
while the upper-storey wall was **91% un-plastered** — a number rubber-stamped an un-skinned surface (the
recurring fooled-gate failure, [[render-aliasing-not-material-speckle]]). The gate scored *something* but
not "is the intended dominant actually applied?".

## Acceptance Criteria

- [ ] A **per-zone dominant-coverage metric** (pure, unit-tested): the fraction of a zone's wall-field
      surface covered by the **intended** dominant material (from the E-21 map). 
- [ ] A **gate precondition**: if any zone's dominant coverage is **below threshold**, the face/skin
      **FAILS** — regardless of the marginal resemblance delta. Coverage is a **precondition**, not a
      tie-breaker (resemblance refines a skin that already has its base coat; it cannot substitute for one).
- [ ] **Proof both ways**: the gate **rejects** the E-23 9%-splat cottage skin (under-applied) and
      **passes** the zone-filled ≈77% one — recorded.
- [ ] Wired into the per-face / resemblance gate (E-22) ahead of the hill-climb count; pure metric + gate
      logic unit-tested; `npm test` green.
