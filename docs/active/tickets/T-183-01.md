## Context (self-contained)

Epic **E-46** / Story **S-183**. Build the corpus substrate: ≥8–10 styled build states (multi-subject:
gatehouse, cottage, barn, …) with a factorial that **decouples PACK from CONCEPT IMAGE** so the T-182-01 pack
confound is testable (E-46 background). Must include the **crux cells** (match / same-pack-wrong-picture /
wrong-pack-right-picture / cross) and the **hard middle** (partially-faithful states — one wrong material,
slightly-off proportions, missing dressing).

The harness `experiments/eval-alignment/corpus-referee.mjs` already takes (build, pack, concept) via env
(`CRATER_BUILD`, and the pack/concept conditions) — the corpus is a manifest of such triples + their renders,
not new scoring code. Reuse existing builds as match cells (`builds/gatehouse/faithful-covered`, cottage,
barn); the work is the decoupled cells (same build, swapped pack/concept) and the partially-faithful middle.

## Falsifiable claim (anti-hedge — lead with how it fails)

Every crux cell is constructible and the manifest lets S-184 measure pack-effect and concept-image-effect
separately. **Fails if:** the same-pack/wrong-picture cells can't be built (recognition always re-derives a
matching pack → pack/concept inseparable by construction — the structural-confound finding, report it); or the
"hard middle" states render as obviously-good or obviously-bad (not contestable → the corpus can't embarrass
the term — inspect each on the render before trusting its intended label).

## Acceptance Criteria

- [ ] ≥8–10 states across ≥3 subjects, including all four crux cell types and ≥2 partially-faithful
      hard-middle states; generated **by replay** (reproducible).
- [ ] A manifest (`experiments/eval-alignment/corpus/manifest.json` or sibling) recording per state: build
      dir, pack, concept, intended faithfulness, cell type.
- [ ] Each state **rendered beside its scored concept**; the hard-middle states inspected on the render and
      confirmed genuinely contestable (not obvious).
- [ ] **Recorded honestly:** which crux cells were constructible; any the pipeline refuses (and why).
- [ ] `npm test` green; nothing under `measurements/` touched.
