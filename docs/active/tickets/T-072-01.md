## Context (self-contained)

Epic **E-21**. The LLM material map (T-071-01) names materials by intent + placement; this ticket
**assigns those blocks to voxels by geometric feature** (no SAM) so near-tone-distinct materials land
where the artist put them — brick on walls, cobble on corners — which mean color can never separate.

Most architectural material zoning follows form, so a pure geometric classifier suffices: **flat-face**,
**edge-corner** (convex verticals / few-neighbor cells), **top-roof** (upward-facing / highest band),
**base** (lowest band), **opening-recess** (inset). Classify each cell, place the map's block for its
feature; keep the colorimetric matcher (E-14 `nearestLab`) for within-material value + as the fallback
when the map is silent for a cell.

## Acceptance Criteria

- [ ] `classifyFeatures(occupancy) → Map<cell, feature>` over `{flat-face, edge-corner, top-roof, base,
      opening-recess}` — pure geometry, deterministic, GL-free.
- [ ] Unit-tested on a synthetic mass (a cube/house prism): corners→edge-corner, top→top-roof, lowest
      layer→base, broad faces→flat-face, an inset→opening-recess.
- [ ] An assigner places each feature's block from the T-071 map; the colorimetric matcher remains for
      within-material value + silent-map fallback. Output passes the AJV gate.
- [ ] Applied to the **gatehouse**: corners/buttresses = **cobblestone**, walls = **stone_bricks** (the
      collapsed distinction **restored** — verified in the manifest + render); brick≠cobble by feature,
      not color.
- [ ] `npm test` green.
