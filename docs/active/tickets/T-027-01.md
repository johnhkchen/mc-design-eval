## Context

Epic E-11 / story S-027. Seed craft pass A, a `stage(state, intent) → state` over the **locked massing**.
For each region/surface: pick a **hue-family set** of 2–3 real blocks (use the E-10 engine to find the
nearest block *and its near neighbours* in Lab) and assign cells from that set with a noise pattern, so the
surface reads as textured/aged rather than one flat ID. **Vary the set or mix ratio across height** (top
vs bottom) so banding reads as light break. Writes `material`; locks it. The target palette comes from the
design's manifest / the E-10 extracted palette (via `intent`).

NOT Floyd–Steinberg color dithering — this is same-hue material *noise* for texture (the run-015 effect),
default the variation modest so color fields stay clean.

## Acceptance Criteria

- [ ] A material-noise stage assigns each surface a 2–3 block same-hue set (via the E-10 engine) with a
      noise mix, varied across height; writes `material`, locks it; leaves `occupied` (locked) untouched.
- [ ] **Tested:** on a fixture massing, output materials are all from the intended hue-family set + the
      manifest (no out-of-palette blocks); height variation is present (top/bottom differ); the massing
      lock is not violated.
- [ ] Composes through the orchestrator after massing; compiles to a `DesignArtifact` that passes AJV.
- [ ] `npm test` green.
