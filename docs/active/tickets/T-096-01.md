## Context (self-contained)

Epic **E-26** / Story S-096. The cottage concept
(`benchmarks/sculpture/runs/014-vConcept-a-cottage/concept.png`) visibly depicts **smooth sandstone**
panels, **stripped logs**, planks, **trapdoor shutters**, and **fence-infilled windows** — but the E-21
material map (`benchmarks/sculpture/material-map/cottage.json`) holds 7 full-cube *color-role guesses*
(`white_terracotta` for the sandstone panels — renders pink) with 4 coarse placement rules. The map's
rationales prove the LLM **saw** the materials ("warm, matte CREAM", "heavy round structural timbers");
the contract just never asked *"which Minecraft block is this?"* — though the concept is voxel art
depicting nameable blocks. **Recognize, don't match** (E-26 Rule 1).

## Acceptance Criteria

- [ ] A **kit schema + extractor**: the multimodal LLM (strong tier via the `claude -p` subscription
      shim — never the metered API) enumerates the concept's depicted ingredients as
      `{block, role, formClass: cube|fixture|rail, whereUsed, confidence}`; block IDs validated against
      the `minecraft-data` vocabulary; output saved as a **reviewable kit artifact** beside the concept
      (a human can check it line by line against the picture).
- [ ] **Value verification**: each recognized cube block's render swatch checked against the concept
      region in CIE-Lab (reuse `src/color/block-table.mjs`); a mismatch **flags the entry for review** —
      it must NOT silently fall back to color-snap. Surfaces the extractor declares unidentifiable get
      color-snap as the **recorded** fallback.
- [ ] **Builds on the T-092 band profile** (one concept-reading seam): the kit references the same bands;
      it does not re-derive them. The zone map's `dominantRole → block` resolution consumes the kit when
      an entry covers that band (recognition beats snap).
- [ ] **Cottage proof**: the extracted kit names the ingredients a viewer sees — smooth sandstone (or the
      LLM's recognition, recorded with rationale if it differs), stripped logs, planks, trapdoors,
      fences — diffed against the old 7-role map (the `white_terracotta` correction visible).
- [ ] **Gatehouse kit** extracted through the same untuned path (zero subject-specific code — E-25
      Rule 3); extraction is seeded/pinned for stable re-runs (E-24 Rule 2); `npm test` green.
