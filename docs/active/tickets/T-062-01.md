## Context (self-contained)

Epic **E-19** regains text→JSON's clean color/material on the GLB-voxel build. The fixes hill-climb on
metrics — but two are inadequate; fix the scoreboard first (gates the epic).
- **No stray-voxel measure:** TRELLIS leaves floating islands + (moai) duplicate masses & hallucinated
  connectors (≥3 connected components). Nothing counts it.
- **`speckleScore` lies** (`src/form/material-clean.mjs`, T-058-01 review concern #4): it counts EVERY
  face-adjacent differing-block pair, so an *intentional* region boundary reads as "speckle" and it
  rewards "paint it all one block." It can't tell fragmentation (bad) from a clean boundary (good).

## Acceptance Criteria

- [ ] A **stray-voxel / disconnected-component metric** over the occupancy's face-adjacency: component
      count + **largest-component fraction** (1.0 = single solid mass) + count of cells in sub-floor
      islands. Pure, in `src/form/`.
- [ ] **`speckleScore` fixed** to measure *fragmentation*, not all boundaries: a speck = a cell whose block
      differs from a strong neighborhood majority (or an isolated singleton), so a large clean region with
      a sharp edge to a neighbor region scores **≈0**. Old call sites keep working (same signature/shape).
- [ ] Unit tests: a 2-region clean block → speckle ≈ 0 (NOT penalized for the boundary); a checkerboard →
      high; a single floating island → counted as stray (largest-fraction < 1); a solid mass → fraction 1.
- [ ] The **E-18 builds re-scored** on the fixed metrics and recorded as the before-baseline
      (`benchmarks/sculpture/cleanliness-baseline.{md,json}`).
- [ ] `npm test` green.
