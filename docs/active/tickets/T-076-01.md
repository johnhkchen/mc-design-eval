## Context (self-contained)

Epic **E-22** / Story **S-076**. The goal: the Minecraft build **looks like its references** (the concept
image + a render of the GLB mesh). The old sign-off used proxy metrics (`speckle`, `distinct`, `IoU`,
`valueDeltaE`) that read perfect on a build that looked like static — the wrong target. This ticket builds
the gate that measures the real goal: visual resemblance to the fixed references.

**Rules of engagement (E-22, binding):** the references (concept image, GLB) are **immutable** inputs — do
not regenerate or swap them (Rule 1); the **triptych is the verdict a human inspects**, proxy scores only
explain it (Rule 2); the judge prompt + thresholds are fixed (Rule 5); reproduce before claiming (Rule 6).

## Acceptance Criteria

- [ ] A **triptych assembler**: render the **concept image**, the **GLB mesh**, and the **Minecraft build**
      at one shared view (`BUILDING_VIEW_3Q`, the fixed lens from T-075-01) into a single side-by-side PNG
      `concept | mesh | minecraft`. Saved per subject (`benchmarks/.../resemblance/<subj>-triptych.png`).
- [ ] A **perceptual resemblance scorer (pure, GL-free, unit-tested)**: silhouette **form** IoU (reuse
      `extractSilhouette` / `rasterizeSilhouette` / `iou`) + a **palette/material-agreement** score (do the
      build's dominant block colors, via `block-table.mjs` Lab, land where the concept/mesh place those
      materials?). Returns a structured row; **diagnostic, not the verdict** (Rule 2).
- [ ] A **categorical multimodal judge** (metered `claude -p`): sees all three images → rules
      `same object | drifted | different object` + a **named gap** (region + attribute: form / massing /
      material zoning / palette) when not "same object". Parse/validate logic unit-tested; the live call is
      metered.
- [ ] Run on the **gatehouse**: save the triptych, the perceptual row, the verdict, and the named gap. If
      the verdict is "drifted/different", the gap is **named, not hidden** (Rule 7).
- [ ] The gate is **reusable** (a function/runner S-077 calls per subject), references passed as immutable
      inputs (Rule 1), thresholds fixed (Rule 5).
- [ ] `npm test` green.
