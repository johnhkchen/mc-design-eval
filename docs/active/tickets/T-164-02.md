## Context (self-contained)

Epic **E-39** / Story **S-164**. Layer B — the unified "what to do" router. A BAML function
`RouteCritique(Critique) → [{department, idiom, why}]` that maps each item to a construction department and
a concrete idiom-registry entry via the `departmentToIdioms` seam (T-163-01). Then **wire diagnose→route
into the creation loop**, replacing the fused `WorkshopReply` action path — keeping the fused path behind a
flag for the S-166 bake-off.

## Falsifiable claim (anti-hedge — lead with how it fails)

The router selects, for the worst critique item, a department/idiom that actually addresses it at least as
often as the fused judge picked the right tool. **Fails if:** Layer B just echoes Layer A's department with
no resolution value (the split is unjustified — flag for collapse in S-166), or it routes to an idiom that
can't fix the item (the registry lacks the tool — that gap is a generator-epic finding).

## Acceptance Criteria

- [ ] `RouteCritique` BAML fn → dispatch list; every item resolves to a real idiom-registry entry (never an
      unbuildable department); `b.parse` fixture-tested.
- [ ] Creation loop runs on **diagnose→route**, replacing the fused action path; fused path retained behind
      a flag (do not delete — S-166 needs it).
- [ ] One loop run rendered beside concept (judge-free smoke witness); the dispatch trace is logged so the
      bake-off can score routing correctness.
- [ ] `npm test` green; frozen instrument + transport-guard untouched.
