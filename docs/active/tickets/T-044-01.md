## Context (self-contained)

Epic **E-15** revises a finished build **one section at a time**, bounded so it converges and **locked so
it can never regress what already worked** (the project's P14 rule: a blanket whole-build "improve" once
regressed by detaching masses; the cure is additive, bounded change). E-11 enforced this **per-field** on
a facade build-state (`src/sculptor/build-state.mjs`: writing a LOCKED field throws `LockViolationError`).
This ticket builds the same guarantee **per-region** on the compiled `DesignArtifact` (the shared JSON of
voxel placements both facade and 3-D sculpture builds produce), so the loop reaches the 3-D sculptures and
a future GLB form-target can plug in at the artifact level.

Two primitives, no control flow yet: **(1)** region addressing + a **region-lock** (freeze all placements
outside region R; permit/validate edits only inside R), and **(2)** **observe a section** — a tight crop
render of R. The camera already frames an arbitrary voxel bounds (`render/src/camera.mjs`
`framedCamera(bounds, view)`, `boxOf`, `boundingSphere`), so observing R is `framedCamera(subBoundsOf(R))`
— no new camera math.

## Acceptance Criteria

- [ ] `selectRegion(artifact, spec) → R` where `spec` is a **bbox**, a **named part**, or a critic
      `where` string; R carries the in-region placement set + its integer sub-bounds.
- [ ] A **region-lock**: `applyRegionEdit(artifact, R, edit)` mutates only in-R placements and **rejects**
      any edit that adds/removes/moves a placement outside R (the spatial generalization of E-11's
      field-lock); the result still passes the AJV gate (`src/artifact.mjs`).
- [ ] `observeRegion(artifact, R) → png` — a tight crop render via `framedCamera(subBoundsOf(R))`.
- [ ] Unit tests: sub-bounds math; the lock rejects an out-of-R edit and permits an in-R one; round-trip
      stays schema-valid. One **live** crop render on a committed sculpture
      (`benchmarks/sculpture/runs/009-*-koi-fish`) proves the observe path (GL-gated, isolated like E-11's
      review seam so the pure tests load no GL).
- [ ] `npm test` green.
