## Context (self-contained)

Epic **E-29** / Story S-112. The E-28 per-component roof fit (T-110-01) accepted the church **nave** but
took a named fallback on the **tower**: *"insane gable — a pyramidal cap is not a ridge pair"*
(`benchmarks/sculpture/roof/church.json`). The construction vocabulary (E-27 roof program + shaped
vocabulary) generates gable slopes, ridges, verges, arches — but **no hip end and no pyramidal cap**:
any tower, hip-roofed mass, or pavilion is unfittable by construction. Both the repair path and
generate-first (T-115-01) need the complete roof family. Sequenced after T-111-01 (the closure
milestone owns the judge runs in flight; this ticket edits the roof cores it re-runs).
