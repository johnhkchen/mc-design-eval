## Context (self-contained)

Epic **E-15**, terminal. The surgical revision loop now exists end-to-end: a form-fidelity metric
(silhouette IoU, T-043-01), a region-lock + section-observe (T-044-01), the proven deterministic loop +
accept-gate (T-045-01), and the LLM form-edit route behind it (T-046-01). Two things close the epic.

**(1) The GLB seam (interface only, not the GLB).** A standing project intention: *down the line* an
image→3D tool (TRELLIS → GLB mesh, deferred in E-09) supplies a **better form target** for "is this region
the right shape." The loop's accept step must already consult a **form-target interface** so that target
swaps in later with **no change** to observe/diagnose/accept. Today the target is derived from the concept
image / occupancy heuristics; build the interface + a documented GLB adapter point — do **not** implement
GLB/TRELLIS here.

**(2) The honest demo + number** (mirroring the E-14 value-true consolidation: a measured before/after, the
residual shown not hidden).
