## Context (self-contained)

Epic **E-19**, the color/material cleanliness core — "regain the text→JSON cleanliness." text→JSON reads
clean because it uses a few **flat solid blocks** (concrete/terracotta/wool) in coherent regions. The
GLB-voxel build is busier for three documented reasons:
1. **Texture-busy blocks pollute the palette** — `src/color/block-table.mjs` `meanOpaqueRgb` scores blocks
   by MEAN color, so high-variance blocks (`dead_brain_coral_block`, `nether_quartz_ore`, `mycelium`) win a
   mean-ΔE fit but add visual noise (E-18 finding; visible on the heart's secondary patch).
2. **Gradients scatter on non-cardinal axes** — `material-segment.mjs` `gradientAxis` bands along a cardinal
   i/j/k axis; a diagonal gradient (rounded organic surfaces) fragments (T-058-01 concern #3).
3. **`minRegion` eats legitimate detail** — the 12-cell speck-absorb removes real small features (mushroom
   cap spots) with the noise (T-058-01 concern #1).

## Acceptance Criteria

- [ ] **Texture-variance-aware palette:** compute each candidate block's texture variance (from the
      committed `minecraft-assets` textures) and **prefer flat blocks** — exclude/penalize busy ones from
      BOTH the design-doc snap (`paletteFromManifest` consumers) AND the gated secondary
      (`palette-augment.mjs`). A busy block must lose to a flat block of comparable mean ΔE.
- [ ] **PCA / true-axis gradient banding:** `gradientAxis`/`bandRegion` band along the region's actual
      gradient direction (principal axis), so a diagonal gradient bands monotonically instead of scattering.
- [ ] **`minRegion` retune** (or a noise-vs-intent rule): absorbs isolated specks without eating a
      legitimate small region (mushroom spots survive).
- [ ] Unit tests: a busy block loses to a flat block at equal mean ΔE; a diagonal-gradient region bands
      monotonically (≤2 blocks across the transition, ordered); a legitimate small region is NOT absorbed.
- [ ] Applied ×7: the **fixed speckle metric (T-062) drops**, the **palette stays flat-block** (no busy
      blocks in any manifest), form IoU not harmed; before/after recorded. `npm test` green.
