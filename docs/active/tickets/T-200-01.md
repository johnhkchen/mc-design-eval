## Context (self-contained)

Epic **E-49** / Story **S-200**. The T-198 form stage decided "tie" on the **picture scalar**, which has a
documented **0–76 swing on the same seed** (round 0 = 0 in one run, 16 in another; VOTES=3 median dampens, not
removes). So a `close_shell` "tie" may be **vote noise**. Make the form decision ride a **clean deterministic
signal** so the S-199 form-credit is given on truth, not noise.

Two items (both runner-side, `experiments/eval-alignment/`):

1. **Form decision on closureOf.** A FORM move (`close_shell`, `construct_walls` when it changes closure) is
   judged on **closureOf** (T-197's `eaveRingClosure`, deterministic) — not the noisy picture vote. The
   **detail-stage** picture gradient is **unchanged** (it's the right gradient there). Separate the two so
   noise in the picture vote can't corrupt the form decision.
2. **Port the `agentPick` parse hardening.** T-198 found a latent crash: the naive `parse` crashes on any
   two-object LLM reply; fixed in `picture-climb.mjs` with a balanced-brace parse + re-ask-once-then-`done`
   fallback. `autonomy-loop.mjs` shares the idiom and the latent crash — port it.

## Falsifiable claim (anti-hedge — lead with how it fails)

Deciding form moves on closureOf makes the form decision **stable across re-runs** (the close_shell keep no
longer flips with vote noise), and the ported parse survives a two-object reply. **Fails if:** closureOf is too
coarse for some real form gain (a gain it can't see → name it, propose a richer signal, don't fake it);
separating the signals changes a **detail**-stage decision (scope leak — detail gradient must be byte-stable);
or the parse port regresses an `autonomy-loop.mjs` fixture.
