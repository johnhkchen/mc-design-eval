## Context (self-contained)

Epic **E-15** builds a surgical revision loop that **hill-climbs**: it keeps a tweak only if a form number
went up. Color already had such a number (E-14's concept↔render Δvalue gate); **form does not**. This
ticket builds it, and it gates the whole epic — without it the loop is unmeasured opinion.

The signal exists in every `vConcept` build: a matched 3/4 pair `render-3q.png` (the built voxels) and
`concept.png` (the Nano-Banana reference), both **background-segmentable** (concept on solid black
`#000000`; render on a flat sky). A **silhouette IoU** of the two binary masks is a real form-fidelity
number. The loop also needs a **per-region** IoU (over a sub-bounding-box) for a *local* accept signal.
Mirror the E-14 metric module shape (`src/color/value-gate.mjs`): small, pure-where-possible, unit-tested,
with an honest note on what it can't see.

## Acceptance Criteria

- [ ] A `formFidelity` module (e.g. `src/form/form-fidelity.mjs`): extract a build-render silhouette + a
      concept silhouette (background-segment each), normalize/align, and compute **whole-object IoU** and
      **IoU over an arbitrary region** (sub-bounding-box). Deterministic.
- [ ] Unit tests on the **committed** E-13 pairs (`benchmarks/sculpture/runs/*/render-3q.png` +
      `concept.png`): IoU is in [0,1], identical-mask IoU = 1, disjoint = 0, region IoU restricts to its
      box; segmentation handles both backgrounds (black concept, sky render).
- [ ] A **baseline IoU recorded per E-13 subject** (the "before" the rest of E-15 improves on), saved as a
      small committed artifact (e.g. `benchmarks/sculpture/form-baseline.{md,json}`).
- [ ] An honest **limits** note (alignment/scale assumptions; that a single 3/4 view can't see the back —
      consistent with the single-view reconstruction limit), mirroring the E-14 gate's self-critique.
- [ ] `npm test` green.
