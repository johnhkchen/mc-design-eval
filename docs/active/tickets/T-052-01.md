## Context (self-contained)

Epic **E-16**, the **synthesis** — the capability the whole arc points at: *the voxelizer supplies the
3-D form, surgical region tweaks polish it against its own 3-D source.* Two pieces now exist: the
**GLB-voxel build** (T-051-01 — a `DesignArtifact` with a real 3-D starting form but voxelization
artifacts: stair-stepping, a thick fin, an almost-closed arch) and the **E-15 surgical loop with a GLB
form target** (T-049-01 `glbFormTarget`). The loop observes a region → diagnoses → tweaks (procedural pass
*or* LLM block-edit) → re-observes → **accepts only if per-region IoU vs the GLB improved** (else rolls
back; locks accepted regions — P14-safe). Unlike the flat-concept run, the loop now has an honest
per-region 3-D signal *and* a starting form that's already close — the conditions for a local edit to earn
its place.

## Acceptance Criteria

- [ ] The E-15 `reviseLoop` runs on the **T-051-01 GLB-voxel** koi + heart builds with `formTarget:
      glbFormTarget({ glbPath })` (T-049-01).
- [ ] For each subject: the **per-region tweak trace** (regions, procedural vs LLM-edit, kept vs
      rolled-back), **before/after form IoU vs the GLB**, and the **judge** categorical — saved
      (`benchmarks/sculpture/glb-voxel-surgical/<subj>/` + an A/B summary).
- [ ] P14-safety holds (no accepted region later altered; non-improving tweaks rolled back).
- [ ] Honest: whether surgical tweaks cleaned voxelization artifacts / raised fidelity, and where they
      didn't (kept-vs-rolled-back counts shown). `npm test` green.
