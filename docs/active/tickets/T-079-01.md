## Context (self-contained)

Epic **E-23** / Story **S-079** — the **judgement path** (craft). The cottage face failed: the E-21
material map was correct (`white_terracotta` plaster + `dark_oak_log` timber over a `stone_bricks` base) but
the feature placer collapsed plaster into stone (**215 → 8** plaster blocks; walls 78–88% stone) because
both carry `placementRule: "walls"` and 3-D feature space has no storey axis. On a painted wall, "the upper
band is plaster" is a horizontal stripe.

## Acceptance Criteria

- [ ] A **face-paint tool**: project a face to the 2.5-D grid (T-078-01) and present the **build face beside
      the concept's same face**; the LLM paints materials onto the build face.
- [ ] A **splat path** (reuse the facade-grid technique, `src/color/image-grid.mjs` `gridFromImage`):
      render the **textured GLB / concept at the SAME angle** as the projected face, grid-quantize it to the
      face cell-grid, and **splat** the per-cell material target onto the face as the auto-paint — then the
      LLM **refines/judges** rather than placing every cell. (Concept splat for the front where it's the
      truth; textured-GLB splat for sides/roof the concept never shows.)
- [ ] **Enforced palette (the "4 cans")**: the tool exposes **only** the design-doc manifest ∪ E-21
      concept-justified additions — off-palette paint is structurally impossible (kills the 91-block bloat
      by construction). A concept material the build is missing may be **added back** (E-21's
      concept-justified-growth right).
- [ ] **Back-projection** (ortho/45° only): paint lands on the front-most surface voxel; a corner voxel
      visible from two faces takes the concept-matching paint; occluded interior keeps the colorimetric
      fallback. Unit-tested.
- [ ] **Per-face accept-if-closer** vs the concept face (the E-22 resemblance gate, per face; P14-safe — a
      paint that doesn't move the face toward the concept rolls back).
- [ ] Run on the cottage **front + one side**: record the **plaster band restored** (white_terracotta count
      recovers) and the **per-face resemblance before/after**. The 215→8 regression reversed.
- [ ] Pure projection/back-projection/palette-enforcement unit-tested; the paint judgement is the metered
      call; `npm test` green.
