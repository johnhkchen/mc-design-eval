## Context (self-contained)

Epic **E-15**'s payoff. The measured **form** gap (E-13): text→JSON keeps palette + parts but loses
*line* — a **koi's swimming S-curve** flattens to a straight body; an **anatomical heart's aortic arch
never builds as a loop**. No procedural pass encodes *form* (E-11's passes do material/depth, not shape),
so the loop needs a **freeform LLM block-edit** primitive.

The loop's **cage is already built and proven** (T-045-01): observe→tweak→re-observe→**accept-if-improved**
converges, locks accepted regions, blocks out-of-region bleed, and **rolls back any tweak that doesn't
raise the form IoU** (T-043-01). This ticket adds the LLM editor as *just another editor behind that same
gate* — and adding it must require **no change to the loop's control flow** (if it does, the cage
abstraction was wrong). The model owns *what shape change*; the cage owns *whether it's kept*.

## Acceptance Criteria

- [ ] An **LLM form-edit route**: `observeRegion` crop → the model returns a **bounded edit** (`add` /
      `remove` / `move` / `swap` of placements **within region R only**) via the structured-output seam
      (`src/sdk-binding.mjs`) + a new BAML edit function (sibling of the build/judge fns); applied under
      the T-044-01 region-lock (out-of-R rejected, AJV-revalidated) and **kept only if per-region IoU
      improved**, else rolled back. `claude -p` subscription seam unchanged.
- [ ] The E-11 critic **routes form defects to this editor** and known defects to the procedural passes —
      one router, two interchangeable editors behind the **same** accept-gate.
- [ ] **No change to the S-045 loop control flow** to add this (demonstrated — the LLM editor implements the
      existing tweak interface).
- [ ] **A/B on koi (`runs/009-*-koi-fish`) + heart (`runs/006-*-human-heart`)**: before/after per-region
      form IoU + the kept/rolled-back edit trace; renders saved.
- [ ] Pure edit-application/bounds logic unit-tested (the live model call is metered/GL-gated); `npm test`
      green.
