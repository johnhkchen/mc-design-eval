## Context

Epic E-03 / spec §6, §7. The iterative archetype (T-005-03) needs a detail-bearing style to show off. This ticket adds the **neoclassical** style: a palette (JSON whitelist, the same format and tooling as `palettes/industrial.json`) and a `STYLE_BRIEFS["neoclassical"]` entry in `src/briefs.mjs`.

The palette must be pinned to **1.20.1** (the instrument-wide version pin) and validate with `node palettes/validate.mjs` (all blocks survival-obtainable). Choose materials that support neoclassical form: smooth/chiseled quartz (`quartz_block`, `quartz_pillar`, `chiseled_quartz_block`, `smooth_quartz`, `quartz_stairs`, `quartz_slab`), `smooth_stone`, `stone_bricks` + `chiseled_stone_bricks` + stairs/slab/wall, polished diorite/andesite/granite, white & light-gray concrete, stone stairs/slabs/walls (for columns, steps, cornices, balustrades), glass panes, and warm lighting (`sea_lantern`, `glowstone`, `lantern`). All must exist and be obtainable in 1.20.1.

The style brief should explicitly call for neoclassical features — symmetry, a columned portico, entablature/cornice, a pediment, a raised stepped base/stylobate, tall windows — and encourage detail and scale rather than a plain box, so the archetype has something to refine.

## Acceptance Criteria

- [ ] `palettes/neoclassical.json` exists in the palette format, `minecraftVersion: "1.20.1"`, and passes `node palettes/validate.mjs palettes/neoclassical.json` (all blocks valid & survival-obtainable).
- [ ] The palette's materials are coherent for neoclassical architecture (light stone/quartz structure, columns, trim, glazing, lighting).
- [ ] `STYLE_BRIEFS["neoclassical"]` is added in `src/briefs.mjs` with a brief that names the defining features (symmetry, columns/portico, entablature, pediment, stepped base) and pushes for architectural detail.
- [ ] Existing palette/brief unit tests still pass, with coverage that the neoclassical palette loads and the style brief is present.
