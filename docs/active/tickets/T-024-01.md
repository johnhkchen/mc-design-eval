## Context

Epic E-11 / story S-024. The framework spine. Implement:

- **Build state** — a structure carrying, per cell (and ready to extend to per-voxel): `occupied`
  (massing), `material` (block id / hue-set member), `relief` (Z-depth), and a per-stage **lock** record.
- **Stage interface** — `stage(buildState, intent) → buildState`, a pure transform. `intent` is the
  LLM/plan side-channel (focal hierarchy, palette-mood) a stage may read.
- **Orchestrator** — runs an ordered list of stages, **locking** each stage's contributions on accept so a
  later stage cannot mutate a locked field (only add within bounds). A stage attempting to write a locked
  field is rejected (the P14 destructive-revision cure, enforced structurally).
- **Compile** — `toDesignArtifact(buildState)` producing a valid artifact (placements with Z from relief)
  that passes the existing AJV gate, so render/judge/export are unchanged.

## Acceptance Criteria

- [ ] Build-state model + `stage` interface + orchestrator + lock semantics implemented (e.g. under
      `src/sculptor/`).
- [ ] **Lock enforcement is tested:** a stage that tries to overwrite a locked field is rejected; a stage
      that only adds to unlocked fields succeeds.
- [ ] `toDesignArtifact` compiles a build state to an artifact that **passes the AJV validator**; round-trip
      tested on a small hand-built state.
- [ ] Two trivial no-op/identity stages compose through the orchestrator (proving the interface) with
      independent lock records.
- [ ] `npm test` green.
