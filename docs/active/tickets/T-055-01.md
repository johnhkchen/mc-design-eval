## Context (self-contained)

Epic **E-17**'s one new build technique — rung **R2**, and the loose end E-16 left. The E-16/T-054-01
**GLB-voxel build** wins on *form* but its color is **speckled**: each voxel sampled the TRELLIS texture
independently, so adjacent cells get scattered colors — the right *shape*, a busy/dirty *surface*, and
silhouette IoU can't see it. This ticket builds the **material-clean pass** to turn that noise into clean
material regions, reusing proven pieces:
- **cluster** the voxel colors into a small palette — `src/color/palette-extract.mjs` `medianCutLab`;
- **snap** each cluster to a **value-true block** — E-14, `src/color/cielab.mjs` `nearestLab` + the
  block-Lab table (`block-table.mjs` `loadBlockTable`);
- **spatial-denoise** — a voxel takes its neighborhood's dominant block — and optionally apply **E-11
  material texture** (`src/sculptor/material.mjs`: same-hue set, height-varied) so surfaces read as
  *deliberate texture*, not noise.

## Acceptance Criteria

- [ ] `materialCleanVoxel(build, opts) → DesignArtifact`: cluster + value-true-snap + spatial-denoise
      (+ optional E-11 material texture); output passes the AJV gate (`src/artifact.mjs`).
- [ ] Unit-tested on **synthetic noisy color** (a block of randomized per-cell colors → a small clean
      palette of value-true blocks; neighborhood denoise reduces distinct-block count). Pure, GL-free.
- [ ] Applied to **all 8** T-054-01 R1 builds → R2 builds + renders (`benchmarks/sculpture/glb-voxel-clean/
      <subject>/`); **before/after noise drop** recorded per subject (value ΔE and/or distinct-block count
      down; form IoU steady — clean must not break the shape).
- [ ] `npm test` green.
