## Context (self-contained)

Epic **E-17**'s one new build technique — rung **R2**, and the loose end E-16 left. The E-16/T-054-01
**GLB-voxel build** wins on *form* but its color is **speckled**: each voxel sampled the TRELLIS texture
independently, so adjacent cells get scattered colors — the right *shape*, a busy/dirty *surface*, and
silhouette IoU can't see it. This ticket builds the **material-clean pass**. The key technique (a
directive): the GLB carries a real **surface texture** (the glTF baseColor image — E-16 already reads it
via `parseGlbColoredSurface`, incl. the `EXT_texture_webp` path), so **ground the voxel materials in a
canonical palette extracted from that texture with the E-10 CIE-Lab palette technique** — not by
clustering the already-sampled (noisy) per-voxel colors, which is what produced the speckle. Steps:
- **Extract a canonical material palette from the GLB texture image** — the E-10 palette technique
  (`src/color/palette-extract.mjs` `extractPaletteFromImage` / `medianCutLab` / `describePalette` /
  `resolvePalette`) run on the baseColor texture → a small set of **value-true blocks** (E-14,
  `src/color/cielab.mjs` `nearestLab` + the block-Lab table `block-table.mjs` `loadBlockTable`). This is
  the same "which real blocks are in this picture" technique E-10 built for facades, now applied to the
  GLB skin.
- **Assign each voxel** by sampling the texture at its surface point (the `parseGlbColoredSurface` UV path)
  and snapping to the **nearest block within that canonical palette** — so the whole build draws from one
  coherent, value-true material set instead of per-voxel noise.
- **Spatial-denoise** — a voxel takes its neighborhood's dominant block — and optionally apply **E-11
  material texture** (`src/sculptor/material.mjs`: same-hue set, height-varied) so surfaces read as
  *deliberate texture*, not noise.

## Acceptance Criteria

- [ ] The canonical material palette is **extracted from the GLB's baseColor texture** via the E-10
      CIE-Lab palette technique (`extractPaletteFromImage` / `medianCutLab` → value-true blocks) — the
      palette is texture-derived, NOT clustered from the noisy per-voxel samples.
- [ ] `materialCleanVoxel(build, opts) → DesignArtifact`: texture-palette extract + per-voxel snap to that
      palette + spatial-denoise (+ optional E-11 material texture); output passes the AJV gate
      (`src/artifact.mjs`).
- [ ] Unit-tested on **synthetic noisy color** (a block of randomized per-cell colors → a small clean
      palette of value-true blocks; neighborhood denoise reduces distinct-block count). Pure, GL-free.
- [ ] Applied to **all 7** T-054-01 R1 builds → R2 builds + renders (`benchmarks/sculpture/glb-voxel-clean/
      <subject>/`); **before/after noise drop** recorded per subject (value ΔE and/or distinct-block count
      down; form IoU steady — clean must not break the shape).
- [ ] `npm test` green.
