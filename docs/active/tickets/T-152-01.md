## Context (self-contained)

Epic **E-36** / Story S-152. Two consecutive loops (E-35 T-149-01..02, T-150-01) reported "GL absent"
and deferred **every** render to an "operator runbook" — building machinery for two sessions while
**never looking at the output**. GL is in fact available (`render/src/render.mjs` `GL_AVAILABLE: true`;
this session rendered a textured barn + the `roof-diff` sheet by hand). A judge-free render is cheap
(`--skip-gate` chains exist; `roof-diff`/sheet render without spawning the judge) and is the creation
loop's feedback signal. The render must become automatic, and missing GL must be loud.

## Acceptance Criteria

- [ ] **Auto render-beside-concept every creation run.** Each creation pass (the workshop loop and the
      generate/chain runners) emits a **judge-free textured render placed beside the concept** —
      reusing `--skip-gate` + the existing diff/sheet path — written to `pr/assets/` (or the run dir).
      No judge spawn, no billed run.
- [ ] **"No GL" is a hard, surfaced failure.** If headless GL is unavailable the run **fails loudly
      with a named error** (and the remedy), never silently defers the render to a runbook. The
      `GL_AVAILABLE` probe is checked at the top of any render-bearing run.
- [ ] **Environment fix.** Diagnose why the autonomous/agent environment reported no GL when the host
      has it (Playwright/Chromium vs headless-gl; sandbox), and make the loop environment provide it.
      Record the root cause and the fix.
- [ ] **Prove it on the barn (the glance).** Re-render the barn with T-150-01's gable/overhang fix live,
      through the de-frozen judge-free path; commit a sheet **beside the concept** to `pr/assets/`
      showing the construction improvement (stone gable, overhanging roof) vs the prior flat barn.
      Honest caption — the build is rough; name what still reads wrong (this is creation, not a verdict).
- [ ] No judge run anywhere in this ticket; `npm test` green; no new ceremony (E-36 Rule 2).
