## Context (self-contained)

Epic **E-30**, follow-on / Story S-122. The T-121 milestone isolated the project's highest-leverage
roof-form defect, with both receipt types agreeing: **the generated cross-gable ridge is built ~4
blocks low — mean delta −4.015, unchanged through T-118's instrument repair** (cottage generated,
`roof-diff` records; the barn's first run carries the same signature: major `form @ roof` at all four
azimuths, roof-diff 4416px / roof share 35%, a visibly flattened roof on the contact sheet). T-118
repaired the *reading* (`fitRidgeLine`: footprint cols, protrusion exclusion, dominant-line selector —
the fitted apex value is now trusted); the *construction* still places the ridge below it. Somewhere
between the fit record and the placed cells, ~4 blocks of height are lost.

## Acceptance Criteria

- [ ] **Diagnosis recorded first**: trace one subject's ridge from fit record → generator input →
      placed cells and name where the height is lost (candidates: the fitted apex not consumed by
      `generateRoof`/`provision-generate`; eave/pitch integer quantization accumulating downward; a
      swap-ladder rung accepting a low candidate). The diagnosis cites the actual numbers (fitted
      apex y vs built ridge y) before any fix is written.
- [ ] **The fix, pure and unit-tested**: the generated ridge height matches the fitted apex within a
      declared tolerance (≤1 block — voxel quantization is the floor). The **−4.015 witness is a unit
      test** (the recorded cottage fit values in, ridge cells out at fitted height); synthetic specs
      cover both gable orientations and the cross-gable case; stair/slab cap states still render
      (`unmapped` empty).
- [ ] **Verified by the instrument, before any judging**: roof-diff ridge-region delta goes to ~0
      (within the declared tolerance) on **cottage (generated) and barn**; before/after diff
      artifacts committed; the cage holds (per-azimuth IoU vs GLB, closure — auto-rollback recorded
      if any step regresses); no other region's delta worsens.
- [ ] **One owned re-judge** of the affected subjects (`generated:cottage`, `generated:barn`) under
      `--rotate-pins` (T-119 policy, retired pins named; T-114 governs malformed replies only; one
      judge run per view, no re-rolls). Verdicts recorded with instrument receipts (`diffs: []`) —
      movement vs the T-121 profiles (cottage generated 12/2, barn 12/2 0/4) or named residuals with
      the diff deltas that explain them. Subjects whose artifacts this fix does not change are **not**
      re-judged (no judge spend without a moved artifact).
- [ ] Reproducible (`--repro`/`--offline` re-asserts); registry-only (generalization grep —
      including the runner-comment hygiene from T-121 concern 1, so the barn record can finally read
      `clean: true`); no hand-edits; `npm test` green.
