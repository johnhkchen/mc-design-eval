## Context (self-contained)

Epic **E-37** / Story S-157. The consolidation cleans the state once; without enforcement it
re-sprawls, because autonomous runs start with **thin context** and docs inform but don't bind them. The
project already trusts **structure over discipline** for the build (4-can palette, registry-as-only-door,
workshop-can't-call-judge). Point that lens at the topology: make the wrong organizational move
structurally impossible. Reuse the existing conformance-sweep pattern
([[vocabulary-authority-one-composition-point]]) — tests that go **red on violation**.

## Acceptance Criteria

- [ ] **`STRUCTURE.md` authoritative + kept-current test.** The canonical map (Stage → owning module →
      artifact → entry point → archived) is the single source of truth; a conformance test fails if a
      live stage module is **absent from the map** or the map names a **module that doesn't exist**. The
      convention recorded: any stage-changing ticket updates the map in the same commit.
- [ ] **Topology conformance suite (red on violation):**
      - a **second "build a subject" entry point** appears → fail (one chain only);
      - a **live-spine module imports from `_archive/`** → fail;
      - a **draft artifact is written outside `builds/`** → fail; the pin-guard allowlist *is*
        `measurements/` + ratified `packs/` (path prefix, not a hand-list).
- [ ] **Done = delivered, not compiled.** A creation run's completion requires the canonical
      `builds/<subject>/` artifact regenerated **and rendered beside the concept** (E-36); green tests
      alone do not satisfy it.
- [ ] **Replace-don't-accrete + lisa claim.** The convention recorded (a superseding ticket archives
      what it replaces in the same ticket; a shared dep gets its own upstream ticket —
      [[parallel-roots-duplicate-shared-deps]]); a **checkable lisa claim** so a second thread sees the
      first instead of racing ([[lisa-same-ticket-concurrency]], [[ticket-double-dispatch]]).
- [ ] Each guardrail has a test proving it fails on the violation and passes on the canonical state;
      `npm test` green; no new ceremony beyond the enforcement (E-36 spirit).
