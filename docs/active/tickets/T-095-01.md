## Context (self-contained)

Epic **E-25**, terminal / Story S-095. Everything upstream built a pipeline that *should* produce
concept-faithful buildings; this ticket proves it **does** — on cottage, gatehouse, and the **church**
(T-094-01), a subject the pipeline has never been tuned on. The epic's binding rules apply in full: the
deliverable is the **multi-angle contact sheet** (E-25 Rule 1); concepts immutable (Rule 2); the church
enters via its registry entry only (Rule 3); all 4 azimuths, contract resolution (Rule 4); no hand-edits,
reproducible (Rule 5); gaps named honestly (Rule 6).
