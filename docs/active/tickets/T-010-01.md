## Context

Epic E-08 / story S-010 / spec §7, §9. Second run-the-test, gated on `T-006-01` (inherits S-006's
champion). The alternate detail experiment: **read the S-006 attempt-log entry first** and pick a
*different* detail mechanism than S-006 used, so the two experiments are not redundant. Candidate
mechanisms (use one S-006 did NOT): a **dedicated detail-only pass** that edits only flat fields via the
revision seam; **per-region articulation minimums** (each plane > ~6 wide carries ≥1 named relief device);
a **paneling/string-course grammar**; a **noisier-grained block-texture / material swap** (busier grain
reads as more detail — journal caveat). If S-006 already reached *strong* detail, instead push the winning
lever further or stack a complementary one to probe *exceptional*.

Same seams and run command as T-006-01 (`baml_src/facade.baml` + `npm run baml:gen`;
`composeRefRevisionPrompt`; `node benchmarks/temple-facade/run.mjs --approach vRefRevise-designdoc --ref
references/taj_mahal.png`). One hypothesis only. Rubric and brief immutable.

## Acceptance Criteria

- [ ] One *distinct* detail lever (different mechanism from S-006) is chosen in Design with rationale and
      applied as a committed prompt diff; `npm test` green; client regenerated if `facade.baml` changed.
- [ ] The Taj trial runs; both `round-0.png` and `render.png` are scored with the categorical judge
      (median of 3).
- [ ] A journal attempt-log entry is appended: the prompt diff, A/B per-dimension scores, judge notes,
      verdict (promote / scope / discard), and an explicit comparison to the S-006 lever (which detail
      mechanism works better, and why).
- [ ] Promotion rule as in T-006-01: keep only on a full-category `detail` lift to *strong* (or higher)
      with no regression and overall ≥ *strong*; else revert and record the negative result.
- [ ] **Control for detail noise:** `detail` flips category run-to-run on the fixed champion (014
      *competent* vs 015 *strong*, identical config). Do NOT credit a single `detail=strong` as a lever
      win — require it robust (strong across 2 generations, or a clear visual articulation delta vs the
      run-015 baseline). This applies to the S-006 vs S-010 comparison too: prefer the lever that is
      *consistently* strong, not the one that got one lucky strong.
- [ ] Renders + `summary.json` retained under `benchmarks/temple-facade/runs/<id>/`.
