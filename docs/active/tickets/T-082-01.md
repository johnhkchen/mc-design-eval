## Context (self-contained)

Epic **E-23** / Story **S-082** — the **agentic-engineering** story. Because the 2.5-D layer scopes each op
to a *view*, many sub-tasks are narrow enough for a **lighter model tier**. This ticket builds the seam and
proves it with two exemplar detectors.

**Hard invariant:** lighter models are reached via the **`claude -p` subscription shim** with a per-task
`--model` override (`config.mjs` single-sources the tier IDs). The metered **API key must never enter this
path** — a smaller model is still the subscription, just a smaller `--model`. (Standing Phase-1 invariant.)

## Acceptance Criteria

- [ ] A **per-op model-tier seam** over the subscription shim (`src/sdk-binding.mjs`): an op declares its
      tier; the shim runs with the matching `--model`. Tier IDs single-sourced in `config.mjs`
      (light = Haiku, strong = the pinned default). Confirm (test/assert) the API key is **not** read on
      this path.
- [ ] Two **light-tier exemplar detectors**, each scoped to a projected view (T-078-01): a **roof-patch
      detector** (which roof cells read wrong / need patching) and the **hollowable-mass detector** (feeds
      T-080-01). Run live on the cottage on the light tier.
- [ ] The **scoping rationale recorded** per op (tier chosen + why), with a short rubric: narrow
      detector/classification on one view → light; cross-view judgement / authoring a generator / material
      zoning → strong.
- [ ] Tier-selection + detector parse logic **unit-tested**; the live detector calls are metered;
      `npm test` green.
