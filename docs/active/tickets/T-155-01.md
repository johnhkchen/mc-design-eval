## Context (self-contained)

Epic **E-37** / Story S-155. The same subject is scattered across seven directories with different
bytes. E-36 established that **drafts regenerate freely while frozen records stay pin-guarded** — but
that distinction is invisible in the tree. Make **location encode status** so a thin-context agent knows
draft-vs-frozen-vs-dead by *where a file lives*. The frozen-record move is the delicate seam (E-37
Rule 1): paths change, bytes never.

## Acceptance Criteria

- [ ] **`builds/<subject>/`** is the canonical draft home — `program.json`, `seed-artifact.json`,
      `ledger.json`, `final-artifact.json`, `renders/`. The unified chain (T-154-01) writes here;
      freely regenerated (no pin-guard — the E-36 free zone).
- [ ] **`measurements/`** holds the frozen records (gate verdicts, baselines, milestones). **The E-36
      pin-guard allowlist becomes, by location, `measurements/` + ratified `packs/`** (the allowlist is
      now a path prefix, not a hand-list).
- [ ] **Frozen records migrated under identity-class discipline** (E-37 Rule 1): every committed gate
      verdict / baseline / milestone moves to `measurements/` with **bytes unchanged** — baselines
      **never re-banked**, every committed verdict **re-derives unchanged**, the judge contract
      unmoved; monotone proof committed; `--repro`/`--offline` byte-identical after the move.
- [ ] **`_archive/`** exists as the dead-code home (populated by S-156); references to moved live
      outputs are updated so nothing dangles.
- [ ] `npm test` green; reproducibility-by-replay of every committed measurement unchanged.
