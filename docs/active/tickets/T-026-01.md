## Context

Epic E-11 / story S-026. Bookend 2 — review. Build a critic that takes a build state, renders it (E-02
head-on is enough for facades; multi-view via E-12's turntable is an opportunistic upgrade), and emits a
**structured diagnosis**: a list of `{ defect, where, route }` where `defect ∈ {flat, ringing,
under-detailed-focal, proportion}` and `route` names the stage that should address it (flat → relief or
material; ringing → curve idiom; under-detailed-focal → detail; proportion → massing). It **routes**, it
does not rebuild (the P14 cure).

Use the categorical-judge BAML pattern for the critic (image in → structured diagnosis). Test against a
**fixture** build state with a known defect (e.g. a flat untextured wall) so the ticket is independent of
the craft passes; the live loop is demonstrated in consolidation (S-029).

## Acceptance Criteria

- [ ] A critic returns a **structured diagnosis** (`{defect, where, route}[]`) from a build state's render,
      not free prose; the defect vocabulary + routing table are explicit.
- [ ] It **routes, never re-emits** — the output references a stage to re-run, not a new artifact. Tested:
      a flat-wall fixture yields a `flat → relief/material` route; a clean fixture yields no defects.
- [ ] The critic is a stage-agnostic consumer of the build state (no coupling to specific passes).
- [ ] `npm test` green (BAML render path tested where feasible; the model call may be stubbed for the unit
      test, with the routing logic tested directly).
