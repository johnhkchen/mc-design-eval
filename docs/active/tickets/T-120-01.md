## Context (self-contained)

Epic **E-30** / Story S-120. The barn's registration (T-116) exposed two gaps: (1) the **S-094
checklist gates geometry, not lens readability** — the barn passed the checklist, spent the
TRELLIS/GLB budget, and was *then* refused by the zone lens (`no-field-cells`), a refusal visible from
the concept alone; (2) **glb-smoke's strict single-component gate over-fires on sub-speck debris** —
the barn's GLB failed at every scale on **one floating mesh cell** (largest-component fraction
≥0.9813 throughout), forcing a named deviation + conditioned-evidence probe
(`runs/017-…/concept-checklist.md`). Depends on T-117-01: the pre-spend smoke must run the **fixed**
lens, or it would wrongly refuse barn-class concepts.

## Acceptance Criteria

- [ ] **Pre-spend lens smoke** in the registration flow: the (role-aware) zone lens + a kit-extract
      dry-run execute against the concept **before** any TRELLIS call; a refusal is **cheap, named,
      and blocks registration** (regenerate or re-concept before a GLB exists — concepts become
      immutable only *at* registration, so this is S-094-compatible). The S-094 checklist doc gains
      the step. **Fixture**: the barn's concept passes the smoke post-T-117; a synthetic
      lens-unreadable concept is refused with zero spend.
- [ ] **Sub-speck tolerance in glb-smoke** (pure, unit-tested): components below a **declared**
      cell-fraction budget are reported + delegated to the standing shellStage strip instead of
      failing the gate; the strict single-component check holds above the budget. **Fixture**: the
      barn's GLB (one-cell speck, ≥0.9813 main fraction) passes without a deviation; a genuinely
      fragmented mesh (moai-class) still fails.
- [ ] Both former barn deviations re-run as regression fixtures and recorded; the registration
      runbook (checklist → smoke → TRELLIS → glb-smoke → registry) documented in one place.
- [ ] No contract relaxation anywhere else (the smoke *adds* a gate, the tolerance is declared and
      bounded); no subject-specific constants; `npm test` green.
