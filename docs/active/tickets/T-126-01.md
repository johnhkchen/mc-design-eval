## Context (self-contained)

Epic **E-31** / Story S-126. Look-adjust-look — the basic loop of all skilled work — has been
structurally forbidden here: the no-re-roll rule (correct for grading) leaked into building, making
every build a single blind shot. E-31 Rule 1 splits the modes: the **workshop** iterates freely and
may never call the frozen judge; the gate convenes once, later (S-127). The tools exist (idiom
realization, parameter adjustment, the E-23 spray-paint path, gate-azimuth renders); this ticket
builds the loop, its ledger, and its judge-isolation.

## Acceptance Criteria

- [ ] **The loop runner**: build → **4-azimuth renders** (the fixed lens) → the model critiques its
      own build against the concept (structured: per-region, named issues) → the model **revises**
      via the sanctioned actions — re-recognize a part, adjust idiom parameters, re-realize,
      spray-paint details (E-23 path) → the pack's **conformance checks** gate the round (a revision
      that regresses regularity/integrity is rolled back, recorded) → repeat within a **declared
      round budget** → the model declares done (or budget exhausts, recorded). Subscription shim,
      tiers per E-23 routing.
- [ ] **The ledger**: every round commits critique, action, conformance result, and render reference
      — raw model replies included. Nothing the loop did is unreviewable.
- [ ] **Replay** (E-31 Rule 5): the final build reproduces **byte-identically** from the committed
      program + ledger via a named `npm run` (no live model calls on replay; `--offline` re-asserts).
- [ ] **Judge isolation, structural** (the T-119 pattern, not convention): the workshop runner has no
      code path to the frozen judge — unit-tested (the seam is absent/THROWS); the pin-guard refuses
      any workshop write to gate records.
- [ ] **Proof run on an existing build** (the S-125 cottage first draft if landed; else a committed
      fixture build): ≥1 full cycle with a measurable improvement (conformance metric or named visual
      defect fixed, render evidence before/after); budget respected; replay verified.
- [ ] No per-building code; `npm test` green.
