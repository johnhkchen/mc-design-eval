## Context (self-contained)

Epic **E-18**. The palette fix locked the GLB-voxel color picker to the **design-doc manifest** (the
model's deliberate few blocks) instead of the full 305-block table — killing the speckle/bloat (heart
91 → 5 blocks). But that tight primary palette can *over-constrain*: TRELLIS textures sometimes carry a
**genuine color the design doc never anticipated**, and forcing it onto the nearest of the 5 design-doc
blocks creates large **drift** (high snap-ΔE → an inaccurate representation).

This ticket adds a **gated secondary palette**: bring in **a couple of extra blocks** from the full
value-true table — but **only when they are a super-great fit that greatly reduces the drift**. The
primary stays the design-doc palette; the secondary is a strictly-capped, high-bar augmentation, *not* a
return to snapping over the universe.

## The augmentation (the gates — all must pass)

`augmentPalette(designDocPalette, texture, table, opts) → palette`:
1. **Cluster the texture's actual colors** (median-cut Lab, weighted by coverage — reuse
   `palette-extract`'s `medianCutLab`) → candidate target colors with their surface coverage.
2. Per cluster: `primaryΔE` = min ΔE to the **design-doc** palette; `bestTable`/`tableΔE` = nearest block
   over the **full table**; `gain = primaryΔE − tableΔE`.
3. A cluster is a candidate for augmentation only if **all** hold:
   - **underserved** — `primaryΔE > driftThreshold` (design doc represents it poorly; default ≈12 ΔE),
   - **real** — `coverage ≥ minCoverage` (a meaningful share of the surface, not stray voxels; default ≈5%),
   - **super-great fit** — `tableΔE ≤ fitThreshold` (a genuinely close block; default ≈6 ΔE),
   - **big win** — `gain ≥ gainThreshold` (greatly cuts the drift; default ≈6 ΔE).
4. Add at most **K = 2** qualifying blocks (ranked by `gain × coverage`), deduped against the primary and
   each other. Final palette = design-doc palette **∪** secondary (≤K). Most subjects should add **0**.

## Acceptance Criteria

- [ ] `augmentPalette(...)` implemented (pure, GL-free) and wired so the candidate palette passed to
      `glbVoxelBuild` / `segmentMaterials` is the **augmented** one. Thresholds + `K` are named constants,
      tunable.
- [ ] Unit-tested: a synthetic texture cluster **far** from the primary but with a **tight** table block
      → that block is added; a well-served cluster → **nothing** added; the cap holds (never > K); a small
      / low-coverage off-color cluster → **not** added (no speckle reopened).
- [ ] Applied across the 7 subjects: a per-subject record (`benchmarks/sculpture/secondary-palette.{md,json}`)
      of **which secondary blocks were added (block, gain, coverage)** and the **mean texture-snap ΔE
      before→after** (the drift it removed). Honest: subjects that need none add none.
- [ ] Total palette per subject ≤ **design-doc size + K**; off-(augmented-palette) count = 0. Form IoU not
      harmed.
- [ ] `npm test` green.
