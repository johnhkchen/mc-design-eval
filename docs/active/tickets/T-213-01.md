## Falsifiable claim (anti-hedge — lead with how it fails)

≥1 candidate agrees with the S-212 glance ranking materially better than the current rule (keeps the +48 arch
and the dressed compound) **without rubber-stamping** (still rejects a deliberately-worse build). **Fails if:**
agreement is only reachable by **keeping everything** (no rule both keeps the arch and rejects a worse build →
the gap is the *scorer's gradient*, not the rule — name it, redirect to the judge); the candidates **trade**
(non-median lets noise through, batch-while-improving rubber-stamps); or none beats the current rule (the median
was the rule class's ceiling → architecture-ceiling territory → S-214).
