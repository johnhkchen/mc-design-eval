## Context (self-contained)

Epic **E-26** / Story S-098. The E-21 map's placement vocabulary is 4 coarse zone-wide rules (`walls` /
`corners-edges` / `trim` / `roof`) — which is exactly how stone and plaster both claimed `walls` and one
ate the other (the cottage's 215→8 plaster collapse). The kit (T-096-01) names *what* the ingredients
are; this ticket supplies *where each instance goes*: the concept's framing rhythm is structural — the
stripped-log frame follows floor lines, corner posts, gable rakes, and eave beams; panels fill the
bounded fields **between** frame lines; each opening is an instance with its own treatment.

## Acceptance Criteria

- [ ] A **pure placement-grammar core** (unit-tested on synthetic structural reads): kit entries bind to
      structural feature instances — `frameLines` (floor lines + corner posts + gable rakes + eave beams,
      derived from the structural read's geometry) → frame block; bounded **fields between frame lines**
      → panel block; **each opening instance** → its declared treatment (applied by T-099); roof courses
      → course block. Output: concrete placements (with states where fixtures), deterministic given
      kit + read.
- [ ] **Composes with the E-24/E-25 fill**: the grammar refines what the zone-fill paints (fields vs
      lines), it does not fight it — one pipeline order, recorded. Frame lines survive the full-shell
      fill (they are declared secondaries, per T-090-01's contract).
- [ ] **Cottage run** behind the named `npm run`: stripped-log frame on the frame lines, panel block in
      the fields, **both storeys** showing the concept's framing rhythm (the concept is half-timbered on
      both storeys over a plinth — per the T-092 concept-derived map, not the old stone-base prior).
      Before/after renders at gate angles.
- [ ] No subject-specific constants (E-25 Rule 3); no hand-edits (E-24 Rule 1); `npm test` green.
