## Context (self-contained)

Epic **E-24** / Story **S-085**. The E-23 spray-paint applies material by splatting a concept-COLOR target
per cell, which **cannot establish a zone's dominant material**: on the cottage it converted only **9%** of
the upper-storey wall to plaster (64% stayed stone — quantization collapse + concept→face misalignment), so
the upper storey still read grey. A structural **zone-fill** took it to **77% plaster** — but that was
applied **inline by hand** and `npm run spray:paint` regenerates the bad version. Make the fill a
first-class, deterministic, reproducible pipeline step.

## Acceptance Criteria

- [ ] A **deterministic zone-fill** core: for each structural zone (`structuralZones` — base / upper /
      roof), fill the **wall-field surface** cells with that zone's **dominant material** from the E-21
      material map (base=`stone_bricks`, upper=`white_terracotta`/plaster, roof=plank), **preserving
      secondaries** (`dark_oak_log` timber studs, trim — runs, not isolated cells). **Pure, unit-tested** on
      synthetic occupancy (a stone upper-band cell → plaster; a timber stud stays; a base cell stays stone).
- [ ] **Wired into the spray-paint pipeline ahead of the splat**: zone-fill lays the base coat, then the
      splat/LLM places **secondaries only** over it.
- [ ] **Reproduced by the pipeline (Rule 1)**: `npm run spray:paint` (no hand-edit) yields the cottage upper
      band at **≈77% plaster** (was 9%) — report the coverage histogram from the *pipeline* output, not an
      inline script.
- [ ] `npm test` green.
