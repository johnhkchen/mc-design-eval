## Context (self-contained)

Epic **E-39** / Story **S-163**. Build the typed contract between judge and builder: a `Department` enum
**generated from** `src/pack/idiom-registry.mjs` (the construction catalogue — roof/wall/opening/room/
chimney/…), and the enriched `Critique`/`CritiqueItem` BAML classes. Schema + generator + conformance only;
no judging behaviour (that is T-164-01). BAML stack: `baml_src/`, `src/baml/bridge.mjs`; test pattern is
`b.parse` fixtures (see `baml_src/critique.baml`, `src/baml/transport-guard.test.mjs`).

## Falsifiable claim (anti-hedge — lead with how it fails)

The idiom-registry's entries partition into a small `Department` enum such that every entry maps to exactly
one department and every department names ≥1 entry; the `CritiqueItem {department, expected, present,
missing, severity}` class expresses any construction-addressable issue. **Fails if:** an idiom serves two
departments or none (the grouping is the finding), or a real critique kind (e.g. proportion — relational,
not per-element) doesn't fit the per-department triple (the schema needs another axis — report, don't force).

## Acceptance Criteria

- [ ] `Department` enum derived programmatically from the idiom-registry (a pure `.mjs` that groups idioms →
      departments), plus a **conformance test** failing on any idiom→no-department or department→no-idiom
      drift (single-composition-point tripwire).
- [ ] BAML `Critique { items: CritiqueItem[] }` + `CritiqueItem { department, expected, present, missing,
      severity }` with `b.parse` fixture tests.
- [ ] Pure `.mjs` `departmentToIdioms(dept)` seam (candidate idiom entries per department) for Layer B to
      consume in T-164-02; unit-tested, no per-subject constants.
- [ ] `npm test` green; transport-guard green (frozen judge path gains no dependency).
