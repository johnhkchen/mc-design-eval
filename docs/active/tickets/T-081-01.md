## Context (self-contained)

Epic **E-23** / Story **S-081** — the **program path crossing into design**. The hollow cottage (T-080-01)
is an empty shell; fill it with an **N×M grid floorplan** across the **N storeys**, generated by a program
the LLM authors/steers from the **below/plan view**.

**This crosses craft → design and the gate changes.** The interior has **no reference** (concept + GLB are
exterior shells) — "break into rooms" is invention. Use the **program-author pattern** (LLM writes the
generator, the program places) and a **plausibility gate**, NOT the resemblance gate (nothing to compare an
interior to).

## Acceptance Criteria

- [ ] From the **below/plan view** (T-078-01): read footprint + storey lines + exterior opening positions.
- [ ] The LLM **authors/steers a floorplan generator** that partitions the footprint into an **N×M grid**,
      places **floors at the structural storey lines**, dividing walls on the grid, and **interior openings
      aligned to the exterior** (behind the front door; sensible per storey).
- [ ] **Fill the N storeys** by running the generator (bulk placement is the program's job — not
      hand-placed).
- [ ] **Plausibility gate** (design-without-reference): rooms valid + non-overlapping; **reachable** (a path
      / doors connect them); floors at storey lines; **storey count matches** the structural read; grid
      **fits the envelope**; openings align with the shell. Report pass/fail per constraint + a named
      residual (Rule 7).
- [ ] The generator + the plausibility gate are pure/deterministic and **unit-tested** (synthetic shells);
      the floorplan reasoning is the metered call. `npm test` green.
