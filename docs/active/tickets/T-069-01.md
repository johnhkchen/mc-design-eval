## Context (self-contained)

Epic **E-20**, the quality bar. The high-resolution building (T-068-01) is placed + clean, but
TRELLIS+voxelization gets the *bulk* right while fine architectural detail (window reveals, cornices, roof
edges) can stair-step or read soft. Push it to a **high standard** with the E-15 **surgical revision loop**
using the building's **GLB as the form target**: observe a region → diagnose → bounded tweak (procedural
or LLM block-edit) → re-observe → **accept-if-improved** (P14-safe: non-improving edits rolled back,
accepted regions lock).

"High standard of passing round" = the **categorical judge** (`baml_src/judge.baml`:
Weak/Competent/Strong/Exceptional) reaches **Strong or better**. The project's purpose is to find *where
quality tops out* — so if it tops out below Strong, **measure and explain where/why**; that is a result,
not a failure to hide.

## Acceptance Criteria

- [ ] The E-15 `reviseLoop` runs on the building with `formTarget: glbFormTarget({ glbPath })`,
      region-by-region, **bounded** rounds, toward a Strong+ verdict.
- [ ] Per-round record: the categorical **judge verdict trajectory**, the per-region **edit trace**
      (region, procedural vs LLM, kept/rolled-back), and the **form IoU** trajectory. P14-safety holds
      (no accepted region later altered; non-improving tweaks rolled back).
- [ ] Outcome stated honestly: **Strong+ reached** (with the round count), OR the **topping-out point**
      (best verdict + the specific detail the loop couldn't fix) is recorded.
- [ ] Final refined `DesignArtifact` + render saved; `npm test` green.
