## Context (self-contained)

Epic **E-25** / Story S-093. The E-22 resemblance gate (`benchmarks/sculpture/resemblance.mjs`) judges
**one shared 3/4 view**. The defects that currently make builds look wrong — the cottage roof's grey side
faces (roof-band exposed surface 42.7% spruce vs 96.7% from straight above), wall residue, the gatehouse
cavity — live on **the views the gate never sees**. A single-angle gate structurally rewards skinning the
photographed face; the multi-angle cottage sheet (`pr/assets/cottage-multi-angle.png`) shows exactly that
divergence.

## Acceptance Criteria

- [ ] The gate renders the build at **4 fixed azimuths** (45°, 135°, 225°, 315°, contract
      elevation/resolution — the angle set lives in config and is **not** overridable per run; E-25
      Rule 4). The gate **refuses to produce a verdict** if any view is missing.
- [ ] **Per-view categorical judgement** against the immutable concept (same object / drifted / different
      object + named gap region/attribute), reusing the E-22 judge; the **E-24 coverage precondition**
      (T-088-01) runs per view before the judge counts.
- [ ] A **contact sheet** verdict artifact: concept | the 4 views, labeled, saved. The sheet is the
      verdict; per-view JSON is support (E-25 Rule 1).
- [ ] **Aggregate pass rule**: same-object at **every** azimuth with **≤2 named minor gaps total**;
      pure aggregation logic unit-tested (incl. the refuse-on-missing-view and gap-budget cases).
- [ ] **Proof both ways, recorded**: the current committed cottage (grey roof sides) **fails** on at least
      one non-front azimuth; a fully-skinned build (or synthetic positive) **passes**.
- [ ] `npm test` green; no weakening of E-22 single-view behavior for existing callers.
