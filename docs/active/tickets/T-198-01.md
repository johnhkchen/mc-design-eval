## Context (self-contained)

Epic **E-51** / Story **S-196**. The M1 capstone for the gatehouse: the one thing proven piece-by-piece but
**never actually run end-to-end** — an *autonomous metered* climb. Everything it depends on now exists:

- **The eyes** (T-196-01): the framing axis flags orientation + scale on the real build (orientation
  quiet/correct, scale flags the steep gable), wired into `scoreBuild`/`agentPick`/trajectory.
- **The form + ordering** (T-197-01): `closeShell` closes the gatehouse (closureOf 0.615→1.000, roof
  preserved) and `formReadyGate` blocks detail tools below closure 0.9 (`carve_arch` BLOCKED@0.615,
  ALLOWED@1.0). The colonnade substrate is gone — there is now a closed wall for carve/relief to read against.
- **The hands** (T-194 carve, T-195 relief) compose in the zero-spend glance.

What is still **deferred**: the *metered* verdict. T-196-01's metered climb **hung ~20 min on a non-returning
`claude -p --model claude-opus-4-8` strong-tier diagnose subprocess** (node idle 0:25 CPU / 21 min elapsed,
child blocked at 0:11 CPU, spawn count frozen) and was killed — twice. This is **infra, not code**; the runner
wiring is GUARD_ONLY-clean. So the climb cannot complete until the runner is **robust to a non-returning
subprocess**, then run for real.

Two coupled deliverables:

1. **Subprocess-timeout guard** on the tiered diagnose/vote op in `picture-climb.mjs` (the `claude -p` spawn
   path): a per-call wall-clock timeout that **kills the child and surfaces a typed timeout** rather than
   hanging the whole climb. A timed-out vote must degrade gracefully (drop that vote / retry once / fall to a
   lower tier) and be **recorded**, never silently masked — a climb that silently drops half its votes is a
   corrupted measurement, not a robust one.
2. **Run the metered gatehouse climb** end-to-end with all E-51 hands + wider eyes, on the closed form, and
   report the autonomous verdict on the glance.

## Falsifiable claim (anti-hedge — lead with how it fails)

With the timeout guard, the metered climb **completes** (no hang); the agent, prompted with form-readiness,
picks `close_shell` first, then carves the gate + builds relief on the closed shell; and the final build
reaches the gatehouse's picture on the glance — closed dressed walls, arched gate, dark gabled roof, right
orientation/scale — **mostly autonomously**. **Fails if:** the guard masks a real auth/spend failure (every
vote times out → the climb "completes" on zero signal — must be detected and reported, NOT scored); the agent
**does not** sequence the hands (picks detail before form despite the gate, or never picks carve/relief → an
orchestration gap, name it); the WALL major **does not clear** even with the relief hand available (the eyes
or the hand still don't connect — name it); or the climb **plateaus on a fourth gap** (roof pitch/material →
E-49). A precisely-named failure here is a complete result and the input to E-49.

## Acceptance Criteria

- [ ] **Timeout guard** on the tiered diagnose/vote subprocess: per-call wall-clock limit kills the child and
      raises a typed timeout; graceful degrade (documented policy: drop/retry/lower-tier) + **recorded per
      round**. Unit/abstracted test of the guard's behavior (times-out → typed error → degrade path), not a
      live hang. The all-votes-timed-out case is **detected and aborts/flags the round**, never scored as 0.
- [ ] **Metered climb run** end-to-end on the gatehouse with all E-51 hands + framing eyes; `climb.log` +
      `trajectory.json` + beside-concept renders (first / best / final) in the work dir. If it hangs again
      despite the guard, that is itself a reportable finding (deeper infra) — record it, don't fake a run.
- [ ] **Autonomous-sequencing verdict (the deferred question):** did the agent pick `close_shell` before
      detail (ordering gate honored live)? did it pick carve + relief? did the WALL major clear? Answer each
      from the trajectory, with the round-by-round picks.
- [ ] **Human-glance check** on the final build vs concept: reached-its-picture (closed dressed walls + arched
      gate + dark gabled roof + right orientation/scale) **or** the named residual ceiling (→ E-49); state how
      much human intervention (autonomous picks vs scripted).
- [ ] **Recorded honestly at full strength**; scale judged on proportion not render pixels; the metered cost
      (votes × rounds × tier) reported.
- [ ] `npm test` green; **frozen instrument (`measurements/`) untouched**; uses the `claude -p` subscription
      shim only (never the metered API / `ANTHROPIC_API_KEY`).
