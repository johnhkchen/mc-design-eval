## Context

Epic E-01, spec §4–§5. The experiment harness (E-03) relies on the model emitting artifacts as **enforced structured output** via the Claude Agent SDK — this is what makes per-trial logging clean and keeps malformed designs out of the pipeline. This ticket binds the schema (T-001-01) as the SDK's structured-output format and provides a parse/validate helper that yields a typed artifact or a clear, actionable error.

Touches the SDK-binding module, separate from the primitive-expansion module (T-001-02), so the two run concurrently.

## Acceptance Criteria

- [ ] The schema is wired as the Agent SDK structured-output format; model output conforms to the schema.
- [ ] A parse/validate helper returns a typed artifact on success or a clear validation error on failure.
- [ ] Malformed or partial outputs are rejected with actionable messages (which field, why).
- [ ] Tests cover valid and invalid sample payloads.
