## Context (self-contained)

Epic **E-25** / Story S-094. Two roster problems:

- **Moai is retired as a measurement subject** (decision 2026-06-10). Its concept art shows **three
  statues in one frame on a black background**; the TRELLIS mesh fragmented into two masses; the build
  was judged "different object" mostly due to debris/fragmentation that say nothing about design
  capability. A weird concept makes every downstream verdict ambiguous.
- **No challenge subject exists.** Cottage and gatehouse were both used to develop the pipeline; passing
  on them cannot prove generalization (E-25 Rule 3 needs a subject the code has never seen).

## Acceptance Criteria

- [ ] **Moai retired** from the `SUBJECTS` registry in `benchmarks/sculpture/resemblance.mjs` (and any
      building-pipeline rosters): moved to a commented/`RETIRED` section with the rationale above, not
      silently deleted. Scale-study history and artifacts on disk untouched.
- [ ] **Church concept generated** via the existing `vConcept` path (GEMINI key from `.env` — never
      printed/committed): **a village church with a square bell tower** — two attached masses, two roof
      forms (pitched nave + pyramidal tower cap), ≥3 distinct material zones (stone walls, dark roof,
      timber door, light trim), **bulky throughout** (no thin freestanding spire/cross — TRELLIS fails on
      thin subjects).
- [ ] The concept passes a **concept sanity checklist, recorded beside the image**: single building ·
      clean background · one canonical 3/4 view · ≥3 distinct material zones · readable silhouette · no
      environmental clutter. If a generation fails the checklist, regenerate **before registration** —
      once registered the concept is **immutable** (E-25 Rule 2).
- [ ] **Textured GLB produced** via `trellis-glb.mjs` → `MODAL_ENDPOINT_URL` (run unsandboxed as that
      path requires); GLB on disk (gitignored, like the existing 7); a **voxelization smoke-check** at the
      working scale confirms a single bulky mass (no moai-style fragmentation) before sign-off.
- [ ] **Registry entry added** for `church`: concept path, GLB path, scale — **paths/config only, zero
      pipeline-code changes** (the whole point: the pipeline must later run it untuned).
- [ ] `npm test` green; journal note (`design-learnings.md`): why moai was retired, the checklist, and
      the church's registration.
