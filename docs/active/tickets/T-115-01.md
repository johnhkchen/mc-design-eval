## Context (self-contained)

Epic **E-29** / Story S-115 — the headline. Eleven epics of records say: **surfaces re-authored from
fitted geometry pass; surfaces inherited from the voxelized TRELLIS blob fail** (E-27: spikes −5×,
0→3 same-object azimuths when the roof became generated; E-28: the residuals are exactly the
not-yet-generated parts). The repair path pays an exorcism per surface. The inversion: **the blob is
fit evidence and cage target only — it never becomes the build.**

## Acceptance Criteria

- [ ] A **generate-first provision mode** behind a named `npm run`: from concept + GLB, **fit the full
      component set** — footprint, storey heights, wall slabs, roof forms (gable/hip/pyramid via the
      complete vocabulary incl. T-112), opening groups — every fit error recorded,
      tolerance-or-named-finding per component (E-29 Rule 1: a failed fit on this path is a registered
      limitation, never a silent fallback to blob cells).
- [ ] **Generate the build** from parameters + kit via the E-27/E-29 construction vocabulary (walls,
      roofs, arches, openings), skinned through the S-113 authority; **zero blob cells in the
      artifact** — a machine check (provenance tag or set-intersection against the voxelized mesh)
      enforces it, unit-tested.
- [ ] **Cage vs the blob**: per-azimuth silhouette IoU + closure against the voxelized mesh as the fit
      target; cage outcomes recorded.
- [ ] **Head-to-head on cottage + gatehouse + church**: generate-first runs judged by the **frozen**
      gates (instrument-diff `[]` receipts), recorded **beside the T-111-01 repair-path results** in a
      per-subject comparison table — verdicts per azimuth, fit errors, spike/ragged census, kit
      presence. Losses are findings with causes, not failures to hide (E-29 honesty).
- [ ] Reproducible (double-run + fresh-process re-proof); registry-only (generalization grep);
      no hand-edits; `npm test` green.
