## Context

Epic E-10 / story S-020. Implement the portable color engine per the exact math in
`docs/knowledge/cielab-block-matching.md`:

- `srgbToLab([r,g,b])` — inverse-gamma (0.04045 / 12.92, (x+0.055)/1.055 ^2.4) → XYZ via the D65 matrix
  → normalize by D65 white (95.0489, 100, 108.8840) → Lab via f(t) with δ=6/29.
- `deltaE(lab1, lab2)` — CIE76 Euclidean by default; keep the metric **pluggable** so CIEDE2000 can be
  added later without touching callers.
- `nearest(color, palette)` — argmin ΔE over `palette: [{key, lab}]`; linear scan (palettes are small),
  with a note on where a k-d tree would go for large sets.

**Constraint (load-bearing):** this module has **zero mc-design-eval / Minecraft / DesignArtifact
imports** — it takes a palette as plain data and returns a key. It is the E-09 portable voxelizer color
core; keep it clean.

## Acceptance Criteria

- [ ] `src/color/cielab.mjs` (or similar) exports `srgbToLab`, `deltaE`, `nearest` — no project/Minecraft
      imports.
- [ ] **Unit tests** with independently-derived expectations: sRGB white→`L*≈100, a*≈0, b*≈0`; black→`L*≈0`;
      a mid-grey and a primary checked against published Lab values (tolerance noted); `deltaE` symmetry +
      a known pair; `nearest` picks the correct key from a small hand-built palette.
- [ ] The ΔE metric is swappable (a parameter or strategy), default CIE76.
- [ ] `npm test` green.
