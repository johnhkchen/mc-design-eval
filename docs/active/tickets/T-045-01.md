## Context (self-contained)

Epic **E-15** closes the *iterate* bookend E-11 left open: E-11 built staged passes + a **diagnose-and-
route critic** (`src/sculptor/review.mjs`: emit `{defect, where, route}`, name the stage to re-run, never
blanket re-emit — the P14 cure) but `staged-loop.mjs` runs **one** forward pass and the diagnosis is
**never consumed**. This ticket wires the real loop.

**Build it with the DETERMINISTIC tweak primitive only — no model in the loop yet.** The point is to prove
the *cage* before adding a freeform model editor (that comes next, S-046/T-046-01, behind this same gate):
the loop must converge, an accepted region must lock and never be touched again, a tweak must never bleed
past the region-lock (T-044-01), and a tweak that **doesn't raise the form metric (IoU, T-043-01) must be
rolled back, not kept**. Model variance would confound that proof, so the only tweak here is a **scoped
procedural pass** — E-11's `relief`/`material` bounded to the region.

## Acceptance Criteria

- [ ] `reviseLoop(artifact, opts)`: pick region → `observeRegion` → diagnose (E-11 critic) → apply a
      **scoped procedural pass bounded to the region** → re-score with `formFidelity` → **accept-if-improved
      else roll back** → lock region → repeat under a **bounded iteration / per-region budget**; returns
      the revised artifact + a **per-iteration trace** (region, defect, tweak, score before/after,
      accepted?).
- [ ] Unit tests prove the cage: **convergence** (the loop terminates within budget); the **accept-gate**
      (a constructed non-improving tweak is rolled back, the artifact unchanged); the **spatial lock** (an
      accepted region is never re-edited; no tweak alters out-of-region placements); determinism (same
      input → same trace).
- [ ] No model/SDK call in this loop (pure + deterministic passes only); the live render seam (re-observe)
      is isolated so pure tests load no GL.
- [ ] `npm test` green.
