## Context (self-contained)

Epic **E-20** breaks Phase-1's **"facade only"** limit (text→JSON can't hand-place a whole building — it
narrates and overflows; voxelizing a TRELLIS mesh now places the bulk). This ticket is the foundation: a
**full-building** `vConcept` mode + its GLB.

`vConcept` handles facades (front elevation) and sculptures (freestanding 3/4 object). Add a **building**
framing: a whole structure in the round (four sides, roof, depth). The concept must be **ONE complete
building in ONE 3/4 view** with bold block-scale architectural detail — *single subject, single view* (the
moai's duplicate-mass mess came from a multi-view contact sheet; a building contact sheet would yield
multiple buildings + hallucinated connectors).

## Acceptance Criteria

- [ ] A full-building concept prompt + design-doc mode (sibling of `SculptureConceptPrompt` in
      `baml_src/conceptart.baml` + the `src/sculpture.mjs` mode pattern): a whole building, bold massing /
      roof / openings / trim, **single building in a single 3/4 view** (hard constraint in the prompt; no
      turnaround/contact sheet).
- [ ] A building **concept image** generated (saved under a run dir).
- [ ] The building **TRELLIS GLB** provisioned (`trellis-glb.mjs`) and recorded in `glb/README.md`;
      validated as a real glTF v2 mesh with sane geometry. **TRELLIS handling confirmed** — a building is
      bulky-angular; verify it doesn't fail like the thin sword, and **note honestly** any lost fine
      architectural detail (windows/cornices) for the surgical pass to address.
- [ ] Single-subject check: the concept is one building (not a contact sheet) and the GLB is a single
      principal mass (≈1 connected component, modulo legitimately separate parts).
- [ ] Pure mode/prompt logic unit-tested where applicable; `npm test` green.
