## Context (self-contained)

Epic **E-54** / Story **S-209**. The lead fix. E-53's T-208 cold-start batch escape works (climb leaves 0, +20)
but the glance-good **+20 dressed batch was rejected** because `relief_walls` collapses `eaveRingClosure`
1.000→0.068 on a still-closed wall. Deterministic proof (`docs/active/work/T-208-01/closure-probe.mjs`):

```
after close_shell        cl = 1.000
after apply_gable_roof   cl = 1.000
after relief_walls       cl = 0.068   (NOT a bounds/floor artifact)
```

`relief_walls` stands the wall **proud** (depth-1 outward) of the program footprint; T-206's `eaveRingClosure`
censuses the **exact footprint ring**, so a proud-dressed wall reads off-ring = "no wall" = open, same as a
colonnade. Make the metric tolerant of **±1 proud displacement** (census the wall plane: a column is closed if
it has a wall cell on the ring *or one step proud*) **without** regressing T-206's invariant — an **open
colonnade still reads open**. Distinguisher: proud-dressed-closed vs proud-open differ by *interior fill /
continuity*, not the ring.

## Falsifiable claim (anti-hedge — lead with how it fails)

The relief-tolerant metric reads proud-dressed-closed **closed (≥0.9)**, open colonnade **open (<0.9)**, a
reopened shell **open**, and on the live build keeps the T-208 +20 dressed batch on a stayed-closed form.
**Fails if:** ±1 tolerance also forgives a real ±1 gap → a colonnade/one-ring-thin wall reads closed (T-206
invariant breaks → proud-relief vs open-colonnade need interior-fill evidence, name it); the ±1 census
double-counts the declared aperture; or it re-introduces the T-202 over-correction (colonnade reads closed).
