## Context (self-contained)

Epic **E-35** / Story S-147. The articulation idioms are missing from `src/pack/idiom-registry.mjs`
(18 brushes): no `pilaster`, `quoin`, `infill-panel`, or `eave-overhang`. `timber-frame`
(`src/form/placement-grammar.mjs`) paints frame **lines** but stops short of the repeating stud+panel
**infill** that makes a half-timber wall read. `jetty`/`dormer`/`plinth` constructs exist
(`src/form/idiom-constructs.mjs`) but are "not [wired into the program path] at all." This ticket
builds the idioms on **T-146-01's relief op** and wires the existing constructs to the recognised
grammar (T-145-01). Registry door only ([[brush-door-export-not-allowlist]]): composition, tests,
preview card; never widen an allowlist. Vocabulary authority holds
([[vocabulary-authority-one-composition-point]]).

## Acceptance Criteria

- [ ] **Four new registry brushes**, each emitting through T-146-01's relief op, each with
      `composition` / `tests` / a `preview` card on the idiom-card:
      - `pilaster` — proud vertical strip on a rhythm (period from the grammar), preserving the rake;
      - `quoin` — corner stepped accent (alternating stretcher/header run up the corner);

        wall plane.

      grammar (T-145-01: per-storey jetty depth, dormer count/placement) actually builds — currently
      unwired.

      the conformance sweep is green (no named-vs-shipped drift); the new idioms appear on the
      idiom-card; no per-building constants.
- [ ] Tests for each brush (placement, rhythm, idempotence, silhouette no-regress via T-146-01's
      harness) + preview cards; `npm test` green; `--repro`/`--offline` byte-identical.
