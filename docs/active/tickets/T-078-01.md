## Context (self-contained)

Epic **E-23** / Story **S-078** — the substrate. Editing on raw 3-D voxels doesn't fit the LLM (the E-15
surgical loop overflowed context at 57k blocks — `[[surgical-edit-path-scale-limit]]`; the cottage face
failed because 3-D feature space has no storey axis). The fix: hand the LLM a **view**. This ticket builds
the shared layer the two downstream paths (spray-paint, hollow/floorplan) and the model-routing seam all
stand on.

## Acceptance Criteria

- [ ] **Multi-angle view reader** — render the build via the **E-22 fixed lens** (supersampled,
      `render/src/render.mjs`) from **ortho (6) + 45° (diagonals) + arbitrary 3-axis** angles. *Reading*
      from any angle is in scope.
- [ ] **2.5-D projected surface grid** for **ortho/45° projections only**: a 2-D cell grid where each cell
      carries the front-most surface voxel along its ray **+ depth + normal**. This is the paint canvas
      (S-079); back-projection here is unambiguous. (Arbitrary-oblique paint-back is explicitly out — E-23
      scope.) Round-trip tested: project → back-project returns the same surface voxels.
- [ ] **Structural read** (pure/geometric, GL-free): **footprint**, **storey bands** (horizontal
      material/floor lines), **opening positions** (doors/windows) from the occupancy. The storey line is
      the shared primitive (S-079 plaster band start; S-081 floor heights). Also expose **roof region** and
      **wall fields** (S-084 consumes these).
- [ ] **Same-angle reference capability**: render the **textured GLB at the same angle** as a projected face
      and **grid-quantize it to that face's cell grid** (`src/color/image-grid.mjs` `gridFromImage`) — the
      cell-aligned material target the S-079 splat consumes. (Reading any angle is in; this is the read side.)
- [ ] Pure cores (projection grid, back-projection, structural read) **unit-tested on synthetic occupancy**;
      one **live multi-angle render of the cottage** as the GL proof (saved under the work dir).
- [ ] `npm test` green.
