## Context (self-contained)

Epic **E-18**. The persistent speckle/palette-bloat had a **single root cause** (user-diagnosed): the
CIE-Lab voxel picker snapped each cell to the nearest of the **full 305-block table** (R1 `glbVoxelBuild`)
or a **median-cut of the noisy TRELLIS texture** (R2/seg) — "a larger universe of options" — instead of
the few blocks the **design doc** actually chose. Measured: the **heart R1 build used 91 distinct blocks;
the design doc chose 5**.

The fix is in (`src/form/glb-voxel-build.mjs` `paletteFromManifest(manifest, table)` — the original build's
`palette.manifest` as the `nearestLab` candidate set, namespace-tolerant; `glbVoxelBuild` and
`segmentMaterials` both accept `opts.palette`; the R1 + seg runners now pass it). **This ticket makes that
discipline a guarantee, not a convention** — audit every build path, regenerate the artifacts so the
committed numbers reflect it, and add a guard so it can't silently regress. It is the gate before the
consolidation scorecard (T-061-01), so the final picture is the corrected pipeline.

## Acceptance Criteria

- [ ] **Audit:** every voxel-build entry point that assigns block colors — R1 (`glbVoxelBuild`, breadth
      runner), R2/seg (`segmentMaterials`, seg runner), the **integrate** combined build (T-060-01), and
      the **surgical R3** path — uses the **augmented design-doc palette** (`paletteFromManifest` +
      T-058-03's gated secondary) as the candidate set. **None** snaps over the full 305-block table or a
      texture-median-cut palette. Fix any that does.
- [ ] **The palette = design-doc ∪ gated secondary.** Every placed block is either in the subject's
      design-doc manifest OR one of its **≤2 gated secondary** blocks (T-058-03), and each secondary on
      record passed the fit/gain/coverage gate. "Off-palette" now means *outside this augmented set* —
      that count is **0**; it is NOT a return to the full-table universe.
- [ ] **Regenerate** the affected committed artifacts (R1, R2/seg, integrate) for **all 7 subjects** with
      the design-doc palette; renders refreshed.
- [ ] **Verify across all 7**, in a committed record (`benchmarks/sculpture/palette-discipline.{md,json}`):
      **off-(augmented-palette) count = 0**, **distinct-block count ≤ design-doc palette size + 2**
      (secondary cap), and the **before→after drop** vs the pre-fix builds (e.g. heart 91 → ≤7). No subject
      exceeds design-doc + the gated secondary.
- [ ] **Guard:** a test/assertion that fails loudly if a build path's manifest contains a block outside
      its **augmented palette** (design-doc ∪ the ≤2 gated secondary) — so a future full-table snap can't
      slip back in, while the gated secondary is permitted.
- [ ] Form IoU **not harmed** by the tighter palette (form is geometry; recorded steady); `npm test` green.
