## Context (self-contained)

Epic **E-36** / Story S-151. `src/form/pin-guard.mjs` refuses a write when the path is **tracked in
git** (`decidePinWrite`: "tracked = path is committed (a pin)"; `guardedWriteRecord` takes a
`trackedSet`). So every committed file is treated as a frozen pin — including **draft build artifacts**.
Live proof (2026-06-14): `npm run generated:barn` (even `--skip-gate`, judge-free) was refused on
`generated/barn/{base-artifact,component-plan,grammar-artifact,artifact}.json`; the guard refused the
*improved* barn because its bytes differ from the committed Jun-11 one. The refusal also got swallowed
into a secondary failure-record write error, masking the real chain behavior.

**Stays frozen (the instrument allowlist) — must still refuse silent overwrite:** multi-angle judge
verdict records (`benchmarks/sculpture/multi-angle/*`), ratified packs of record (`packs/*.json`),
committed baselines/milestones (`pattern-book/*-baselines.json`, `*-milestone.json`,
`facade-baselines.json`, etc.), and `retired-pins.json`. **Becomes free (drafts):** `generated/*`,
`workshop/*` ledgers + final-artifacts that are not the subject of a committed verdict, `recognition/*`
programs, chain intermediates. The dividing line (E-36): **frozen once MEASURED; draft until then.**
Surgical — narrow the freeze, never remove it (Rule 1).

## Acceptance Criteria

- [ ] **Pin-guard fires on a curated instrument allowlist, not "tracked-in-git."** `decidePinWrite` /
      `guardedWriteRecord` / `preflightPins` decide "is a pin" by membership in an explicit instrument
      set (judge verdict records, ratified packs, committed baselines/milestones, retired-pins), not by
      git-tracked status. The allowlist is one named, documented place.
- [ ] **Draft writes need no flag.** Regenerating any draft (`generated/*`, `workshop/*` pre-verdict,
      `recognition/*`, chain intermediates) overwrites freely — **no `--rotate-pins`**. Concretely:
      `npm run generated:barn --skip-gate` completes and persists fresh artifacts with no pin error.
- [ ] **The frozen set still refuses silent overwrite** (regression test, the load-bearing half of this
      ticket): a committed judge record, a ratified pack, a committed baseline/milestone, and
      `retired-pins.json` each still throw without `--rotate-pins` / sanction. Reproducibility-by-replay
      of a committed measurement is unchanged.
- [ ] **Un-swallow the masked error.** A guard refusal during a chain must surface as itself, never be
      re-thrown as a confusing secondary failure-record write (the catch-block at
      `generated-milestone.mjs:~534-545` must not attempt a guarded write that masks the original
      cause).
- [ ] No new ceremony (E-36 Rule 2 — prefer curating/deleting over adding a gate); `npm test` green;
      the instrument contract untouched.
