## Context (self-contained)

Epic **E-21**, the "**refine according to the original concept art**" step. The map (T-071) + feature
assignment (T-072) get materials *mostly* right, but feature heuristics mis-zone some regions (a buttress
read as wall, a gable mis-materialed). This pass lets the LLM **correct material regions against the
concept** — the material analogue of E-15's form surgical loop, reusing its machinery with a **material**
target.

## Acceptance Criteria

- [ ] A concept-grounded **material-correction pass**: render the build → the LLM sees **render + concept**
      → proposes bounded **recolor-only** corrections to material regions (**no geometry change**) → apply
      under the E-15 region-lock, **accept-if-closer to the concept's material zoning**, else roll back;
      bounded rounds; accepted regions lock (P14-safe).
- [ ] **The LLM may ADD a block back into the palette** when it catches a **material present in the concept
      but missing from the build** (a "missing texture"). This is a *right*, gated by **concept
      justification**, not a hard cap: each addition must name the concept material + where it appears, be a
      real survival block, and be a **distinct material role** (a near-tone block like cobblestone alongside
      stone_bricks is allowed — that is the point; a near-*duplicate* with no new material role is not).
      Additions are logged with their justification. This is **concept-justified growth**, NOT a return to
      the full-table snap (the 91-block bloat).
- [ ] **Palette policy (reconciled):** E-21's allowed palette = the **design-doc manifest ∪ the ≤2 gated
      secondary (E-19) ∪ the LLM concept-justified additions**. "Off-palette" is checked against *this*
      augmented set (still no full-table snap); E-19's stricter design-doc-only guard applied to the
      pre-E-21 builds and is intentionally superseded here by the concept-grounded authority.
- [ ] Reuses the E-15 loop (`reviseLoop` / region-lock / accept-gate) with a material target, not a new
      loop.
- [ ] Run on the **gatehouse**: the corrections (kept/rolled-back) recorded + material-region agreement
      with the concept **before/after** (improves or honestly holds).
- [ ] Pure correction-application/bounds logic unit-tested (live multimodal call metered/GL); `npm test`
      green.
