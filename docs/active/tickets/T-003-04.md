## Context

Epic E-02, spec §4. Expose construct + render as a single tool the Agent SDK invokes with a design artifact, returning the rendered image. In the single-language JavaScript stack this is naturally an **in-process Agent SDK tool** (a standalone MCP server is optional). Combines T-003-02 (voxel-world construction) and T-003-03 (headless render), resetting world state between trials. This is the seam the experiment harness calls during a trial (and, later, for multimodal revision turns).

## Acceptance Criteria

- [ ] A tool accepts a design artifact and returns a rendered image (PNG path).
- [ ] The tool internally constructs the world (T-003-02) then renders it headless (T-003-03), resetting state between trials.
- [ ] The tool is invocable from an Agent SDK session (in-process tool or MCP server).
- [ ] Invoking the tool on a sample artifact returns a correct image.
