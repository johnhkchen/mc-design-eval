## Context

Epic E-14 / story S-039 — the keystone seam, gates the whole epic. Build the **shared color contract**:
a pure resolver that snaps a design doc's proposed palette to the **block-Lab table** and surfaces each
block's *true rendered value*. This is the root-cause fix from the E-13 frontier — the doc names blocks,
the concept previews hue, the render exposes value; pin all three to the table up front.

Do: add `resolveValueTruePalette(names | designDoc)` to `src/color/` (pure, GL-free), reusing E-10
(`loadBlockTable`, `nearestLab`, `srgbToLab`, `resolvePalette`). For each named block: if it's a real
full-cube block, return its table Lab/hex/value; if it's non-cube / biome-tinted / **imaginary**
(model-invented), return the **nearest real full-cube block** by ΔE + a `snapped: true` flag and the
original name. Emit a **value-honest palette card** (per block: name, hex, Lab, L\* value, snapped?).
The return shape is the contract S-040 (concept) and S-041 (build) both import — design it for both.

## Acceptance Criteria

- [ ] `resolveValueTruePalette` exists in `src/color/`, pure and GL-free, exercised by the
      `src/**/*.test.mjs` glob with **no** model/GL/network.
- [ ] Unit tests prove: real blocks pass through with table Lab/value; an **imaginary** name (e.g.
      `gold_leaf`) and a **non-cube** name (e.g. `oak_stairs`) each snap to the nearest real full-cube
      block with `snapped: true` + the original name preserved; output is deterministic.
- [ ] A value-honest palette **card** is produced (per-block name/hex/Lab/L\*/snapped) — the artifact
      the concept swatch grid (S-040) and the build target values (S-041) consume.
- [ ] `npm test` green.
