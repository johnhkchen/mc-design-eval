## Context (self-contained)

Epic **E-17** runs an **ablation sweep** across all 7 E-13 sculptural subjects to make each technique's
contribution legible. Rung **R1** is the **GLB-voxel build** — E-16 proved voxelizing a TRELLIS image→3D
mesh is the decisive *form* win (koi +0.150, heart +0.421 IoU vs text→JSON) but built it on **koi + heart
only**. This ticket generalizes the proven path to **all 7 subjects** (the GLBs now exist on disk).

The path already exists from E-16: `glbVoxelBuild` (GLB → `voxelizeGlb` occupancy → E-10 value-true color
→ `DesignArtifact`) + the GLB silhouette form-IoU. The 7 subjects ↔ runs ↔ GLBs:
`002-dancing-man`, `003-moai-statue`, `004-pineapple`, `005-bow-and-arrow`, `006-heart`, `008-mushroom`,
`009-koi-fish` → `glb/{dancing-man,moai,pineapple,bow-and-arrow,heart,mushroom,koi}.glb`.
**`007-sword` is excluded** — TRELLIS 500'd on the thin blade (3 attempts), no GLB (`glb/README.md`).
