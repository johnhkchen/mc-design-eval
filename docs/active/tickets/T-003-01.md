## Context

Epic E-02, spec §3. **No Minecraft server and no Mineflayer** — voxel models are rendered headless using existing Minecraft rendering tools (decided: TypeScript + prismarine-viewer; see CLAUDE.md). This ticket scaffolds the TypeScript render environment: pin a Minecraft version via `minecraft-data`, load block textures/models via `minecraft-assets`, create an empty in-memory `prismarine-world`, and stand up a headless render path (prismarine-viewer in headless Chromium via Playwright, or headless-gl) that renders a world to a PNG. Pinning the version also fixes the canonical block-ID vocabulary used by the schema (T-001-01) and palette (T-001-04).

## Acceptance Criteria

- [ ] TypeScript project with a pinned Minecraft version (`minecraft-data`) and `minecraft-assets` textures loaded.
- [ ] An empty in-memory `prismarine-world` can be created programmatically.
- [ ] A headless render path renders a world to a PNG file with **no Minecraft server and no bot running**.
- [ ] A sample (e.g. single-block) world renders to a correct image.
