## Context (self-contained)

Epic **E-35**, terminal story S-149, second ticket. **T-149-01 shipped the deterministic slice and a
runbook — it did not switch the machine on.** All four upstream parts landed (facade-grammar schema +
recognition pass, the relief-by-construction op + 2.5-D relief read, four articulation brushes
[registry 24→28], the relief-aware gate lens) and the relief join is wired at every realization site,
proven **inert** on today's facade-less programs (byte-identical, `npm test` 2098/2098). But **no real
subject carries a facade grammar** (only a synthetic `recognition/facade/fixture-house`), every build
record is relief `armed:false`, and the cottage/barn renders are **still flat boxes**. The epic's
actual deliverable — *does the flat box become the articulated build at the glance?* — is **unmeasured**.

Two gaps block the first real articulated render, and one is upstream of texture entirely:

1. **The band0 coverage reject (blocks the cottage gate outright).** T-143-02's live cottage gate
   **coverage-rejected all 4 views**: band0 `stone_bricks` 1135/1920 reported missing (59%), so the
   resemblance judge never ran. This is the "dressing breaks runs" family ([[presence-is-a-fixpoint-not-a-census]],
   [[surface-paint-respects-run-rule]]) in a severe form. **Do not assume it is a bare build** — this
   class has repeatedly been the *instrument*, not the build (the church band0 read 91.5% stone-family
   yet censused the literal name `stone`; [[church-band0-is-material-assignment]], [[recognize-blocks-dont-color-match]]).
   The T-143-02 review's own phrasing — "component-skin must re-derive coverage against the workshop's
   output" — points at a stale census reference. Diagnose before fixing.
2. **The live E-35 slice was never run** — facade recognition + relieved workshop build. Both run on
   the `claude -p` subscription shim + GL (available; the T-143-01 barns ran live the same way). **No
   judge run is in scope here** — the judge verdict (singular, billed) stays the runbook's later step;
   this ticket buys the *glance* (the first articulated render), not the verdict.

This also unblocks E-34's cottage: the band0 fix is what stands between T-143-02's clean proportion
answer and a cottage that can reach the judge at all.
