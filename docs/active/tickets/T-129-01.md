## Context (self-contained)

Epic **E-32** / Story S-129. The facade era — whose output looked good — ran model calls as **typed
BAML functions** (`baml_src/`: conceptart, facade, materialmap, judge, review, revise;
`@boundaryml/baml` in `package.json`; `npm run baml:gen`); the geometric era sidelined that into
ad-hoc prompt+AJV seams. Typed functions with fixtures are testable, reviewable, reusable; inline
prompt strings are none of those. This ticket revives the convention for the E-31 design seams.

## Acceptance Criteria

- [ ] **Four BAML functions** in `baml_src/` with input/output schemas + pinned fixtures/tests:
      (a) **idiom recognition** (concept + conditioned sketch → building program; migrates the
      T-125-01 seam), (b) **workshop critique** (renders + concept → structured per-region critique;
      migrates the T-126-01 seam), (c) **vernacular reasoning** (theme brief → material story; new,
      consumed by T-130-01), (d) **concept decomposition** (style + registry state → brush work-item
      specs; new, consumed by T-131-01). `npm run baml:gen` wired into the build; generated client
      never hand-edited.
- [ ] **Transport on the subscription shim — hard constraint**: no metered API keys anywhere in BAML
      config or env. Research decides the mechanism (BAML-native with a local shim proxy, or the
      facade-era pattern: BAML as schema/prompt/test authority with a thin adapter executing through
      `src/sdk-binding.mjs` / `ClaudeStub`); the decision + proof recorded. Raw replies committed
      (T-114 ledger pattern).
- [ ] **The frozen judge untouched** (E-32 Rule 2): no migration, no prompt change — instrument
      surface. A test/grep proves the judge path has no BAML dependency change.
- [ ] **Runners migrated behavior-preserving**: T-125/T-126 runners call the BAML functions; their
      committed records re-verify (`--offline` byte-identical where no live call is made); ad-hoc
      prompt strings retired from the new runners (grep recorded).
- [ ] `npm test` green (BAML fixtures included); no per-building constants.
