## Context

Epic E-02, spec §3. Build an in-memory `prismarine-world` from a normalized (primitive-expanded) artifact: write each voxel's block type and block state/orientation directly into the world data. Consumes the expanded voxel set produced by **S-001** `T-001-02` — this is the cross-section seam where the render harness reads the artifact contract. No bot and no placement actions; blocks are set directly in the world.

## Acceptance Criteria

- [ ] Given an expanded artifact, every voxel is written into the in-memory world at the correct coordinate with the correct block type.
- [ ] Block state/orientation is set where applicable (stairs, slabs, directional blocks).
- [ ] World construction is deterministic and reports any unknown/unmappable block types.
- [ ] A known small artifact builds the expected world structure.
