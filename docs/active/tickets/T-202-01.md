## Context (self-contained)

Epic **E-52** / Story **S-202**. The unblocker. The E-49 capstone (T-201) showed `closureOf` collapsing
**1.000 → 0.068** after `relief_walls` though the shell is physically intact — `eaveRingClosure`
(`src/view/wall-generate.mjs:275`) folds **every** band column `(x,z)` into the perimeter, so the **224 proud
quoins + 106 plinth cells** standing outside the wall plane register as "open." The climb's gate then turned on
the build (round 5 re-picked `close_shell`, which no-op'd — proud columns also defeat footprint registration),
and on a longer budget it oscillates. Make the form-readiness signal **invariant to proud detail**: measure
closure on the **wall plane / footprint**, not over all band columns.

## Falsifiable claim (anti-hedge — lead with how it fails)

A wall-plane/footprint closure metric stays **high** on the real T-201 relief build (detail stays unlocked, no
oscillation) **and** reads **low** on a genuinely reopened shell. **Fails if:** it over-corrects → blind to a
real hole (a true reopened shell now reads closed — the metric is wrong the other way); the wall plane isn't
cleanly separable from proud detail on this geometry (name it); or it shifts the 0.9 form-ready threshold
calibration (re-pin with a failing test).

## Acceptance Criteria

- [ ] `eaveRingClosure` (or a successor) measures closure on the wall plane/footprint so proud quoins/plinth
      don't crater it; **one closure authority** reused, not a third metric.
- [ ] **Unit-tested both ways:** the real T-201 relief geometry (224 quoins + 106 plinth) → stays **high** (≥
      form-ready); a genuinely reopened shell (real holes) → still reads **low**. Counts from T-201 used as the
      fixture.
- [ ] `formReadyGate` + the 0.9 threshold still gate correctly on the new metric (detail blocked on open,
      allowed on closed-with-relief); re-pin the threshold with a test if it moves.
- [ ] Recorded honestly: does relief now preserve a closed reading on the real build? Any threshold re-pin
      documented.
- [ ] `npm test` green; frozen instrument untouched.
