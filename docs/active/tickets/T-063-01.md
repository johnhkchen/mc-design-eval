## Context (self-contained)

Epic **E-19**, the stray-geometry fix — **no SAM** (user directive; stay geometric). Voxelizing a TRELLIS
mesh leaves content not in the reference: floating islands and (moai) **duplicate masses + hallucinated
connecting bars** (its concept was a 3-view contact sheet → TRELLIS meshed multiple statues; ≥3 connected
components, IoU 0.565). Fix geometrically: keep the **principal connected component(s)**, drop the rest.

Also fix a **verified bug**: the integrate/combined build (`benchmarks/sculpture/e18-remeasure.mjs:187`)
passes `palette: prim` (primary design-doc only) though its rationale says "augmented" — so the ≤2 gated
secondary blocks (T-058-03) are **computed but never placed**. Pass `aug`.

## Acceptance Criteria

- [ ] `pruneStrays(occupancy, opts) → occupancy`: connected-component analysis (face-adjacency); **keep the
      largest component plus any ≥ a size floor** (so a legitimately separate part — e.g. an arrow — is
      kept), drop small floating islands. Deterministic, pure, GL-free.
- [ ] Unit-tested: a main mass + a tiny floating island → island removed, main kept; two large legitimate
      parts → both kept; a size-floor boundary case behaves as specified.
- [ ] Wired into the build path; applied ×7. **moai is the headline**: extra statues/connectors removed →
      **largest-component fraction ≈ 1** (or the few legitimate parts), stray count → ~0; form IoU recorded
      (expected to rise as the spurious silhouette mass goes away).
- [ ] The integrate/combined build passes the **augmented** palette (`aug`), so the gated secondary blocks
      are actually placed (verified in the resulting manifest).
- [ ] Stray-voxel count **before/after** per subject (S-062 metric); `npm test` green.
