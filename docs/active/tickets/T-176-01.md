Sourced + critique-refined treatments lift the gatehouse's style-aware (E-41) self-concept score **above
the token baseline (42)** and read as the concept; the same vocabulary yields correct roof overhangs +
opening reveals. **Fails if:** recognition-authored treatments underperform hand-authored (→ a curated
style pattern-book is the answer, reported); the score lifts but the render reads **busy/over-articulated**
(amplitude refinement overshoots — the glance overrules); or roof/openings need element-specific edges the
wall vocabulary can't express (the unification leaks — report where).
