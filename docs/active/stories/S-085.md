## Background (self-contained)

Epic **E-24**, the architectural fix. The E-23 spray-paint applies material by **splatting a concept-color
target** per cell — but that **cannot establish a zone's dominant material**: on the cottage it converted
only **9%** of the upper-storey wall to plaster (64% stayed stone) because quantization collapses near-tones
and the concept→face stretch misaligns. The good result (77% plaster) was achieved by a **structural
zone-fill** applied *inline by hand* — not reproducible.

## Goal

Make the zone-fill a **first-class, deterministic pipeline step**: for each structural zone
(E-23 `structuralZones` — base / upper / roof), fill the **wall-field surface** with that zone's **dominant
material** from the E-21 material map (base=stone, upper=plaster, roof=wood), **keeping the secondaries**
(the `dark_oak_log` timber studs, trim) intact. The splat/LLM is **demoted to placing secondaries** over
this base coat, not establishing it.

The result: the cottage upper storey reads as plaster (≈77%, not 9%), produced **by the pipeline** — the
inline fix made durable.

## Builds on

- E-23 `structuralZones` (the zones) + `src/view/face-paint.mjs` (back-projection) + the E-21 material map
  (the dominant block per zone/role) + `src/view/structural-read.mjs` (wall fields, floor lines).

## Run-the-test ticket

- `T-085-01` — implement the deterministic zone-fill (dominant material per zone, secondaries preserved),
  wire it into the spray-paint pipeline ahead of the splat; run on the cottage; record the upper-band
  plaster coverage (9%→≈77%) reproduced by `npm run`, no hand-edit. Pure fill unit-tested.
