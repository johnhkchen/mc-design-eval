## Background (self-contained)

Epic **E-15** builds a region-scoped revision loop to fix the **form** defects our measurements found:
text→JSON keeps a subject's palette + parts but loses its *line* — a **koi's swimming S-curve** flattens
to a straight chunky body; an **anatomical heart's aortic arch never builds as a loop**. These are not in
any procedural pass's vocabulary (E-11's passes do `flat→relief`, `drab→material` — material/depth, not
*form*). So the loop needs a second tweak primitive: a **freeform LLM block-edit** for form.

By the time this story runs, the loop's **cage is already built and proven** (S-045): the
observe→tweak→re-observe→**accept-if-improved** machinery converges, locks accepted regions, prevents
edits from bleeding past the region-lock, and **rolls back any tweak that doesn't raise the form metric**
(silhouette IoU, S-043). This story adds the LLM editor as *just another editor behind that same gate* —
which is the whole reason the cage was built first: a freeform model editor is only trustworthy inside a
demonstrably tight cage. (If adding it required changing the loop's control flow, the cage abstraction
was wrong — it shouldn't.)

## Goal

An LLM form-edit route: `observeRegion` gives the model a tight crop of region R; the model returns a
**bounded edit** — `add` / `remove` / `move` / `swap` of placements *within R only* — which is applied
under the region-lock (out-of-R edits rejected, result re-validated by the AJV gate) and **kept only if
the per-region form IoU improved**, else rolled back. The critic routes *form* defects here; *known*
defects still route to the procedural passes (S-045). Reuses the project's structured-output seam
(`src/sdk-binding.mjs`) and a BAML edit schema, mirroring the build/judge stages.
