## Background (self-contained)

Epic **E-35** (facade-grammar-and-relief — M1's texture finish, the twin of E-34's proportion
finish). The build's program (Stage 3 recognition, `docs/knowledge/pipeline-philosophy.md`) is
*supposed* to carry the facade grammar — the philosophy lists "openings on a rhythm; jettied
timber-frame upper; stone plinth" as program output. Today it names bands and dominant blocks, not
the **rhythm** (stud/pilaster spacing), the **fields** (infill between frame members), the **corners**
(quoins), the **overhang** (eave/jetty depth), or per-face placement on the faces the single concept
view never shows. A flat box is what you get when the program is silent about all of this.

## Goal

Stage 3 emits a **facade-grammar** program: per-face rhythm, panel fields, quoins, course lines, eave
overhang + per-storey jetty depth, openings on a rhythm — schema-validated against the style pack.
It reads concept **and** textured-GLB multi-angle renders for **spatial layout** on the unseen faces
(back/sides/roof), per the 2026-06-14 ratified narrowing of "textures never read" (spatial-layout
evidence only, never material; palette stays diegetic). Light tier for scoped per-face detectors;
strong for the design judgement. Each row records which evidence (concept vs GLB) sourced it.
