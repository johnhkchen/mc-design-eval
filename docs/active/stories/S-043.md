## Background (self-contained)

Epic **E-15** builds a *surgical revision loop* — a region-scoped observe→tweak→re-observe→
**accept-if-improved** cycle — to close the **form** gap our measurements found: text→JSON builds keep a
subject's palette + parts but lose its *line* (a koi's swimming S-curve flattens; an anatomical heart's
aortic arch never loops). The loop hill-climbs: it keeps a tweak only if some number went up. **Color had
that number** (the E-14 concept↔render Δvalue/ΔE gate). **Form does not yet.** This story builds it — and
must come first, because without it the whole loop is "looks better to me," which is exactly the
undisciplined judgment this project avoids.

The signal is available: a `vConcept` build is rendered at a fixed 3/4 view (`SCULPTURE_VIEW_3Q` in
`src/sculpture.mjs`) and its **concept image** is a 3/4 view too — and **both are background-segmentable**
(the concept floats on solid black `#000000`; the render on a flat sky). So a **silhouette IoU** between
the two binary masks is a real, computable form-fidelity number. The loop also needs a **per-region** IoU
(over a sub-bounding-box) so the accept-gate has a *local* signal, not just a whole-object one.

## Goal

A pure, deterministic form-fidelity metric module: extract the build-render silhouette + the concept
silhouette, align/normalize, and compute **IoU** (whole-object) and **IoU over an arbitrary region**.
Mirror the E-14 precedent (`src/color/value-gate.mjs`): a segmentation-free-where-possible, unit-tested
scorer with an honest note on what it can and can't see.

## Builds on

- `benchmarks/sculpture/runs/*/{render-3q.png, concept.png}` (the matched 3/4 pair per build).
- The E-14 metric precedent (`src/color/value-gate.mjs`) for the shape: a small scoring module + a gate.
- Image decode utilities already in `src/color/palette-extract.mjs` (`decodeImage`) and image helpers.
