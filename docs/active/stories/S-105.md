## Background (self-contained)

Epic **E-27**. The roof-as-program (S-104) is one instance of a general capability the system needs:
**generating clean voxel constructs from fitted parameters** — lines and shapes built the way a player
builds them, instead of sampled from a mesh. The witnessed cases beyond the roof: the **gatehouse arch**
(judged "warm arched door" early, then lost/degraded through the pipeline — an arch is a parametric
curve, trivially generable), church window heads, and slope/edge transitions generally. The fixture-state
path (T-097) already proves stairs/slabs/trapdoors render correctly; what's missing are the *generators*.

## Goal

A small library of **pure shaped-construct generators**, each taking a fitted spec and emitting
state-correct placements: **stair runs** for slopes (any cardinal direction, both windings), **slab
half-steps** for sub-block transitions, **arches** (spring line + radius + depth fit to an opening
group, voxel-circle construction). Unit-tested on synthetic specs (orientation matrices exhaustively);
applied where the component record (S-103) names a candidate — the gatehouse arch and church openings
get generated arches, fit error recorded, inside the S-102 cage. Generators are subject-agnostic and
become the construction vocabulary S-104/S-106 and future epics draw from.

## Builds on

- S-103 component record (opening groups, edges to fit); T-097 state path (placement legality);
  S-102 cage (acceptance); E-26 kit (block family per construct).

## Run-the-test ticket
