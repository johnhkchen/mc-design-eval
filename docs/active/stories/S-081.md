## Background (self-contained)

Epic **E-23**, the **program path crossing into design** (Path A). The hollowed cottage (S-080) is an empty
shell. This story fills it: an **N×M grid floorplan** across the **N storeys**, generated by a program the
LLM authors/steers from the **below/plan view**.

**This is the first deliberate step across craft → design, and it changes the gate.** The interior has **no
reference** — the concept and GLB are exterior shells, there is nothing to copy. So "break the space into
rooms" is *invention*. We handle it the world-builder way (the LLM authors a **generator**, the program does
the placement — inspectable, scalable, deterministic) and we judge it with a **constraint/plausibility
gate**, NOT the resemblance gate (which has nothing to compare an interior to).

## Goal

1. From the **below/plan view** (S-078), read the footprint + storey lines.
2. The LLM **authors/steers a floorplan generator**: partition the footprint into an **N×M grid**, place
   **floors at the structural storey lines**, dividing walls on the grid, and **openings (interior doors)
   aligned to the exterior** (behind the front door, sensible per storey).
3. **Fill the N storeys** by running the generator (bulk placement is the program's job, not hand-placed).
4. **Plausibility gate** (the design-without-reference acceptance test): rooms are valid and non-overlapping,
   **reachable** (doors connect them / a path exists), floors sit at storey lines, the storey **count
   matches** the structural read, the grid **fits the envelope**, openings align with the shell. Report
   pass/fail per constraint + a named residual (Rule 7).
