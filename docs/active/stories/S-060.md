## Background (self-contained)

Epic **E-18** closes the two gaps E-17 left on the glb-voxel build: **speckle** (S-058 —
material-region segmentation → clean materials) and **thin form** (S-059 — thin-feature-preserving
voxelization → thin members survive). This story **combines them and re-measures** across the 7 subjects,
so the consolidation (S-061) is a pure read.

The combined build: voxelize with **thin preservation** (S-059) → color value-true (E-10) → **segment
materials** (S-058). Score it on the same axes the E-17 sweep used so the gains are directly comparable:
**form IoU vs the GLB**, the **speckle metric** (S-058), and **value ΔE**.

## Goal

For all 7 subjects: build the combined (thin-preserved + material-segmented) glb-voxel build, render, and
collect **form IoU + speckle + value ΔE** into one record vs the E-17 R1 (glb-voxel) / R2 (material-clean)
baselines — `benchmarks/sculpture/e18-remeasure.{md,json}`. The data spine for the scorecard delta.
