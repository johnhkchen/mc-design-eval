## Background (self-contained)

Epic **E-19** regains text→JSON's clean color/material on the GLB-voxel build (speckle, stray voxels, busy
texture). The fixes hill-climb on metrics — but two of the metrics we have are inadequate, so this story
(the root) fixes the scoreboard first:

- **No stray-voxel measure.** TRELLIS can reconstruct extra masses + hallucinated connectors (the moai
  shows ≥3 connected components — duplicate statues + bridging bars) and voxelization leaves floating
  islands. Nothing counts this.
- **`speckleScore` lies** (`src/form/material-clean.mjs`, T-058-01 review concern #4): it counts every
  face-adjacent differing-block pair, so an *intentional* material boundary (region edge) reads as
  "speckle." It rewards "paint it all one block" and can't tell **fragmentation** (bad) from a **clean
  boundary** (good) — so it can't certify cleanliness.

## Goal

Add a **stray-voxel / disconnected-component metric** (component count + largest-component fraction, over
the occupancy's face-adjacency) and **fix `speckleScore`** to measure *fragmentation* rather than *all
boundaries* — e.g. count only specks (a block differing from a strong neighborhood majority / isolated
singletons), so a large clean region with a sharp edge to another region scores ~0. Pure, unit-tested.

## Builds on

- `src/form/material-clean.mjs` `speckleScore` (the metric to fix) + the occupancy/`occupiedCells`
  adjacency helpers (`src/form/glb-voxelize.mjs` / `material-segment.mjs`).

## Run-the-test ticket

- `T-062-01` — add the stray-voxel/component metric; fix `speckleScore` (fragmentation, not boundaries);
  unit-test both on synthetic sets (a 2-region clean block scores ~0 speckle; a checkerboard scores high;
  a floating island is counted as stray). Record the E-18 builds' baseline on the fixed metrics.
