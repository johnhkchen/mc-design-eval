## Background (self-contained)

Epic **E-17** answers "what did each improvement actually buy?" by taking all 8 E-13 sculptural subjects
up one **canonical technique ladder** and scoring every rung the same way. The rungs:

```
R0  text→JSON       the E-13 baseline build              (runs/00[2-9]-*/artifact.json)
R1  glb-voxel       voxelize the TRELLIS GLB (E-16)       (S-054 — built)
R2  + material-clean clean the per-voxel color (E-17)     (S-055 — built)
R3  + surgical      E-15 region polish vs the GLB target  (this story runs it)
```

R0/R1/R2 exist by the time this story runs; this story **adds the R3 surgical rung** (run the E-15
`reviseLoop` on the cleaned voxel build with `formTarget: glbFormTarget({ glbPath })` — E-16's GLB target)
and then **collects every rung's metrics into one structured record** so the consolidation (S-057) is a
pure read, not a re-measurement. The metrics, identical across rungs: **form IoU vs the GLB**, **value ΔE**
(palette cleanliness), and **judge categorical**.

## Goal

For all 8 subjects: assemble the 4-rung ladder (R0–R3), running R3 (surgical on the R2 build, GLB target),
and emit one structured record — `subject × rung → { formIoU, valueDeltaE, verdict }` plus the per-rung
**marginal Δ** — to `benchmarks/sculpture/sweep-ablation.{md,json}`. The data spine for the scorecard.

## Builds on

- S-054 (R1) + S-055 (R2) + the E-13 builds (R0) + the E-15 surgical loop & E-16 `glbFormTarget` (R3) +
  the form-IoU metric (`src/form/`) + the value-ΔE gate (`src/color/value-gate.mjs`) + the judge.
