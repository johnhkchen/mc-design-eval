## Context (self-contained)

Epic **E-39**. The epic's whole bet is falsifiable; this story is the referee. Two claims to settle, each
with a fixture that can embarrass us:

1. **Split beats fused** (S-164's claim): does diagnose→route dispatch more correctly than the fused
   `WorkshopReply`? Both paths were kept runnable for exactly this bake-off.
2. **The within-family gradient now exists** (S-165's claim): the missing test asset from the E-38 wrong-
   style probe — a **clean build** (no capping geometry defect) scored against a **same-family wrong-style
   concept** — must **crater** under the per-style Layer-A judge, where the scalar eval left it flat (the
   probe got gatehouse/barn/cottage/church all 22–32, inside noise; the confound was that the build was
   itself defective, masking style). A clean build removes the confound.

## Falsifiable claim (anti-hedge — lead with how it fails)

(1) The split path's dispatch matches the worst-defect's correct department **more often** than the fused
path on a held set of builds; (2) a clean build scored against a same-family wrong-style concept scores
**far below** the same build against its matched-style concept (a real spread, well outside the eval's
noise). **It fails if:** split ties or loses to fused (the split is unjustified — report and recommend
collapse); OR the clean×wrong-style fixture does **not** crater (then the per-style `expected` is cosmetic
and the blindness is in the model's reading — the most important negative result, route it to a deeper
measurement epic); OR no build is clean enough to remove the confound (then S-160's geometry work or a
synthetic clean fixture is the prerequisite — name it).

## Acceptance Criteria

- [ ] A **bake-off harness**: run split vs fused on a fixed set of (concept, build) states; score dispatch
      correctness (did it route to the department of the actual worst defect?) and report the comparison —
      including if fused wins.
- [ ] The **clean × wrong-style fixture**: a clean build (real or synthetic) scored against (a) its
      matched-style concept and (b) a same-family wrong-style concept; report the spread and whether it
      craters. Renders beside both concepts as evidence.
- [ ] **Recorded honestly**: state which way each claim landed, with numbers and renders; if either fails,
      name the localized next gate (collapse the split / deeper measurement epic / clean-build prerequisite).
- [ ] `npm test` green; the eval instruments touched here are the **creation-loop** judges, not the frozen
      scalar instrument.
