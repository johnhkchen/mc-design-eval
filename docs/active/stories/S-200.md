## Context (self-contained)

Epic **E-49**, the co-lever the T-198 review named. The form stage decided "tie" on the **picture scalar** —
which has a documented **0–76 swing on the same seed** (round 0 scored 0 in one run, 16 in another; VOTES=3
median dampens but does not remove it). So a `close_shell` "tie" may be **vote noise**, not a real read. The
form-credit fix (S-199) keeps a form win through a tie; this story makes sure the *form decision itself* rides
a **clean, deterministic signal** so the credit is given on truth, not noise.

Two items:

1. **Finer form signal.** The form stage / form-credit term should judge a FORM move on **closureOf**
   (deterministic, T-197's `eaveRingClosure`) — not the noisy picture vote. Closing the shell moved closure
   0.615→1.000 *unambiguously*; that is the signal a form decision should turn on. Keep the picture scalar for
   the *detail* stage (it's the right gradient there); separate the two so noise in one can't corrupt the
   other.
2. **Port the `agentPick` parse hardening.** T-198 found + fixed a latent crash: the naive `parse` crashes on
   any two-object LLM reply (balanced-brace parse + re-ask-once-then-`done` fallback fixed it in
   `picture-climb.mjs`). `autonomy-loop.mjs` shares the idiom and carries the same latent crash — port it.

## Falsifiable claim (anti-hedge — lead with how it fails)

Deciding form moves on closureOf (not the picture scalar) makes the form decision **stable across re-runs**
(the close_shell keep no longer flips with vote noise), and the ported parse survives a two-object reply.
**Fails if:** closureOf is itself too coarse for some form move (a real form gain that doesn't move the ring
metric → need a richer form signal, name it); separating the signals changes a *detail*-stage decision
(scope leak — the detail gradient must be unchanged); or the parse port regresses an autonomy-loop fixture.
