## Background (self-contained)

Epic **E-31**, terminal. The epic's claim: a model that **recognizes** the concept's forms,
**substitutes** canonical pattern-book realizations, and **revises its own work** produces a build
that finally looks like the concept — where fourteen epics of mesh-metrology produced honest,
receipt-backed, *atrocious-adjacent* output. Project-best profiles to beat (the metrology path's
ceiling): cottage generated **10/2 with 2/4 same-object** (T-122); barn **12/2, 0/4** with
coverage/material majors (T-122). The product bar above both: sheets a human reads at a glance as
*clean builds of the concept's building*.

## Goal

**Cottage and barn through the full pattern-book path**: conditioned sketch → model-recognized
program → canonical realization → workshop revision (budgeted, ledgered) → **one frozen-gate run
each** (the epic's only judge calls; fresh renders, receipts `diffs: []`, T-114 for malformed replies
only; pins rotated under T-119). Recorded per subject: the committed program + ledger (replay
byte-identical), conformance results, the gate verdict vs the project-best profile, and the
**head-to-head table vs the metrology path** — journaled whichever way it falls. Honest outcomes are
the deliverable; if recognition mis-names a form and the workshop doesn't catch it, that is a measured
limit of the model's visual judgement — the thing this project set out to measure.
