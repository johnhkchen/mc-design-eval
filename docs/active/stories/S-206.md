## Context (self-contained)

Epic **E-53**, the lead fix. The E-52 capstone (T-205) stalled at score 0 because **T-202 over-corrected** the
form-readiness metric. The zero-spend seed probe is the smoking gun — the same open-colonnade gatehouse seed:

```
seed wall-band closure: 0.980          ← current eaveRingClosure (post-T-202 extent clamp)
close_shell ... closure 0.615 → 1.000  ← close_shell's internal measure of the SAME seed
```

T-202's `robustExtent` clamp (trimming perimeter extremes to ignore proud relief) **also absorbed the
colonnade's gaps**, so an open colonnade reads 0.980 = "form-ready." The form-before-detail gate (T-197) then
never picks `close_shell`, detail runs on an open form (E-51 disease), the build stays a dark colonnade, the
judge scores it 0 / keeps all majors → total stall.

The fix: measure form-readiness closure on the **absolute program footprint** (we have `program.masses[].rect`)
— a footprint-perimeter column with **no wall cell at the plane is open** (colonnade gaps read open); cells
standing **proud of the footprint** (relief quoins/plinth) are **ignored** (relief doesn't crater it). This is
the original T-202 goal done correctly: distinguish *missing cells inside the footprint* (open) from *extra
cells outside it* (fine) — T-202 conflated the two.

## Falsifiable claim (anti-hedge — lead with how it fails)

On the footprint metric: the **colonnade seed reads ~0.6 (< 0.9)** so the form gate forces `close_shell`; a
**closed shell with proud relief reads ≥ 0.9**; and the metric **agrees with `close_shell`'s internal measure**
(no more two-numbers-disagree). **Fails if:** the program footprint doesn't match the build's real wall plane on
this seed (the `AMBIGUOUS` axis/registration flag — closure still mis-reads → deeper geometry problem,
[[wall-construct-needs-dense-shell]]); or the proud-vs-missing distinction is leaky (some relief sits inside the
footprint plane / some gaps sit at the edge → re-introduces one error or the other); or fixing the colonnade
read re-craters the relief read (back to the T-202 dilemma → the two are fundamentally coupled, name it).
