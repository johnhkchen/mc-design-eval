## Background (self-contained)

Epic **E-18**, the **speckle fix**. The mature pipeline voxelizes a TRELLIS GLB into a build that wins on
*form* but whose **materials are speckled**: each voxel sampled the GLB texture independently, so adjacent
cells get scattered blocks. E-17's material-clean pass (R2) extracted a value-true palette from the
texture (E-10 CIE-Lab) and snapped each voxel + light neighborhood smoothing — which **narrowed but did
not eliminate** the salt-and-pepper noise (the heart's R2 still reads busy). The reason: per-voxel
snapping + a weak smoother can't enforce *regional* coherence.

This story replaces that with proper **material-region segmentation**: group contiguous voxels of the same
material into regions, and fill each region with **one** block. An isolated off-color voxel gets absorbed
into its region instead of surviving as a speck. Within a region we can still apply **E-11 material
texture** (a same-hue set varied by surface normal/height) so surfaces read as *deliberate* texture, not
noise.

## Goal

`segmentMaterials(build, opts) → DesignArtifact`: over a glb-voxel build's value-true voxels, region-grow
/ connected-component by Lab ΔE threshold in 3-D surface space → regions; fill each region with its
dominant value-true block (optional E-11 same-hue texture within a region). Demonstrate a **speckle-metric
drop** (neighborhood-disagreement rate / distinct-block count) without harming form IoU. Apply ×7. Pure
logic unit-tested.
