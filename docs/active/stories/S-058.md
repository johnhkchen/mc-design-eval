## Background (self-contained)

Epic **E-18**, the **speckle fix**. The mature pipeline voxelizes a TRELLIS GLB into a build that wins on
*form* but whose **materials are speckled**: each voxel sampled the GLB texture independently, so adjacent
cells get scattered blocks. E-17's material-clean pass (R2) extracted a value-true palette from the
texture (E-10 CIE-Lab) and snapped each voxel + light neighborhood smoothing — which **narrowed but did
not eliminate** the salt-and-pepper noise (the heart's R2 still reads busy). The reason: per-voxel
snapping + a weak smoother can't enforce *regional* coherence.

This story replaces that with proper **material-region segmentation** — but two specific symptoms (a
directive) need first-class attention, because they are *why* the speckle persists:
- **Palette leakage** — the build uses **many blocks beyond the intended palette** (per-voxel
  nearest-block over a loose/large palette + the E-11 same-hue expansion let near-duplicates in). The fix
  must hold a **tight, fixed palette**: a handful of value-true blocks, **zero off-palette blocks**,
  distinct-block count ≈ palette size.
- **Gradients break down** — the GLB texture has smooth gradients; snapping each voxel *independently*
  scatters a gradient into noise. A gradient region must become a **deliberate band or ordered dither**
  between two adjacent palette steps, never a per-voxel scatter.

So: under a tight fixed palette, group contiguous voxels of the same material into regions and fill each
region with **one** palette block (an isolated off-color voxel gets absorbed, not kept); where a region
carries a real gradient, band/dither it along the gradient direction. Within a flat region we can still
apply **E-11 material texture** (a same-hue set varied by normal/height — *but kept within the fixed
palette*) so surfaces read as *deliberate* texture, not noise.

## Goal

`segmentMaterials(build, opts) → DesignArtifact`: confine to a tight fixed palette (zero off-palette
blocks); region-grow / connected-component by Lab ΔE in 3-D surface space → regions; fill each region with
one palette block; band/dither gradient regions between adjacent palette steps (no per-voxel scatter);
optional E-11 same-hue texture *within the fixed palette*. Demonstrate drops in **distinct-block count,
off-palette count (→ 0), and speckle (neighborhood-disagreement) rate**, plus gradients that band cleanly,
without harming form IoU. Apply ×7. Pure logic unit-tested.
