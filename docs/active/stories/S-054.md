## Background (self-contained)

Epic **E-17** brings every accumulated technique together in one measured **ablation sweep** across all 7
E-13 sculptural subjects (dancing man, moai, pineapple, bow & arrow, heart, mushroom, koi; sword excluded), so the
contribution of each improvement becomes legible. The sweep's rung **R1** is the **GLB-voxel build** — the
E-16 finding that voxelizing a TRELLIS image→3D mesh is the decisive *form* win (koi +0.150, heart +0.421
IoU vs text→JSON). E-16 built and proved that path (`glbVoxelBuild`: GLB → occupancy → E-10 value-true
color → `DesignArtifact`) on **koi + heart only**. This story generalizes it to **all 7 subjects** — the
GLBs now exist on disk (`benchmarks/sculpture/glb/*.glb`, provisioned via TRELLIS; manifest in
`glb/README.md`), so this is mostly running a proven path across breadth.

## Goal

Run `glbVoxelBuild` across all 7 subjects → for each: a `glb-voxel` `DesignArtifact`, a render at
`SCULPTURE_VIEW_3Q`, and the form IoU vs its GLB. This is the **R1 rung** of the sweep for every subject —
the broad form-win baseline the later rungs (material-clean, surgical) build on.

## Builds on

- E-16 `glbVoxelBuild` + `voxelizeGlb` + the GLB silhouette/IoU path (`src/form/`, `benchmarks/sculpture/`).
- The 7 GLBs on disk (`glb/{dancing-man,moai,pineapple,bow-and-arrow,heart,mushroom,koi}.glb`),
  regen via `trellis-glb.mjs` if any is missing.
- E-10 value-true color (already inside `glbVoxelBuild`).
