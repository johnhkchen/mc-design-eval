## Background (self-contained)

Epic **E-23**, terminal — the milestone that proves the 2.5-D interaction sector by exercising **both paths
and both gates** on one build: **a hollow, accurate-looking cottage with an N×M grid infill.**

## Goal

Bring the pieces together and report honestly:

- **Exterior accurate** (S-079, judgement path / craft): the half-timbered face restored by spray-paint —
  plaster band back, the **resemblance gate** at *same-object* or a materially-narrowed *drifted* where the

- **Hollow** (S-080, program path): shell + structure, exterior render unchanged by the carve.
- **N×M grid infill** (S-081, program path / design): the N storeys filled, the **plausibility gate**

  subscription shim; the scoping recorded.
