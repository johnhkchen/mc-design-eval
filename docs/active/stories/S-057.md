## Background (self-contained)

Epic **E-17**, terminal link — the legible answer. The sweep (S-056) ran all 8 E-13 sculptural subjects up
the canonical 4-rung ladder (R0 text→JSON → R1 glb-voxel → R2 +material-clean → R3 +surgical) and collected
the same metrics at every rung (form IoU vs GLB, value ΔE, judge) into one record
(`benchmarks/sculpture/sweep-ablation.json`). This story turns that record into the thing the whole epic
exists for: a **scorecard that shows what each technique bought**, and a **per-subject march-of-progress**
you can look at. The motivating complaint — *"it's hard to tell what improvements got made yet"* — is
answered here, honestly (a rung that bought nothing, or regressed, is shown as such; the same discipline
as the E-14/E-15/E-16 consolidations).

## Goal

From the S-056 record, produce: **(1)** a **scorecard** — subject × rung with the per-rung metric AND the
**marginal Δ** each technique added, plus an **AVG / Δ row** ("on average, value bought X, form bought Y,
material bought Z, surgical bought W"); **(2)** a **per-subject march-of-progress** image (R0→R3 renders
side by side); **(3)** a **journal section** (`docs/knowledge/design-learnings.md`) stating the
attribution and the residual; **(4)** an **E-12 handoff** (`pr/assets/`) — the "bringing it all together"
beat (8 subjects climbing the technique ladder).

## Builds on
