## Background (self-contained)

Epic **E-19**, the **color/material cleanliness fix** — the heart of "regain the text→JSON cleanliness."
text→JSON builds read clean because the model uses a few **flat solid blocks** (concrete/terracotta/wool)
in coherent regions. The GLB-voxel build is busier for three documented reasons:

1. **Texture-busy blocks pollute the palette.** The block→Lab table scores each block by its **mean**
   color (`src/color/block-table.mjs` `meanOpaqueRgb`), so high-texture-variance blocks
   (`dead_brain_coral_block`, `nether_quartz_ore`, `mycelium`) win a mean-ΔE fit yet add *visual* noise
   back — visible on the heart's gated-secondary patch. (E-18 finding.)
2. **Gradients scatter on non-cardinal axes.** `material-segment.mjs` `gradientAxis` bands along the best
   cardinal i/j/k axis; a **diagonal** gradient (rounded organic surfaces) fragments into salt-and-pepper.
   (T-058-01 review concern #3.)
3. **`minRegion` eats legitimate detail.** The speck-absorb threshold (12 cells) removes real small
   features (mushroom cap spots) along with noise. (T-058-01 concern #1.)

## Goal

Three coordinated fixes: (1) **texture-variance-aware palette** — compute each candidate block's texture
variance (from the committed `minecraft-assets` textures) and **prefer flat blocks**, excluding/penalizing
busy ones from BOTH the design-doc snap and the gated secondary; (2) **PCA/true-axis gradient banding** so
a diagonal gradient bands cleanly along its actual direction; (3) **`minRegion` retune** (or a
noise-vs-intent test) that absorbs specks without eating legitimate small detail. Measured by the **fixed**
speckle metric (S-062) + visual before/after; the palette must stay flat-block.

## Builds on

- S-062 (the fixed speckle metric) + `src/color/block-table.mjs` (per-block texture/variance from assets)
  + `src/form/material-segment.mjs` (`gradientAxis`, `bandRegion`, `minRegion`, `absorbSmallRegions`) +
  `src/form/palette-augment.mjs` (the gated secondary, which must also exclude busy blocks).

## Run-the-test ticket

- `T-064-01` — texture-variance-aware palette (flat blocks preferred, busy excluded); PCA/true-axis band;
  `minRegion` retune; unit-test (a busy block loses to a flat block of equal mean ΔE; a diagonal gradient
  bands monotonically; a legitimate small region survives). Apply ×7; speckle drops, palette stays flat.
