## Goal

Epic **E-10**, the headline capability: **describe which blocks are actually in a facade picture →
the canonical block palette.** Given a concept image, cluster its colors in Lab, match each cluster to
the nearest real survival block (the S-019 table, via the S-020 engine), merge duplicates, and emit the
**canonical palette** — an ordered list of `{ block, repColor, coveragePct }` plus a human-readable
description ("terracotta 38%, gold_block 14%, lapis_block 9%, …"). This is the design's palette manifest
(§5/§6), derived from the picture instead of asserted.

## Builds on

- **S-019** (block→Lab table) and **S-020** (color engine). A concept image from `concepts/` (variant C).

## Run-the-test ticket

- `T-021-01` — implement palette extraction (cluster → match → canonical palette + description).
