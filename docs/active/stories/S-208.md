## Context (self-contained)

Epic **E-53**, **CONTINGENT** — built only if S-207's re-climb (on a corrected, genuinely-closed form) **still
stalls at score 0**. If S-207 reached the picture, the form fix sufficed and **this story is a documented
no-op** (anti-hedge: it must be allowed to be unnecessary; do not build a speculative mechanism the evidence
doesn't demand).

The gap it would address (if confirmed): a **score-0 cold start**. The picture-score judge can saturate at 0 —
on a build far from the picture it scores 0 and keeps all department majors, so **no single detail hand clears a
major or beats 0** (T-205 trajectory: `deptMajorsBefore == deptMajorsAfter` every round). The greedy per-move
accept-gate then rolls back every hand as "tie at 0 — no shrink," and the build can never escape the cold start
even though the hands work and *compounding* several would read better. This is the picture-scalar-reliability
problem (the documented 0–76 swing; the E-49/E-50 co-lever) surfacing for **detail** moves — E-49's form-credit
fix solved it only for **form** moves (judged on deterministic closure).

**Diverge before converge** ([[diverge-before-converge-experiment-freedom]]): spike candidate escapes, judge on
the glance, let the strong one win — don't pre-commit the algorithm. Candidates:
- **Provisional-accept-then-judge-the-batch:** let N detail moves stack un-credited, then accept/reject the
  compound vs the pre-batch build (escape the greedy local minimum).
- **Structural fallback signal:** when the VLM scalar saturates at 0, fall back to structural deltas (pale field
  present? wide opening present? slate roof present?) for the keep/rollback decision.
- **Lower the judge's floor:** make the diagnose score differentiate near the bad end (a finer scale) so
  improvements register — a measure fix, not a gate fix.

## Falsifiable claim (anti-hedge — lead with how it fails)

The chosen escape lets detail hands **compound off a score-0 cold start** so the climb leaves 0 and the build
improves on the glance — and a re-climb reaches the gatehouse's picture (or a higher, glance-agreed plateau).
**Fails if:** S-207 already reached the picture (then this is correctly a **no-op** — report and close); the
escape **credits genuinely-bad compounds** (lets a worse build through because the batch scalar is noisy too →
the rubber-stamp risk, guard it); or the score is **so unreliable** that no batch/structural signal is
trustworthy (then the real fix is de-noising the judge, not the gate — name it).
