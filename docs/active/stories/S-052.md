## Background (self-contained)

Epic **E-16**, the **synthesis** — the capability the whole arc has been pointing at. Two pieces now
exist:
- a **GLB-voxel build** (S-051): a `DesignArtifact` voxelized straight from the TRELLIS mesh, so it
  carries a real 3-D *starting form* (the koi's actual curved body, the heart's actual lobed shape) where
  the text→JSON build lost that line — but it also carries voxelization artifacts (stair-stepped
  surfaces, a fin that reads thick, an arch that nearly closes);
- the **E-15 surgical region loop** with a **GLB form target** (S-049's `glbFormTarget`): observe a
  region → diagnose → bounded tweak (procedural pass *or* LLM block-edit) → re-observe → **accept only if
  the per-region IoU vs the GLB improved**, P14-safe (rolls back otherwise, locks accepted regions).

The thesis: *voxelizer supplies the form, surgical region tweaks polish it against its own 3-D source.*
The loop now has an honest per-region 3-D signal to climb (the thing the flat concept never gave it), and
a starting form that's already close — exactly the conditions under which a local edit can earn its place.
This is "surgical tweaks to a GLB-based voxel set with regions," tested.

## Goal

Run the E-15 `reviseLoop` on the **S-051 GLB-voxel build** with `formTarget: glbFormTarget({ glbPath })`
(S-049). For koi + heart: record per-region tweaks (which regions, procedural vs LLM-edit, kept vs
rolled-back), the before/after **form IoU vs the GLB**, and the judge categorical. Show whether the
combination cleans voxelization artifacts and raises fidelity — and where it doesn't.
