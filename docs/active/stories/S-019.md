## Goal

Epic **E-10**, foundational input. Build the **block → Lab color table**: for each full-cube,
survival-obtainable 1.20.1 block, derive one representative color and convert it to CIE L\*a\*b\*. This is
the Minecraft-specific data the color engine (S-020) matches against. Source textures from
`minecraft-assets`; handle the gotchas from `docs/knowledge/cielab-block-matching.md` (biome tint,
alpha, directional faces, animated, non-full-cube exclusion).
