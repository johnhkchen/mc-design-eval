## Goal

Build the **Claude Agent SDK experiment harness** (epic **E-03**, spec §4, §7) with the **single-shot** archetype, then run the **end-to-end smoke trial** (first step of epic E-06, spec §10): prompt → artifact → materialize → render → image. The smoke trial is the **milestone** — the first real building session whose result you can see.

Scoring (E-04) and the rating system (E-05) are out of scope for this milestone; this story stops at a viewable image plus a logged transcript and token counts.

## Track breakdown

- **Runner:** `T-004-01` builds the harness skeleton; gates on **S-001** `T-001-03` (structured-output binding).
- **Archetype:** `T-004-02` adds the single-shot config; gates on the runner **and** **S-001** `T-001-04` (palette as material constraint).
- **Sink:** `T-004-03` is the single converging ticket — it gates on the single-shot archetype **and** **S-003** `T-003-04` (the render MCP tool). Completing it means the milestone is reached.

## DAG

```
S-001:T-001-03 (binding) ──> T-004-01 (runner) ──> T-004-02 (single-shot) ──┐
S-001:T-001-04 (palette) ───────────────────────────────────────^          │
S-003:T-003-04 (render tool) ──────────────────────────────────────────────┴──> T-004-03 (SMOKE TRIAL)
```

Cross-section gates: the runner consumes the contract (`T-001-03`), the archetype consumes the palette (`T-001-04`), and the smoke trial converges the harness and render sections (`T-004-02` + `T-003-04`). `T-004-03` is the lone DAG sink — run the swarm until it completes.
