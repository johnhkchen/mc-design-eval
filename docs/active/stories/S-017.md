## Goal

Epic **E-09**, third link. Harden the two properties that matter for the downstream pipeline, across all
references under the locked default variant:

- **Clean segmentation** — a single isolated subject, no ground/shadow/surroundings, on a uniform
  background, with a crisp silhouette (no dark blocks merging into a dark background). This is what makes
  the concept usable by TRELLIS (after stage-2 rembg).
- **Resolution discipline** — no sub-block detail (figures, text, filigree, fine tracery) anywhere; the
  smallest feature reads as a few whole blocks at the fixed 48-block resolution.

Find any reference where either property breaks and tighten `FacadeConceptPrompt` until all five hold.
