## Context (self-contained)

Epic **E-42**. Construction must apply the recognized program's material **roles** so the build matches the
concept's materials. The E-40 "matched" gatehouse scored ~2 against its own rustic concept because it is
plank/log, not cobblestone — and it is plank because it has **no recognition program** (it ran on hardcoded
constants; program-less subjects fall back to default materials). The wall-skin path (archived T-160-02)
already lowers roles→materials *when a program/pack exists*; the gap is program coverage + ensuring the
construction path actually consumes the roles for every subject.

## Falsifiable claim (anti-hedge — lead with how it fails)

Giving the gatehouse a recognition program and feeding its material roles through construction yields a
**materially faithful** gatehouse (cobblestone field + stone dressing, matching its concept) — raising its
self-concept score off the floor. **It fails if:** the construction path doesn't actually consume the roles
for this subject (the roles are recognized but dropped — find where); OR producing a faithful program per
subject is the hard part, not the application (then recognition-coverage/volume is the real wall — name it);
OR faithful materials alone don't lift the score because the roof-prism still dominates (then S-172 is the
binding gate, reported).
