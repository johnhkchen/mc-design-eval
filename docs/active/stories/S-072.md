## Background (self-contained)

Epic **E-21**. The LLM material map (S-071) names materials by **intent + placement** ("walls = stone
bricks, corners = cobblestone, roof = dark oak, base = stone"). This story **assigns those blocks to the
voxels by geometric feature** — so near-tone-distinct materials land where the artist put them, which mean
color can never do (brick and cobble share a color; they differ by *where* they go).

A **no-SAM** geometric feature classifier over the occupancy is enough for architectural intent: most
material zoning follows form — **flat wall faces**, **edges/corners** (convex verticals, few-neighbor
cells), **top/roof** (upward-facing / highest band), **base course** (lowest band), **openings/recesses**
(inset cells). Classify each voxel, then place the map's block for its feature. This is the bridge from the
LLM's intent to the geometry, without pixel-accurate segmentation.

## Goal

`classifyFeatures(occupancy) → {cell → feature}` (flat-face / edge-corner / top-roof / base / opening) —
pure geometry — and an assigner that places each S-071 map role's block by feature. The colorimetric
matcher (E-14/E-18) is retained for **within-material value** and as the **fallback** when the map is
silent for a cell. Result: brick on walls, cobble on corners — the distinction preserved.

## Builds on

- S-071 (the material map) + the occupancy/adjacency helpers (`src/form/glb-voxelize.mjs`,
  `material-segment.mjs`) + E-14 `nearestLab` (within-material value / fallback).
