## Context (self-contained)

Epic **E-43**. With the engine (S-174) and a readable hand-authored proof (S-175), two things close the
epic: **source** the treatment specs (stop hand-authoring) and **generalize** the same edge vocabulary
beyond walls.

- **Sourcing.** A treatment spec per element comes from recognition and/or a **style pattern-book** (a
  curated per-style treatment library keyed on the declared style, E-41). The E-39 structured critique
  ("trim thin / arch absent / quoins under-realized") **refines amplitude** — closing the
  feedback→construction loop the builds currently lack (single-shot today).
- **Generalization.** The same `edges`-from-geometry vocabulary applies to **roof** (eave/verge =
  overhangs, ridge = trim — composes with E-42's roof-as-construction) and **openings** (perimeter =
  reveal, head = arch). One grammar, three element types.

## Falsifiable claim (anti-hedge — lead with how it fails)

Sourced treatments (recognition/pattern-book + critique-refined amplitude) lift the gatehouse's
style-aware (E-41) self-concept score **above the token-relief baseline (42)** AND read as the concept; and
the same edge vocabulary produces correct roof overhangs + opening reveals. **It fails if:** recognition
can't author treatments as good as hand-authored (then a curated style pattern-book is the answer, not
LLM-authored specs — the finding); OR the score lifts but a human finds it **busy/over-articulated** (the
amplitude refinement over-shoots — the glance overrules the score); OR roof/opening need element-specific
edges the wall vocabulary can't express (the unification is leakier than claimed — report where).

  curated style libraries are a fine answer (and align with the style-pack direction).
