## Context (self-contained)

Epic **E-54**, the capstone — and the **stop-line**. With the relief-tolerant closure metric (S-209) and the
centered gate (S-210), re-run the metered gatehouse climb with the **cold-start batch escape on**
(`CLIMB_BATCH_SIZE`>0, the T-208 mechanism). The expectation: `close_shell` closes the form, the batch escape
lets relief + centered arch + slate roof **compound and be KEPT** (the relief-tolerant metric no longer reads
the dressed wall as reopened), and the kept build is the dressed gatehouse visible in
`T-208-01/beside-batch-rollback.png` — now with a centered arch and, ideally, the slate roof and right pitch
compounded in.

This story judges the **kept** build on the glance against the concept, and **draws the pre-committed
stop-line** (E-54 epic): win or lose, this is the last gatehouse fix-and-climb. A near-miss does **not** license
a seventh gatehouse epic; it triggers the step-back.

## Falsifiable claim (anti-hedge — lead with how it fails)

The re-climb (batch on, relief-tolerant closure, centered gate) **keeps the dressed build** and it **passes the
glance as M1** — a stranger recognizes the concept's gatehouse: closed dressed walls, a **centered arched gate**,
a **dark gabled roof**, right proportion — mostly autonomously. **Fails if:** the kept build still misses (brown
roof / grey walls / boxy — recolor/scale didn't compound → **stop-line fires**, M1 near-miss, step back); the
relief-tolerant metric mis-keeps a genuinely-open batch (S-209 invariant leaked → back to S-209); or **score
variance** makes the verdict unreproducible (M1-passing one run, near-miss the next → the judge can't *certify*
M1 → also fires the stop-line: the architecture can't measure a finish).
