## Background (self-contained)

Epic **E-26**. The artifact contract already half-supports fixtures: the schema carries a `state` per
placement and the render path applies block + orientation (`render/src/world.mjs` → `setBlock(world,
pos, block, state)`). But **no pipeline stage has ever emitted a non-cube block** (repo-wide grep: zero
trapdoor/fence usage), so the path is unproven — and the *analysis* layers were built assuming full
cubes: occupancy treats every cell as solid-or-empty, and the E-25 closure check would read a
fence-infilled window as a hole (or a sealed one as a wall).

## Goal

**Prove and harden the fixture path end-to-end**: trapdoors, fences, stairs, and slabs flow from
artifact JSON (with states the live AJV gate accepts) through occupancy and the structural read to a
correct render — orientations right at gate angles — and the closure/hollow semantics treat a
**dressed opening as dressed**: not a shell hole (closure passes), not wall mass (the opening's identity
survives for the grammar and the interior checks).

## Builds on

- `src/artifact.mjs` + `schema/design-artifact.schema.json` (the `state` slot); `render/src/world.mjs`
  (state application); `src/view/occupancy.mjs` + `structural-read.mjs` (`openings`); E-25 S-091
  six-direction closure.

## Run-the-test ticket
