## Background (self-contained)

Epic **E-36** (de-freeze the creation loop). Two consecutive loops (E-35, T-150-01) reported "GL
absent" and deferred **every** render to an "operator runbook" — so the loop built machinery for two
sessions and **never looked at its own output**. But GL is available (`render/src/render.mjs`
`GL_AVAILABLE: true`; a textured barn + roof-diff sheet were rendered by hand this session). The render
is the creation loop's feedback signal; without it the loop is blind, which is why quality stalled while
guard-coverage grew.

## Goal

**Every creation run produces a judge-free textured render beside the concept**, automatically — reuse
the existing `--skip-gate` chain + the diff/sheet path (no judge spawn, no billed run). **"No GL" is a
hard, surfaced failure**, never a silent defer: diagnose why the autonomous environment reported no GL
when the host has it, and make the loop environment provide headless GL (Playwright/Chromium or
headless-gl). Kill the "operator runbook" deferral for judge-free renders — a judge-free render is cheap
and reproducible-enough to be the standard loop output. **Prove it on the barn**: re-render the barn
(with T-150-01's gable/overhang fix live) through the de-frozen loop, sheet beside the concept, the
construction improvement visible.
