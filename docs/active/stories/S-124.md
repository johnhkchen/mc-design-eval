## Background (self-contained)

Epic **E-31**. Minecraft building is a finite, conventional **pattern language** — gable, hip, dormer,
chimney, jetty, timber panel, arch, plinth, porch — and the project already owns canonical generators
for most of it (gable/hip/pyramid roofs, arches, placement grammar, opening dressing, hollowing,
floorplans, all unit-tested across E-23..E-30). What doesn't exist: a **style pack** that bundles a
curated palette, the idiom set, proportion rules, decoration vocabulary, and conformance checks into
one reusable, per-STYLE artifact (per-style code is sanctioned; per-building code stays forbidden —
E-31 Rule 2). The pack also structurally retires a known failure mode: the barn's auto-flagged kit
silently disabled its own roof (T-121/T-122) — a **human-curated pack palette, once per style**,
replaces per-subject kit recognition flags on this path.

## Goal

(a) The **style-pack contract**: palette (curated, value-checked once), idiom set with parameter
schemas, proportion rules (storey height, pitch class, opening rhythm), decoration vocabulary, and the
pack's **deterministic conformance checks** (courses even, declared symmetry held, openings aligned,
palette in-pack — the regularity QA that points at what eyes see). (b) The **idiom registry**: each
idiom name → its canonical generator (existing generators registered; the milestone's gaps built —
**dormer, chimney, jetty** at minimum). (c) The **first pack** (rustic/Tudor — covering cottage and
barn) committed and human-reviewable.
