## Background (self-contained)

Epic **E-23**, the **program path** (Path A). Voxelizing a TRELLIS mesh gives a **solid** mass — the
cottage is a filled block, not a building you could put rooms in. The milestone needs it **hollow**: a shell
+ structural members, ready for an interior. Carving is a job for a *program* (deterministic, exact,
re-runnable); the *judgement* of what is safely hollowable is a small, scoped call for the LLM.

## Goal

1. **Mark the hollowable interior** — a scoped detector (light model tier via S-082, or pure-geometric:
   voxels fully enclosed, not on the exterior skin, not load-bearing structure) identifies the mass that can
   be removed.
2. **Carve, by program** — a deterministic op removes the marked interior, leaving:
   - the **exterior skin intact** (the resemblance gate signed off the exterior — hollowing must not change
     what the gate sees: same exterior render before/after),
   - **structural members** kept (corner posts, the chimney shaft, anything the skin needs to stand).
3. **Verify exterior-unchanged** — re-render the exterior post-carve; the resemblance verdict must not
   regress (hollowing is invisible from outside).

## Builds on

- S-078 (the structural read identifies skin vs interior vs structure; the footprint/storey lines bound the
  cavity), S-082 (the hollowable-mass detector is a right-sized-model exemplar).

## Run-the-test ticket

- `T-080-01` — implement the hollowable-mass mark + the deterministic carve; run on the cottage; record
  block count before/after (the cavity), and prove the **exterior render is unchanged** (resemblance
  verdict held). Pure carve + skin-preservation unit-tested on synthetic occupancy.
