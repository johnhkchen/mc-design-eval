## Background (self-contained)

Epic **E-35**. The "prove the look" spike (2026-06-14, [[look-proven-on-cottage-relief]]) rendered the
two chains side by side and found a sharp split: the **cottage workshop build is clean** (solid
cross-gable roof, plaster walls, stone plinth, no holes), while the **generate-first barn is holey** —
gappy roof slopes you can see through, irregular/holey walls. The GLB is *not* the cause (the reviewer
was right; the cottage proves a clean build is normal) — this is a **generate-first-specific Stage-4
construction defect**. It matters now because **E-37 makes generate-first the seed the workshop
iterates**; a holey seed undermines the unified chain and every build off it. (Distinct from facade
texture — this is base build solidity.)

## Goal

The generate-first build is **watertight and solid** by construction: roof slopes complete (no
see-through gaps), walls solid, the exterior shell closed — while the hollow loft is preserved (the
shell stays watertight *around* the carved interior, [[twodee-interaction-sector]] S-084 precedent).
Diagnose the root cause first (over-aggressive `hollow-carve`? the roof `sheet`-column thin-shell
leaving gaps? voxelization?) — render, locate the holes, name the cause — then fix at the source. No
per-building constants. Proven by render (judge-free, E-36 path) beside the clean cottage reference.
