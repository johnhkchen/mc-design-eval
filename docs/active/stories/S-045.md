## Background (self-contained)

Epic **E-15** closes the *iterate* bookend that E-11 left open. E-11 (`src/sculptor/`) built staged
construction with **locks** (improve is additive, never destructive — the P14 cure) and a **diagnose-and-
route critic** (`review.mjs`: emit `{defect, where, route}`, name the stage to re-run, never blanket
re-emit) — but `staged-loop.mjs`'s `runStagedLoop` runs *one* forward pass and the diagnosis is **never
consumed**. This story wires the actual loop: observe a region → diagnose → tweak it → re-observe → **keep
the tweak only if it improved** → lock the region → next, all under a **bounded** iteration budget.

**Crucial sequencing decision (settled in the epic):** build the loop with the **deterministic** tweak
primitive *only* first — a scoped procedural pass (E-11's `relief`/`material`, bounded to the region) — and
**no model in the loop yet**. The point is to prove the *cage* is tight: the loop converges, an accepted
region locks and is never touched again, a tweak never bleeds past the region-lock, and the
**accept-if-improved** gate actually rolls back a non-improving change (so the loop can't regress — P14,
now per-region + per-iteration). Model-in-loop variance would confound that proof; it's added next (S-046)
behind this same, already-trusted gate.

## Goal

`reviseLoop(artifact, opts)`: pick region → `observeRegion` (S-044) → diagnose (E-11 critic) → apply a
**scoped procedural pass bounded to the region** → re-score with the form metric (S-043) → **accept-if-
improved else roll back** (via the region-lock/commit model) → lock region → repeat to a bounded
iteration / per-region budget; return the revised artifact + a per-iteration trace (region, defect,
tweak, score before/after, accepted?). Deterministic — same input, same output.

## Builds on

- S-043 `formFidelity` (the accept-gate's per-region signal) + S-044 region-lock + `observeRegion`.
- E-11's passes (`src/sculptor/relief.mjs`, `material.mjs`) and critic (`review.mjs` `routeDefect`/
  `ROUTING_TABLE`), now invoked **scoped to a region** rather than whole-object.
- The hill-climb-with-rollback shape (accept only on improvement) — the same discipline E-14's gate used,
  applied temporally.

## Run-the-test ticket

- `T-045-01` — implement the bounded loop driven by deterministic scoped passes; unit-test convergence
  (it stops), the accept-gate (a non-improving tweak is rolled back, not kept), spatial lock (an accepted
  region is never re-touched; no edit bleeds out), and produce a per-iteration trace.
