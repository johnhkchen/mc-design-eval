## Background (self-contained)

Epic **E-37** (canonical-build-flow). Four live "build a subject" chains exist (pattern-book/workshop,
generate-first, styled, challenge), each with its own runner and artifact tree. The symptom that proves
the cost: T-150-01's gable/overhang fix landed in **generate-first** while the barn that gets
**measured** is the **workshop** one. The decision (reviewer 2026-06-14): **unify — generate-first
becomes Stage 4** (the clean parametric seed) feeding the **Stage 5 workshop** (where the model
iterates). The philosophy already implies this: pattern-book grew its *own* rougher Stage-4 seed
brushes, and the workshop was bolted onto that one; canonical = the strong realizer feeds the loop.

## Goal

**One `build:<subject>` chain:** recognize (Stage 3) → **generate the seed via generate-first's
parametric realizer** (Stage 4 — GLB-fit + kit, gable-as-wall, overhang, articulation) → **workshop**
(Stage 5 — model critiques renders, revises via tools, ledgered, judge-free render every round per
E-36) → final. The pattern-book seed-brush stage is **replaced** by the generate-first realizer (one
realizer feeding one loop, so a construction fix lands in the chain that gets measured). The gate stays
a **separate explicit step** (frozen, billed — not part of `build`). The first cut of `STRUCTURE.md`
(the canonical map: Stage → module → artifact → entry point) lands here.
