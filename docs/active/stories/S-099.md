## Background (self-contained)

Epic **E-26**. The witnessed case: the cottage concept's windows have **trapdoor shutters** and **fence
infill**; the build's windows are bare geometric holes (when they survive at all). Openings are already
first-class in the structural read; the fixture path is proven by S-097; the kit (S-096) names the
treatment. What's missing is the op that walks the openings and applies it.

## Goal

A deterministic **opening-dressing op**: for each opening instance from the structural read, apply the
kit's declared treatment — fence infill in the aperture, trapdoor shutters flanking, lintel/sill from the
frame block — with correct orientations, sized to the opening (and when an opening is too small for its
full treatment, the conflict is recorded and the chosen reduction named, per the epic's honesty rule).
Run on the cottage: every window dressed as the concept shows; the door framed; visible at gate angles.

## Builds on

- S-097 fixture path (states render; closure treats dressed openings correctly); S-096 kit (which
  treatment); `structural-read.mjs` `openings` (where); E-25 S-091 void-repair's opening allow-list (a
  dressed opening must stay an *opening* to the integrity stage).

## Run-the-test ticket

- `T-099-01` — the dressing op, pure core unit-tested on synthetic openings; cottage run with
  before/after renders at gate angles showing shutters + fence infill on every window.
