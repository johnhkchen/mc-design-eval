## Background (self-contained)

Epic **E-16**, Arm B (continued). S-050 turns a GLB mesh into an **occupancy** voxel grid (form, no
color). This story adds color and compiles to a renderable build — the **GLB-voxel build** that goes
head-to-head against text→JSON. Color reuses the project's proven E-10 layer: the **CIE-Lab nearest-block
engine** (`src/color/` `cielab.mjs` `nearestLab`, `block-table.mjs` `loadBlockTable` — a 305-block Lab
table) already maps an arbitrary color to the closest real Minecraft block (this is exactly how E-14
killed the moai value drift). Here the per-voxel target color comes from the **GLB surface** (the nearest
vertex color, or a texture sample via the mesh UVs) rather than a concept image.

The output is a standard `DesignArtifact` (the shared JSON of voxel placements), so render + judge are
**unchanged** — the same instrument scores a GLB-voxel build and a text→JSON build identically.

## Goal

`glbVoxelBuild(glb, { scale }) → DesignArtifact`: take S-050's occupancy, assign each occupied cell a
**value-true block** via E-10 `nearestLab` on the GLB's surface color at that cell, compile to a valid
`DesignArtifact` (passes the AJV gate `src/artifact.mjs`), render at `SCULPTURE_VIEW_3Q`, and judge. The
"is the voxelizer's form better than text→JSON's?" build.

## Builds on

- S-050 (occupancy) + E-10 color engine (`src/color/cielab.mjs` `nearestLab`, `block-table.mjs`
  `loadBlockTable`) — the same engine E-14 used, untouched.
- The compile→render→judge path (`src/sculptor/compile.mjs` `toDesignArtifact` pattern, `src/artifact.mjs`,
  the render rig, the judge) — reused as-is.
- The GLB surface color (vertex colors / texture from the glTF; decode with the existing image utilities
  in `src/color/palette-extract.mjs` `decodeImage` if sampling a texture).
