## Goal

Add the **iterative, visually-grounded** prompting archetype (epic **E-03**, spec §7 archetypes 2 + 3) and use it to produce a markedly better building than the flat single-shot box. The loop: generate → render a WIP image → feed that image back to the `claude -p` session → revise → repeat for N rounds, then a final render. Target a **neoclassical building** so there is real architectural detail (columns, entablature, pediment, portico, symmetry, steps) for the model to demonstrate and improve.

Motivation: the single-shot industrial house (S-004) is blocky and basic and does not reflect the model's capability — mc-bench-style results are far richer. Two levers close that gap: (1) a more detail-bearing style/palette, and (2) visual feedback so the model can *see* and fix what it built.

## Builds on (done, committed)

- The `claude -p` subscription seam (`src/sdk-binding.mjs`) and trial runner (`src/trial.mjs`).
- The render tool / headless render at the correct version pin (`src/render-tool.mjs`, `render/`).
- The single-shot archetype + prompt scaffolding (`src/single-shot.mjs`, `src/briefs.mjs`) — the iterative archetype layers on the same runner, exactly as single-shot did.

## Track breakdown

- **Parallel inputs (wave 0):** `T-005-01` (neoclassical palette + style brief — data/brief) and `T-005-02` (multimodal feedback seam — sends a render image to `claude -p`) are independent and run concurrently.
