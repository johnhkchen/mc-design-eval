## Background (self-contained)

Epic **E-15** builds a *surgical revision loop* that revises a finished build **one section at a time**:
look closely at a region, make a small local tweak, keep it only if it helped, lock it, move on — bounded
so it converges, locked so it can never regress what already worked. That discipline is the project's
hard-won rule (recorded as **P14**: a blanket "improve the whole thing" 2nd pass once regressed by
*detaching masses*; the cure is to keep every change **additive and bounded**). E-11 enforced this
**per-field** on a facade build-state (`src/sculptor/build-state.mjs`: writing a LOCKED field throws). This
epic needs the same guarantee **per-region** on the compiled `DesignArtifact` (the shared JSON of voxel
placements that both facade and 3-D sculpture builds produce), so the loop reaches the 3-D sculptures and
so a future GLB form-target can plug in at the artifact level.

This story builds the two primitives the loop is made of, before any control flow:
1. **Region addressing + region-lock** — select a sub-region R of a `DesignArtifact` (a bounding box, a
   named part, or the critic's `where`); **freeze everything outside R**; permit only bounded edits to
   placements inside R. A generalization of E-11's field-lock from "which field" to "which cells."
2. **Observe a section** — render a *tight crop* on R so the model/critic sees it closely. The render rig
   already frames an arbitrary integer voxel bounds (`render/src/camera.mjs` `framedCamera(bounds, view)`,
   `boxOf`, `boundingSphere`) — so "observe R" is `framedCamera(subBoundsOf(R))`, not new camera math.

## Goal

A region layer over the `DesignArtifact`: `selectRegion(artifact, spec) → R`, a **region-lock** that makes
out-of-R placements immutable and validates that an edit touches only R, and `observeRegion(artifact, R)`
→ a tight crop render of R. Pure where possible (region math, lock enforcement); the live crop render is
the one boundary-crosser, isolated like E-11's review seam.

## Builds on

- The compiled `DesignArtifact` (voxel placements with integer coords) + `src/artifact.mjs` (the AJV gate
  the edited artifact must still pass).
- `render/src/camera.mjs` (`framedCamera`/`boxOf`/`boundingSphere`) + `render/src/render-tool.mjs`
  (`renderArtifact`) for the crop render.
- E-11's lock semantics as the conceptual model (`src/sculptor/build-state.mjs` / `orchestrator.mjs`),
  generalized from per-field to per-region.

## Run-the-test ticket

- `T-044-01` — implement region addressing + the region-lock (out-of-R immutability, in-R bound check) +
  `observeRegion` crop render; unit-test the lock (an edit that touches outside R is rejected) and the
  sub-bounds math; one live crop render on a committed sculpture proves the observe path.
