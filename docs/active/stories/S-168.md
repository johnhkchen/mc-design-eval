## Context (self-contained)

Epic **E-40**. The fix itself. Today `styleFidelityScore` (`src/workshop/bakeoff-score.mjs`) is
`100 − Σ penalty(severity)` with `major=20, minor=8` — it counts *missing-element presence* and has **no
term for a present element that belongs to the wrong style**. So a clean wrong-style build (nothing
missing, everything present-but-wrong) is barely penalized.

This story adds **style distance** as a first-class, capping severity, derived from the Critique's own
`expected` vs `present` per item: when `present` is non-empty but its grammar diverges from `expected`
(the per-style Layer A already names this — guildhall pilasters where rustic timber is present, etc.),
that item is a **MAJOR style defect** and contributes a **distance**, not just a fixed penalty. The roll-up
becomes defect-dominated on style: a build far from its target style is **capped low** regardless of
completeness.

## Falsifiable claim (anti-hedge — lead with how it fails)

A style-distance term keyed on `expected`-vs-`present` mismatch makes a clean wrong-style build score far
below its matched twin (the spread the E-39 fixture lacked), **without** wrongly tanking a build that is
merely incomplete-but-right-style. **It fails if:** the `expected`/`present` strings aren't separable into
a reliable grammar-mismatch signal (the judge's free text is too noisy to classify present-vs-expected →
the term needs a typed grammar tag from Layer A, a feedback to E-39's schema); OR distance collapses back
to a binary that over- or under-penalizes (then it needs a graded scale validated in S-169); OR matched and
wrong-style still tie because the judge emits identical `present` text for both (the reading, not the
scoring, is the gate — routes back to Layer A).

## Tickets

- **T-168-01** — implement the style-distance severity in `bakeoff-score.mjs`: classify each item by
  `expected`-vs-`present` grammar mismatch, assign capping MAJOR severity + a distance contribution, fold
  into `styleFidelityScore`; pure, unit-tested (incl. a matched-vs-wrong-style pair that must now separate).
