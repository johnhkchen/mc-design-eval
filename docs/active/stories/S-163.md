## Context (self-contained)

Epic **E-39**. The foundation everything else binds to: the **typed contract** between judge and builder.
Today the workshop critique is `WorkshopCritique { issues: [{region, issue, severity}] }` — freeform prose,
no expected/present/missing split, and `region` is an untyped string the builder can't reliably route on.

This story defines (a) a `Department` enum **generated from the idiom-registry** (`src/pack/idiom-registry.mjs`
— roof / wall / opening / room / chimney / …, the addressable construction catalogue) so judge and builder
share one vocabulary, and (b) the enriched `Critique`/`CritiqueItem` BAML classes. No judging behaviour yet
— schema + generator + conformance only.

## Falsifiable claim (anti-hedge — lead with how it fails)

A `Department` enum generated from the idiom-registry, plus a `CritiqueItem {department, expected, present,
missing, severity}` class, can express every construction-addressable issue the existing brushes can fix,
with **no department the registry lacks a tool for** and **no registry idiom that maps to no department**.
**It fails if:** the registry's idioms don't partition cleanly into departments (some idiom serves two, or
none) → then the taxonomy needs a real grouping decision, and that decision is the finding; OR the
expected/present/missing triple can't capture a real critique kind (e.g. proportion, which is relational
not per-element) → then the schema needs an axis beyond department, reported not forced.

## Acceptance Criteria

- [ ] A `Department` enum **derived programmatically** from the idiom-registry (grouping idioms → departments),
      with a **conformance test** that fails if an idiom maps to no department or a department names no idiom
      (the single-composition-point rule — drift tripwire).
- [ ] BAML `Critique { items: CritiqueItem[] }` and `CritiqueItem { department: Department, expected, present,
      missing, severity }` in `baml_src/`, with `b.parse` fixture tests (the repo's BAML test pattern).
- [ ] A pure `.mjs` mapping from a `CritiqueItem.department` to its candidate idiom-registry entries (the
      seam Layer B will consume in S-164) — unit-tested, no per-subject constants.
- [ ] `npm test` green; the frozen judge path carries **no** new dependency (transport-guard stays green).

## Notes

- This is schema + plumbing; resist adding judging logic here (that's S-164).
- `expected/present/missing` map to construction ops downstream: missing→add, present-but-wrong→replace,
  absent-from-expected→remove. Keep the three fields, even when one is empty.
