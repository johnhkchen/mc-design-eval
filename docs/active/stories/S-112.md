## Background (self-contained)

Epic **E-29**. The E-28 church per-component roof fit accepted the **nave** but took a named fallback on
the **tower**: *"insane gable — a pyramidal cap is not a ridge pair"*
(`benchmarks/sculpture/roof/church.json`, T-110). The construction vocabulary (E-27 shaped vocabulary +
roof program) generates gable slopes, ridges, verges, and arches — but has **no hip end and no pyramidal
cap**, so any tower, hip-roofed mass, or pavilion is unfittable by construction. Both the repair path
and generate-first (S-115) need the complete roof family.

## Goal

Extend the roof vocabulary with **hip and pyramid construction**: fit (apex point + per-face slope
against the GLB roof component — for a square tower cap, four meeting planes; for a hip end, the slope
replacing a gable triangle), generate as stair/slab courses with correct corner states via the proven
fixture path, cage-wrapped (per-azimuth IoU, closure, auto-rollback), fit-or-named-fallback contract
unchanged. Proven on the **church tower**: the named fallback becomes an accepted per-component fit.

## Builds on

- E-27 roof program + shaped vocabulary (the generators this extends); T-110 per-component invocation
  (the seam that calls it); T-103 church component record (the tower geometry); T-102 cage.

## Run-the-test ticket
