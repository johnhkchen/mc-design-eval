  //   valueSelectRecord.substitution when present (throw on divergence — same math, same inputs)

### Record schema (`durable-skin/v1`)

`{ schema, subject, inputs{build,concept,glb,map}, valueTrue{substitution, rows, agreesWithRecord},
sealed{raw,sealed}, zones{storeyDivide,upperTop}, fill{policy(shipped-space), placements, kept, byZone},
splat{front{painted,zoneRejected,accepted,gateBlind,resemblance?}, side{…}},
pattern{course{before,after,columnsRaised,voxelsAdded}, salt{stripped,kept,byZone}},
coverage{splatOnly, final}, coverageGate{threshold, splatOnly(expect fail), final(expect pass)},
invariants{plasterHistogram?, interiorStrays?}, reproducible{doubleRun:true, sha256},
materialCounts{before,after}, renders[], frames[], notes }`

## Test surface

No new unit tests: the runner is impure wiring over already-tested cores (repo convention, stated in all
four upstream reviews). Verification layers instead: the **double-execution reproducibility assert** (every
live run), the **terminal coverage-gate + plaster + AJV throws** (a failing skin cannot write a record),
the **value-select agreement assert** (cottage), and `--offline` re-asserts on the committed records
(deterministic, GL-free, exercised in review). Named gap to carry into review.md: gatehouse zoning
constants (if any override is needed) are registry data verified live, not unit-tested.
