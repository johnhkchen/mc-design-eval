## Acceptance criteria — status

1. **Deterministic zone-fill core, pure, unit-tested** — ✅. Stone upper-band cell → plaster; timber stud
   run stays; base cell stays stone — each a named test; secondaries preserved as runs (isolated cells
   filled). Pure (no GL/I-O/Date/random), policy passed as data (nothing cottage-specific in `src/`).
2. **Wired ahead of the splat; splat places secondaries only** — ✅. §0c runs on the sealed occupancy;
   all splat/gate/commit work runs on the base-coated build; per-zone splat palettes exclude every field
   material (upper = `dark_oak_log` only).
3. **Reproduced by the pipeline (Rule 1)** — ✅ with an honestly-named number: upper-band dominant
   coverage **13% (splat-only replay) → 71.2%** plaster, recorded in `zones.coverage` from pipeline
   output. **71% ≠ the literal 77%**: the fill alone takes the band to ~91%; the splat then lawfully
   places 184 timber-stud cells (29%, vs the inline edit's 19%), so plaster lands at 71%. The final upper
   skin is *exactly* plaster + timber (zero third materials — stray salt eliminated as a side effect),
   which is the "dominant established, secondaries on top" composition the story defines. Within the
   plan's pre-declared 0.6–0.9 window; visual check confirms the banded half-timbered read.
4. **`npm test` green** — ✅ 991/991 (and `--offline` re-check exits 0).

## Open concerns / known limitations (named, per Rule 5)

1. **Plaster is still pink.** The coat is `white_terracotta` because the E-21 map says so — value-true
   block selection is T-086-01, which should only need to touch `ZONE_POLICY`/the map, not the fill.
2. **Upper-band stone window reveals are plastered.** Stone cannot be in upper's preserve set (it *is* the
   displaced field, and it sits in runs). Reveal restoration is a surface-pattern concern → S-087.
3. **Coverage is reported, not gated.** The `--offline` check only asserts zoneFilled > splatOnly; the
   threshold gate ("fail under X%") is T-088-01's, and `surfaceZoneHistogram` is the seam built for it.
4. **The fill is surface-only**, so total plaster count (459) is far below the inline artifact's 975
   (which recolored interior cells). Anything that later *exposes* interior cells (hollowing, cutaways)
   will reveal un-coated stone — acceptable for the exterior-skin scope of E-24, but worth knowing.
5. **`LEGACY_ZONE_MATERIALS` is intentional dead-looking code** — it exists only to replay the "(was
   ~9–13%)" baseline. If the baseline ever stops being worth a record field, delete it and the §2b(b) block
   together.
6. **Side-effect to verify downstream**: the gate's "before" renders now show the base-coated build, so
   historical before/after PNG comparisons straddle this commit boundary.
