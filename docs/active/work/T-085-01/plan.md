## Step 5 — run the pipeline (the AC-#3 evidence)

`npm run spray:paint` end-to-end, no hand edits. Expected stderr milestones:

- `zones: storeyDivide=…` (sanity: matches the inline fix's band start, ≈7);
- per-zone fill counts (upper filled ≫ 0);
- `histogram … MASKED {base:0, upper:…, roof:0}` and **no §5b throw**;
- coverage log: upper `white_terracotta` fraction **≈0.77** (target window 0.6–0.9; the inline reference
  was 0.77), splat-only baseline ≈0.09;
- plaster `before → after` strongly up (inline reference: 88 → 975);
- GL face renders best-effort — a headless-GL failure is a recorded gap, not a blocker (the coverage
  evidence is GL-free by design).

Then `npm run spray:paint -- --offline` (note: script invokes node directly, so flags pass through) —
exits 0 with the new coverage line.

Contingencies (decide-and-document, not stop-and-ask):
- upper fraction < 0.6 → inspect `byZone` + the upper `byBlock` census: most likely a preserve-set
  member occupying large runs (e.g. gable planks); tune `ZONE_POLICY.upper.preserve` (policy data, not
  core code), re-run, record the rationale in progress.md.
- §5b throw → a fill placement leaked plaster outside upper, which is impossible by construction unless
  `zoneOf` differs between fill and census — debug zone wiring before touching the guard.
- `storeyDivide` ≠ ~7 → the seal changed the floor-line read; check `structuralZones` opts before trusting
  any coverage number.

## Testing strategy summary

- **Unit (npm test)**: all fill semantics — the 9 tests in step 2. Pure, synthetic, no cottage data.
- **Integration (the benchmark run)**: `npm run spray:paint` is the integration test — its §5b throw, the
  AJV assert, and the recorded coverage are the criteria. Not in CI/`npm test` (GL + cost), matching every
  sibling runner.
- **Reproducibility check**: `--offline` validates the committed record's invariants deterministically.
