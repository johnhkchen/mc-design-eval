# T-150-01 Structure — file-level blueprint

Principle: **opt-in cores keep byte-identity** (absent input ⇒ legacy emission). Real-subject
activation flows through the generate-first path (provision-generate) and the program path (compile).
Committed *judge-pinned* artifacts are never re-pinned here; the barn GL render is an operator step.

## 1. `src/view/roof-generate.mjs` (MODIFY — the heart)

`generateRoof(gables, family, opts = {})` — add `opts.gableBlock` (namespaced wall block) handling:

- New helper `gableEndColumns(gable)` (exported, pure): for a gable with `hip.demanded === false`,
  return the Set of `"x,z"` columns whose ridge-axis coordinate is `bbox.min`/`bbox.max` along the
  ridge axis (ridge=x → x∈{minX,maxX}; ridge=z → z∈{minZ,maxZ}). Empty for hip gables (no vertical
  triangular face). Computed in `roofHeightfield` and stamped onto `owner` as `gableEnd: boolean`.
- In the cell loop: when `opts.gableBlock` is set AND `own.gableEnd` AND the cell is **not** the
  covering surface (not the top `y===top` stair/full, not the `slab` at `top+1`, not a `cap` cell):
  emit `{ pos, block: opts.gableBlock }` and add `"x,y,z"` to `gableWallKeys`. The covering surface
  cell stays exactly as today (roof field / shaped / cap). For sheet columns (open underside) there
  is no sub-surface fill, so gable-end + sheet interact cleanly (the verge surface stays roof).
- Return shape gains `gableWallKeys: Set<string>` (empty when `opts.gableBlock` absent).
- **Byte-identity:** with `opts.gableBlock` undefined, no branch is taken; output identical.

## 2. `src/view/zone-map.mjs` (MODIFY — zone classification)

`zonesFromBands({ bands, roof, roofKeys, upperTop, gableWallKeys = new Set() })`:
- In `zoneOf`, **before** the `y >= upperTop || roofKeys.has(key)` roof clause:
  `if (gableWallKeys.has(\`${x},${y},${z}\`)) { <band walk for y>; }` — return the band whose
  `yRange` contains y (same walk as the wall path), clamping like the existing total function.
- Default empty Set ⇒ identical behavior.

## 3. `src/view/structural-read.mjs` (MODIFY — the geometry-derived zoneOf)

`structuralZones(occ, opts = {})` — accept `opts.gableWallKeys` (default empty). In `zoneOf`,
before the roof clause: `if (gableWallKeys.has(key)) return y >= storeyDivide ? "upper" : "base";`.
Default empty ⇒ identical. (This is the generate-first/skin path's classifier alongside zonesFromBands.)

## 4. `src/form/provision-generate.mjs` (MODIFY — generate-first activation)

In the roof loop (lines 110-140):
- Resolve `gableBlock = wallBlockAt(gen.bandFloor)` (the wall material at the eave band — the
  realized "default to the wall upper/ground field"; for the barn this is cobblestone, == gableRole).
  Pass `generateRoof(roof.gables, family, { gableBlock })`.
- Collect `gen.gableWallKeys` into a module-level `allGableWallKeys` Set; add it to the returned
  `roofPlan` (`roofPlan.gableWallKeys`).
- The gable-end-wall cells are NOT fascia (they are wall, not roof) — the fascia recolour
  (`isFascia`) must skip cells in `gen.gableWallKeys` (guard the `isFascia` condition).
- Wall exclusion unchanged (gable-end columns are interior to the roof footprint, already part of the
  roof plan, not extruded as walls).

## 5. `src/recognition/compile.mjs` (MODIFY — program path consumes gableRole + overhang)

In the roof block (lines 221-249):
- Resolve `gableBlock = roleBlock(pack, m.roof.gableRole ?? m.walls.ground.role)` (AC1 default).
- Resolve overhang amount `ov = pack.proportions?.roofOverhang ?? eaveWiden` where `eaveWiden` keeps
  the current 1-cell behavior (byte-identical default). Widen the expanded footprint `ex` at the eave
  sides by `ov` (today 1) AND, when `ov` carries a verge component, the gable-axis ends by the verge
  amount; mark the outer ring `sheet`. (Default keeps `ov`=1 eave-only ⇒ byte-identical.)
- Add `gableBlock` to the roof element `spec.blocks` (new field `blocks.gable`), threaded by the
  construct to `generateRoof` opts.
- **Guard:** only for `layout.ridge` gable idioms (`roof.gable`/`roof.gable.steep`); hip/pyramid/flat
  unaffected.

## 6. `src/pack/idiom-registry.mjs` (MODIFY — construct threads gableBlock)

`roofGableConstruct` (and the steep construct in `roof-steep.mjs`): read `spec.blocks.gable` and pass
`{ gableBlock: spec.blocks.gable }` into `generateRoof`. Absent ⇒ undefined ⇒ byte-identical.

## 7. `benchmarks/sculpture/generated-milestone.mjs` (MODIFY — skin sees gable walls; operator render)

- Thread `gen.roofPlan.gableWallKeys` into the zone-classification used by `buildSkin`
  (`zonesFromBands`/`structuralZones` call site) so the skin dresses the gable-end as wall.
- No re-pin in this ticket: the committed `generated/barn.json` + `pr/assets` sheet are regenerated by
  the operator (`npm run generated:barn -- --repro` then `npm run diff:roof -- --subject barn`),
  documented in review.md. (GL + judge are out of `npm test` by project rule; "no judge run".)

## 8. Tests (NEW / MODIFY)

- `src/view/roof-generate.test.mjs` (NEW cases): with `gableBlock` set — (a) gable-end sub-surface
  cells carry `gableBlock`; (b) the covering surface (stairs/cap) is unchanged vs no-gableBlock run;
  (c) `gableWallKeys` contains exactly the end-slice fill, none of the surface; (d) hip gable ⇒ empty
  `gableWallKeys` (no vertical face); (e) byte-identity: no `gableBlock` ⇒ identical cells to legacy.
- `src/view/zone-map` test (NEW): a key in `gableWallKeys` above `upperTop` returns its wall band, not
  "roof"; absent ⇒ "roof" (regression of the legacy contract).
- `src/form/provision-generate.test.mjs` (MODIFY/NEW): a single-gable fit ⇒ gable-end columns'
  sub-surface cells are wall material; `roofPlan.gableWallKeys` non-empty; hollowness preserved
  (interior carved, gable slice intact); fascia not applied to gable-wall cells.
- `src/recognition/compile.test.mjs` (NEW/MODIFY): roof spec carries `blocks.gable` from gableRole;
  overhang default ⇒ byte-identical footprint; verge widening present when pack carries it.
- Slope no-regress: assert the covering cells (stairs/slabs/cap positions+states) are byte-identical
  between gableBlock-on and gableBlock-off runs (the AC2 "slopes byte-unchanged" guarantee at the
  unit level, complementing the GL silhouette gate).

## 9. `docs/knowledge/design-learnings.md` (MODIFY — E-35 section)

Add the **construction-model** note: prism-on-prism → envelope-then-covering; gable end is wall
(consume `gableRole`, default wall ground), roof is covering (slopes+ridge), overhang is honest
widening (eave drip + gable verge) the E-34 ruler reads AS the eave line (record both ways);
opt-in `gableBlock`/`gableWallKeys` preserve byte-identity.

## Ordering

3-core (1,2,3) → tests for cores → wiring (6,5,4) → tests for wiring → runner (7) → learnings + review.
Each core lands byte-identical-by-default, so the suite stays green at every commit.
