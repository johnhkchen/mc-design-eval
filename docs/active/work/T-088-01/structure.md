### MODIFIED `src/view/face-resemblance.mjs` (+~55 lines)

Three exports appended after `acceptIfCloser` (no changes to existing functions or imports — the gate

```js
export const DEFAULT_COVERAGE_THRESHOLD = 0.5;

/**
 * The S-088 coverage PRECONDITION over a dominantCoverage record. Iterates the POLICY zones (`zones`
 * keys when given, else every measured zone): each must show dominantFraction >= threshold on a
 * non-empty census. Missing zone / total 0 / null fraction → failure (absence of evidence fails).
 * @returns {{passed:boolean, threshold:number,
 *            failures:{zone,dominant,fraction,total}[],
 *            byZone:Record<string,{dominant,fraction,total,passed}>}}
 */
export function coverageGate(coverage, { threshold = DEFAULT_COVERAGE_THRESHOLD, zones } = {}) { ... }

/**
 * Coverage-aware accept: coverageGate FIRST (precondition — a failing base coat rejects regardless of
 * the resemblance delta), then acceptIfCloser unchanged.
 * @returns {{accepted, reason:"coverage"|"resemblance-improved"|"resemblance-not-improved",
 *            coverage:<coverageGate result>, before, after, delta, epsilon} }  // resemblance fields
 *            null-filled when short-circuited on coverage
 */
export function acceptWithCoverage({ coverage, threshold, zones, before, after, epsilon }) { ... }
```

Shape detail for `acceptWithCoverage`:
- coverage fail → `{accepted:false, reason:"coverage", coverage, before:null, after:null, delta:null,
  epsilon: epsilon ?? 0}` — resemblance fields explicitly nulled, NOT computed (the record must show
  the delta was never consulted).
- coverage pass → spread `acceptIfCloser({before, after, epsilon})`, add `reason` + `coverage`.

## Module boundaries (unchanged, restated)

- `zone-fill.mjs` owns the CENSUS + its decoration (what IS on the skin vs. what the policy intends) —
  no thresholds, no verdicts.
- `face-resemblance.mjs` owns the VERDICT (threshold, precondition ordering, accept/reject) — no
  occupancy access; consumes the coverage record as data.
- The runner owns I/O, GL, zone policy derivation, and the durable record — no decision logic.
